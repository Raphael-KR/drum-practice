# 시간 정보가 있는 가사 찾기

목표는 해당 곡에 실제로 대응하는 시간 자료를 찾아 재사용 가능성과 한계를 확인하는 것이다. 일반 가사 페이지를 검색 성과로 대신 제시하지 않는다.

## 곡 식별과 탐색

- 곡명·가수·표기 변형을 확보한다. 일본어는 Unicode NFC 정규화, 원어·로마자·영문 제목, 공동 명의 가수까지 고려한다. 앨범명 일치만으로 곡 일치라 판단하지 않는다.
- 음원 버전이나 길이가 없더라도 탐색은 진행한다. 풀 버전·TV 편집·라이브·커버는 분리한다. 정확한 싱크 검증에는 사용 음원이 필요하다.
- LRCLIB의 실제 API 결과와 공개 웹 검색을 병행한다. LRC만 검색하고 모든 시간 자료가 없다고 결론 내리지 않는다.
- 필요하면 Enhanced LRC, ASS/SSA 가라오케, SRT/VTT/TTML, 공개 가라오케 저장소, TypingTube의 해당 곡으로 확장한다. 구체 접근법은 [sources.md](references/sources.md)를 읽는다.
- 사용자가 “다 조사해”, “마저 해봐”라고 하면 이미 확인한 결과를 반복하지 말고 미검증 후보의 실제 데이터를 확인한다. 동일 실패를 반복하거나 끝없이 검색하지 않는다. 접근 제한은 차단 상태로 보고한다.
- CLI·API·비-GUI 검색을 우선한다. 외부 사이트 GUI 승인은 로컬 앱 GUI 승인과 별개다. 인증·결제·접근 통제를 우회하지 않는다.

## 실제 자료 판정

다음 항목을 분리해서 기록한다.

1. 곡과 버전: 제목·가수·길이·원본 음원/영상 URL 또는 ID.
2. 형태: 배포되는 독립 파일 / 사이트 내부 시간 데이터 / 영상에 구워진 자막.
3. 단위: 행 / 단어 / 음절. 확장자나 “karaoke”라는 이름만으로 판정하지 않는다.
4. 검증: 검색 결과만 확인 / 실제 내용 검사 / 사용 음원과 싱크 검증.

- LRC: 실제 `[mm:ss.xx]` 태그와 가사 이벤트의 존재를 검사한다. 메타데이터만 있는 파일은 제외한다.
- Enhanced LRC: 행 내부 시각 태그가 존재하는지 확인하고, 단어와 음절 중 무엇을 구분하는지 내용으로 판정한다.
- ASS/SSA: 노래 구간인지 먼저 확인하고 `\k`, `\K`, `\kf`, `\ko` 등을 검사한다. 일반 대사 ASS 묶음을 노래 파일 후보로 삼지 않는다. 태그가 없으면 표준 가라오케 태그는 없다고만 판정한다. 별도 이벤트로 구현된 효과까지 없다는 증거는 아니다.
- SRT/VTT/TTML: 실제 노래 구간과 cue/span의 시간 단위를 확인한다. 보통의 cue 시작·종료 시각은 음절 타이밍이 아니다.
- 시간값의 범위·정밀도·정렬·중복·offset·빈 행·종료 표식을 검사한다. 겹침이나 중복을 무조건 오류로 삭제하지 않는다.
- 판정은 “확인”, “검색 범위 내 미발견”, “접근 불가로 미확인”을 구분한다. 인터넷 전체에 존재하지 않는다고 단정하지 않는다.

## 저장과 사용자 가사 결합

- 저작권 있는 외부 가사 전체를 추출·재배포하는 파일은 제공하지 않는다. 허용된 자료인지 구분하고, 필요한 경우 타임스탬프만 저장한 뒤 사용자가 제공한 가사로 변환한다.
- 타임스탬프만 요청받으면 가사·발음·번역·원문 API 응답을 파일이나 로그에 남기지 않는다. `[mm:ss.xx]` TXT 또는 행 번호·시작 시각 CSV를 사용한다.
- 출처 URL, 조회일, 타이밍 단위, 영상 ID, 선택·제외 행 수, offset 처리, 오디오 검증 여부를 가사 없는 별도 메타데이터로 남기면 후속 매핑에 도움이 된다. 세션 토큰·쿠키·키는 저장하지 않는다.
- 드럼연습실에서는 `data/reference/lyrics-timing/`에 로컬 자료를 저장하고 현재 Git 제외 설정을 확인한다. 기존 파일을 덮어쓰지 않는다.
- 사용자 가사를 결합할 때 원문을 보존한다. 원본 시간 데이터의 구절 경계와 실제로 대조한 경우에만 타이밍을 배정한다. 행 수·문자 수·순서만으로 대응을 추측하지 않는다.
- 35개 시각과 31개 가사 행처럼 개수가 다르면 분할·병합 대응을 먼저 검증한다. 확인된 병합은 설명하고, 알 수 없는 내부 시작 시각을 보간하거나 만들어내지 않는다. 대응을 확인할 수 없으면 미확인 구간을 명시한다.
- 파일을 직접 내려받은 결과와 내부 데이터로 새로 만든 LRC를 구분한다. 사용자 요청이 코드블록이면 코드블록으로 제공한다.
- 사용 음원과 대조하지 않았으면 “해당 영상 기준 초안, 음원 싱크 미검증”이라고 표시한다. 악보 마디·박 및 MusicXML 변환은 별도 요청 범위다.

## 짧은 결과 보고

먼저 사용 가능한 시간 자료가 있는지 말한다. 이어 출처 링크, 형식·단위·곡 버전, 실제 검사 결과, 저장 경로와 미검증 한계를 적는다. 일반 가사 링크나 같은 검색 결과로 보고를 채우지 않는다.
