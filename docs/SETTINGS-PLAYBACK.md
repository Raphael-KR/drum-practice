# 설정과 재생 정책

목표: 설정을 화면·재생·악보·정보로 정리하고 연습 재개 동작을 사용자가 선택한다.
범위: 설정 UI, 앱 공통 재생 환경설정, 카운트오프 스케줄·음색.
완료 조건: 두 토글 독립 동작·저장 복원·곡 전환 시 유지, 4분음표 스틱 4회 후 재생, 관리 메뉴 보존.
제외: 악보/가사 정본 변경, 기존 HTML 재내보내기, 외부 게시.
검증: 단위·UI 통합 검사, 전체 회귀/빌드, Safari 설정과 재생 확인.

- 화면: 보기·크기·전체화면.
- 재생: ‘마디 처음부터 다시 재생’, ‘카운트오프 (Count-off)’ 토글. 둘 다 기본 켬. 브라우저 앱 공통 설정이며 곡/백업 데이터와 분리한다.
- 악보: 악보·가사·곡 정보 편집, 추가/내보내기, 백업/복원.
- 정보: 앱 이름·package.json 버전, 최근 작업 기록(현재 세션 5건).
- 카운트오프는 현재 연습 템포의 4분음표 간격으로 스틱 4회. 박자표의 분자/분모와 무관하게 길이는 4분음표 네 개다. 4/4·5/4·6/8 모두 동일한 분음표 길이를 사용한다.
- 수동 시작/재개에 적용한다. 드래그 후 이어 재생, 속도 변경, 루프 경계는 새 카운트오프 없이 연속 진행한다. 기존 준비 마디 수·반복마다 준비 UI는 없애고 저장된 과거 필드는 호환성을 위해 보존하되 새 재생 정책에는 사용하지 않는다.
- 두 토글 변경은 다음 수동 재생부터 적용한다. 현재 위치나 재생은 즉시 변경하지 않는다.
- ‘카운트오프’는 이 앱의 확정 표기다. 영어 count-in도 국제적으로 사용되는 용어이므로 비표준/한국 한정으로 설명하지 않는다.

## 검증 (2026-09-20)

- 전체 46파일 193테스트 및 production build 통과. 4/4·5/4·6/8, 연습 배속별 카운트 간격과 두 토글 네 조합을 검사했다. 저장소 사용 불가 시 세션 내 설정을 유지한다.
- Safari 실제 앱에서 토글 저장/재로드 복원을 확인했다. 원본 위치 70.37초에서 둘 다 끄면 70.37초부터 지연 없이 재생한다. 둘 다 켜면 해당 마디 시작 69.323506초로 이동하고 약 0.638283초 간격 4회(총 2.553131초) 후 재생한다.
- 가로 1133×744 설정 화면과 악보 관리 메뉴를 확인했다. 증거는 로컬 docs/experiments/settings-*.png에 보관한다.
- 스틱 소리는 짧은 합성 타격음이다. 실제 iPad 스피커 음량·음색 청취는 미검증이다. Safari 결과를 실기기 청취 결과로 간주하지 않는다.
