# 설정과 재생 정책

목표: 설정을 화면·재생·악보·정보로 정리하고 연습 재개 동작을 사용자가 선택한다.
범위: 설정 UI, 앱 공통 재생 환경설정, 카운트오프 스케줄·음색.
완료 조건: 두 토글 독립 동작·저장 복원·곡 전환 시 유지, 4분음표 스틱 4회 후 재생, 관리 메뉴 보존.
제외: 악보/가사 정본 변경, 기존 HTML 재내보내기, 외부 게시.
검증: 단위·UI 통합 검사, 전체 회귀/빌드, Safari 설정과 재생 확인.

- 화면: 보기·크기·전체화면.
- 재생: ‘마디 처음부터 다시 재생’, ‘카운트오프 (Count-off)’ 토글. 둘 다 기본 켬. 브라우저 앱 공통 설정이며 곡/백업 데이터와 분리한다.
- 악보: 악보·가사·곡 정보 편집, 추가/내보내기, 백업/복원.
- 정보: 제품 버전(소스 식별자)·KST 빌드 시각, 최근 작업 기록(현재 세션 5건).
- 카운트오프는 현재 연습 템포의 4분음표 간격으로 스틱 4회. 박자표의 분자/분모와 무관하게 길이는 4분음표 네 개다. 4/4·5/4·6/8 모두 동일한 분음표 길이를 사용한다.
- 수동 시작/재개에 적용한다. 드래그 후 이어 재생, 속도 변경, 루프 경계는 새 카운트오프 없이 연속 진행한다. 기존 준비 마디 수·반복마다 준비 UI는 없애고 저장된 과거 필드는 호환성을 위해 보존하되 새 재생 정책에는 사용하지 않는다.
- 두 토글 변경은 다음 수동 재생부터 적용한다. 현재 위치나 재생은 즉시 변경하지 않는다.
- ‘카운트오프’는 이 앱의 확정 표기다. 영어 count-in도 국제적으로 사용되는 용어이므로 비표준/한국 한정으로 설명하지 않는다.

## 검증 (2026-09-20)

- 전체 46파일 193테스트 및 production build 통과. 4/4·5/4·6/8, 연습 배속별 카운트 간격과 두 토글 네 조합을 검사했다. 저장소 사용 불가 시 세션 내 설정을 유지한다.
- Safari 실제 앱에서 토글 저장/재로드 복원을 확인했다. 원본 위치 70.37초에서 둘 다 끄면 70.37초부터 지연 없이 재생한다. 둘 다 켜면 해당 마디 시작 69.323506초로 이동하고 약 0.638283초 간격 4회(총 2.553131초) 후 재생한다.
- 가로 1133×744 설정 화면과 악보 관리 메뉴를 확인했다. 증거는 로컬 docs/experiments/settings-*.png에 보관한다.
- 스틱 소리는 짧은 합성 타격음이다. 실제 iPad 스피커 음량·음색 청취는 미검증이다. Safari 결과를 실기기 청취 결과로 간주하지 않는다.

## 화면 설정 개편 (2026-09-20 추가 승인)

- 설정 바깥에서 시작하고 끝난 탭만 설정을 닫는다. 뒤 악보에 클릭을 전달하지 않는다. 미저장 편집 창에는 이 동작을 적용하지 않는다.
- 모달 닫기는 접근성 이름 ‘닫기’를 가진 원형 × 아이콘, 최소 48px 터치 영역으로 표시한다.
- 보기 선택은 한 줄/두 줄/검수 드롭다운이며 선택한 보기 설명만 표시한다.
- 수동 전체화면 버튼을 제거한다. 자동 전체화면 옵션은 현재 열린 악보에도 즉시 적용/해제하며 다음 곡에도 유지한다. 브라우저가 거절하면 안내한다.
- ‘악보를 PDF로 보기’는 앱 공통 설정, 기본 끔(MusicXML SVG 우선). PDF만 있으면 켬·잠금, MusicXML만 있으면 끔·잠금 및 ‘PDF 악보 없음’. 강제 표시 상태는 공통 선호를 덮어쓰지 않는다. 검수 모드에서는 옵션을 숨긴다.
- 목록에서 특정 형식을 명시적으로 열면 두 형식이 있는 경우 같은 공통 선호를 갱신한다. 곡별 선호는 저장하지 않는다.
- 형식 전환은 새 이미지 준비 후 표시 기하만 교체한다. 오디오 엔진을 재로딩하지 않아 위치·재생 상태·반복을 유지한다.
- 검증: 단일 형식/양쪽 형식과 공통 선호 보존 단위 검사, 바깥 탭과 드래그 구분 UI 검사, Safari 실제 양방향 전환·위치 유지·바깥 탭 확인.
- Safari 실측: 39마디 2박+¼에서 38–40마디 반복을 설정한 채 PDF로 전환해 둘 다 유지. 전체화면 스위치로 fullscreenElement 생성/해제 확인. 전체 47파일 195테스트와 빌드 통과.

## 프로그램 버전 및 빌드 식별 (간소화)

- 버전은 package.json의 실제 제품 버전을 사용한다. UI 변경 때 임의로 버전을 올리지 않는다.
- 정보 표는 `버전 <제품 버전> (<소스 식별자>)`, `빌드 시각 YYYY. M. D. HH:mm KST` 두 줄만 표시한다. 프로그램 정보 소제목·이름·빌드 번호·별도 소스 식별자 행은 제거한다.
- 빌드 번호 데이터 자체도 생성하지 않는다. 생성 JSON은 builtAt과 source만 가진다. 소스 식별자는 기존과 동일하게 빌드 입력 SHA-256 앞 12자리이며 미커밋 수정도 구분한다.
- scripts/build-info.mjs가 메타데이터를 생성한다. npm run dev의 predev, npm run build의 portable 단계에서 생성하고 웹/HTML에 같은 값을 포함한다. npm test의 pretest에서도 생성해 새 checkout 테스트를 지원한다.
- 개발 서버에서 소스만 실시간 수정한 경우 시각과 소스 식별자는 마지막 메타데이터 생성 시점 기준이다. 최종 빌드/HTML 생성 시 갱신된다. 생성 JSON은 Git에 넣지 않는다.

## 설정 사용 흐름과 배치 (2026-09-20)

- 가로 화면 설정 최대 너비 720px(기존 880px), 세로는 기존 화면 폭 대응 유지.
- 보기 선택은 현재 문구와 여백/화살표에 맞춰 자동 너비, 우측 끝 고정. 설명도 우측 정렬. 스위치별 설명은 좌측 유지.
- 재생 하단 ‘모든 곡에 공통으로 적용하며…’ 문구만 제거. 정책은 그대로 유지.
- 정보 상세 제목은 ‘드럼 연습실’, 왼쪽 메뉴 이름은 ‘정보’ 유지.
- 마지막 메뉴를 drum-practice.settings-category에 저장. 처음에는 화면, 이후 다시 열기·앱 재시작 시 마지막 메뉴 복원.
- 설정에서 연 악보/가사/곡 정보 편집·원본·악보 추가 창을 닫거나 Escape로 닫으면 출발 메뉴와 스크롤을 복원. 설정 외부에서 직접 연 창은 설정으로 돌아가지 않는다. 설정 자체 닫기는 연습 화면으로 돌아간다.

- 상세 영역의 화면/재생/악보 중복 제목은 숨긴다. 정보의 ‘드럼 연습실’ 제목만 유지한다. PDF 옵션은 구분선 아래에서 전체화면 바로 위에 배치한다. 보기·악보 크기 제목은 스위치 제목과 동일하게 15px/600으로 통일한다.

- 보기 명칭은 ‘두줄로 고정 보기’. 항목과 하단 설명은 공통 5px 간격으로 묶는다. 전체화면 성공 상태 문구는 표시하지 않고 지원 불가/실패 안내만 해당 항목 설명 아래에 표시한다.
