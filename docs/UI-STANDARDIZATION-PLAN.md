# UI 표준화·다국어·접근성 통합

- 목표: 화면 이름·공통 문구·접근성 이름을 정본으로 연결하고 재생바를 하나로 묶는다.
- 범위: 웹앱, 공유 재생 HTML 런타임, UI 카탈로그와 자동 생성 문서, Sites 반영.
- 완료 조건: 두 재생바가 공통 컨테이너에 있고 주요 컨트롤의 안정적 ID·접근성 이름이 양쪽 런타임에 적용된다.
- 제외: 전체 앱 영어 번역 완료 선언, 악보 데이터 번역, 미디어 변경, 버전 변경.
- 검증: 카탈로그 구조와 문서 동기화, 웹/HTML DOM 의미·레이아웃 회귀 검사, 전체 테스트·빌드, Safari 실제 화면 검수.

정본은 `src/ui-catalog.json`, 호출은 `src/ui-standard.ts`, 문서는 `docs/UI-COMPONENTS.md`다. 한국어 기본을 유지하고 영어는 명시적으로 조회하는 기반만 제공한다. 브라우저 언어에 따라 부분 번역 화면을 자동 노출하지 않는다.

## 검증 결과 — 2026-09-21

- 카탈로그의 이름·상위 관계·공통 상태 문구, 두 런타임의 DOM 그룹 및 기존 이벤트 보존을 자동 검사했다.
- Safari MCP 웹앱: 폭 1024px, 문서 폭 1024px, 재생1/2바 간격 6px. Escape로 설정 닫기 후 `open-settings-dialog`에 포커스 복귀.
- Safari MCP file HTML: 폭 1024px, 문서 폭 1024px, 재생1/2바 간격 6px. Escape 후 `settings`에 포커스 복귀. 공통 정의가 실제 DOM에 연결됨.
- iPad mini 시뮬레이터 Safari 가로·세로: 공통 테두리, 버튼 잘림 없음, 설정 열기·메뉴 전환·닫기 확인. `docs/experiments/ui-standard/IPAD-SAFARI-QA-2026-09-21.md`.
- 빌드의 HTML 모듈 제외 검사: 관리·저장·원본 렌더러 코드 없음. HTML에는 재생에 쓰이는 UI 정의만 필터링해 포함한다.
- 한계: 전체 영어 번역과 VoiceOver 낭독 실사용 평가는 이번에 완료한 것으로 간주하지 않는다. 현재 범위는 공통 명명·번역 기반·의미 구조·키보드/포커스 동작이다.
- 실험 기록: 최초 4-worker 전체 검사에서 기존 bundled-score 테스트가 5초 제한 초과. 2-worker 검사로 재검증했다. Safari `ESC` 키 표현은 지원하지 않았고 `Escape`로 실제 닫기 및 포커스 복귀를 확인했다. 네이티브 QA 중 HMR로 중단된 1회는 제외하고 다시 검사했다.

최종 검증: 57개 테스트 파일/242개 테스트 통과, 빌드와 문서 동기화 검사 통과. Sites 버전 6 배포 succeeded.
