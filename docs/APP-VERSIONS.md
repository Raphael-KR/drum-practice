# 앱 공통 버전

악보제작기와 드럼연습실의 현재 정본은 `src/app-versions.json`이며 두 앱 모두 **0.7.4**다. 한쪽 전용 수정도 기본적으로 같은 릴리스 번호를 쓰고 변경 내용을 구분한다. 새 독립 사용자 기능은 minor, 기존 기능 완성·보완·오류 수정은 patch다. 음원 연습 기능 안정화는0.7.x로 유지한다.

문서의 릴리스 제목·앱 표시 정본은 정정 번호를 사용한다. 위의 당시 표시 값은 배포 추적용이며 현재 버전 정책이 아니다. 기존 커밋 SHA, Sites 버전/배포 ID, 빌드번호, 원본 검증 로그는 당시 산출물을 가리키므로 유지한다. 검증 로그의 `.tmp/release-0.8.0/` 및 `.tmp/release-0.8.1/` 경로도 그대로다. 의존 라이브러리 버전은 이 정정과 무관하다.

이번 정정은 로컬 커밋까지만 수행한다. push와 공개 발행은 보류하므로 공개 Site에는 아직 당시 player 표시가 남아 있다. 다음 발행에서 공통0.7.4 표시를 반영한다. 제작기 공개 범위는 늘리지 않는다.
