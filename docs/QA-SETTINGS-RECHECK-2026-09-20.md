# 설정·주요 연습 흐름 재검증 — 2026-09-20

## 범위와 판정 기준

사용자가 지적한 홈/곡 상태 차이, 설정 일관성, 하위 창 복귀를 중심으로 새로 실행했다. 기존 QA 결과를 이번 실행 결과로 재사용하지 않았다. 자동 테스트 성공과 실제 브라우저 확인은 별개로 기록한다. 전체 앱의 모든 입력·모든 악보가 검증됐다는 의미는 아니다.

- 대상: http://127.0.0.1:5173/, 제품 0.2.0, 수정 후 소스 식별자 `9aa6a3f7862a`.
- Safari 실제 viewport: 초기 1080×799, 세로 744×1133, 최종 가로 1133×744. macOS Safari 크기 조절 검증이며 실물 iPad 검증이 아니다.
- Ego: Safari MCP 미지원인 실제 pointer drag/wheel 입력만 CDP Input으로 검사. DOM 합성 이벤트로 드래그를 대신하지 않았다.
- 보기 변경·형식 전환 일부는 Safari 페이지의 실제 컨트롤 change/click 처리기를 실행했다. native select 메뉴 자체 조작 증거로 간주하지 않는다.
- 기존 곡·가사·미디어는 교체/삭제하지 않았다. 편집 창은 저장하지 않고 닫았다.

## 자동 검증

- 수정 전/후 `npm test`: 48파일, 198테스트 통과. 기존 UI 테스트에 홈/곡 상태 전환 및 동적 닫기 아이콘 회귀 조건 추가.
- 수정 후 `npm run build`: TypeScript, portable template, Vite 성공.
- 기존 경고: portable IIFE의 개발 전용 import.meta.hot, score-pages 동적/정적 import 혼합, 큰 bundle. 런타임 오류로 판정하지 않으며 빌드 경고가 없었다고 주장하지 않는다.

## 검증하지 않은 범위

- 실물 iPad 터치/두 손가락 제스처, 스피커에서의 메트로놈 음량·카운트오프 청취.
- 모든 마디의 PDF/MusicXML 음악 내용 대조, 전체 가사 싱크.
- 이번 실행에서 PDF-only/XML-only 파일을 실제로 새로 가져오는 E2E. 해당 분기는 자동 테스트만 실행했다.
- 파일 교체/백업 복원/삭제 같은 실제 데이터 변경, 새 HTML 파일 내보내기 후 오프라인 실행, OS 클립보드 캡처 왕복.
- 이번 Ego 실행에서 단일/이중 탭과 진행률 드래그는 별도 재실행하지 않았다. 관련 자동 테스트 성공만으로 실물 제스처 성공이라 하지 않는다.
