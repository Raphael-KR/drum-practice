# 사용자 교체 가사 v2 — 반영 및 한계

## 범위와 결과

2026-09-19 사용자가 제공한 새 가사와 추가 후렴을 표시 정본으로 삼았다. 11개 가창 구간 전체를 다시 분석했다. 한글 발음을 사용하고 영어는 기존처럼 한글 발음으로 표시한다. 장음 하이픈과 ‘나앗’·‘타앗’·‘후웃’ 같은 표기는 앞 음절과 묶어 별도의 잘못된 시작점을 만들지 않는다. 기존 556개에서 534개 표시 단위로 바뀌었다. 단위 수 변화는 단순 삭제 수가 아니다.

Apple 로컬 STT로 음원 전체 가창부를 재전사하고 AFM은 텍스트 차이 후보 59건에 의견을 붙였다. 총 차이 후보 112건에는 일본어 원문의 누락 글자·표기 차이·STT 오인식이 포함된다. AFM의 판단으로 가사나 시각을 자동 확정하지 않았다.

반주 포함 음원 2조건, 분리 보컬 2조건, 짧은 보컬 구간 1조건의 phonetic DTW를 비교했다. 0.035–0.8초 길이와 확률 0.03 이상인 후보 중 중앙값을 사용하되 근거가 2개 미만이면 기존 구절의 잠정 위치를 유지했다. 구간 첫 음절은 DTW가 클립 시작에 붙이는 현상이 있어 그대로 채택하지 않았다. 단어 내부에 일정 간격으로 시각을 나누지 않았다. 순서 충돌로 최소 0.01초 간격을 부여한 6곳도 의심 목록에 표시했다.

001, 002, 15마디 청취 앵커는 확정 보존. 003은 ‘소’가 새 가사 ‘카’로 바뀌므로 26.872초를 구절 앵커로만 사용했다. 전체 청취 검증이나 100% 정확한 정렬을 주장하지 않는다. 자동 정렬 의심 항목 136개는 [새 목록](LYRIC-SYNC-SUSPECTS.md)에 있다.

## 새 제공 가사 자체에 남은 확인점

표시 가사를 임의로 고치지 않고 사용자 한글 원문을 유지했다. 다음은 싱크와 별도로 확인할 내용이다.

- ‘코마라테타히’와 일본어 ‘困らせた日’는 발음이 일치하지 않는다. 보통의 읽기는 ‘코마라세타히’에 해당한다.
- ‘미타코토노나이’와 일본어 ‘見たこともない’의 노/모가 다르다.
- ‘요 니’, ‘타이요’, ‘키보’ 등 장음 표기가 구절마다 다르다. 사용자가 적은 음절만 표시하며 누락된 장음 음절을 생성하지 않았다.
- 일본어에는 ‘風の い’, ‘すり?けても’, ‘きだすよ’, ‘した夢’, ‘身 な者’ 같은 누락·깨짐이 있다. 일본어 원문을 완전한 기준 전사로 취급하지 않았다.
- 영어 ‘always blight’는 사용자 원문대로 보존했다. 영어 철자·정확한 가창 발음은 별도 확인이 필요하다.

## 적용·복구

src/lyric-revision.ts가 기존 곡 ID와 구판 전체 가사 지문/개수를 확인한 뒤 새 가사로 교체한다. 교체 전 음절·시각·수동 확인 상태는 song.lyricArchive에 복사해 저장하며 JSON/휴대용 내보내기에도 함께 남는다. 새 판본에 대한 이후 수동 편집은 재진입 시 덮어쓰지 않는다. 가사 본문을 이미 다른 내용으로 수정한 악보에는 자동 적용하지 않는다.

public/demo/song.json 갱신. 개발 웹앱은 새로고침 후 해당 악보를 열면 저장된 구판을 전환한다. 이전에 내보낸 독립 HTML 파일은 변경하지 않았다.

로컬 재현 자료: docs/experiments/lyrics-v2/ 아래 user-source.json, song-before.json, manifest.json, units.json, kana.json, Apple 결과, aligned-*.json, evidence.json, new-lyrics.json, apply.ts. 원문·음원·실험 자료는 Git 제외 경로에 보존했다. 절차 스크립트는 scripts/apple-local/align_syllables.py 및 reconcile_alignment.py이다.
