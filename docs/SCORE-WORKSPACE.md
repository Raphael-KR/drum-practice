# 통합 악보 화면

설정 > 악보에는 곡 제목·아티스트·마디 수·BPM과 보유 상태 칩을 표시한다. 그 아래의 정사각형 악보 편집 버튼을 누르면 기존 editor-dialog를 화면을 크게 채우는 별도 모달 레이어로 연다. 새 편집창을 만들지 않는다. 닫으면 아래의 설정으로 돌아간다.

별도 상단 공통영역은 두지 않는다. 파일 보유 칩은 최상단 편집 제목 우측에 표시한다. 곡 제목·아티스트·BPM은 곡 정보의 기존 입력값으로만 표시하고, 마디 수는 곡 정보에 읽기 전용으로 표시한다.
최상단 제목/닫기와 같은 바에서 곡 정보, 악보 편집, 가사, 파일을 글자 탭으로 전환한다.
각 탭은 파랑/빨강/초록/노랑 색으로 구분하고 내용 배경도 같은 계열로 표시한다.
탭에는 한국어 i18n 이름과 접근성 이름을 제공한다. 선택된 탭은 높게 올라오고 같은 색의 본문과 이어진다.

모달은 화면 높이를 넘지 않는다. 큰 창의 본문 영역만 세로 스크롤하며 탭별 위치를 기억한다.
탭 이동은 입력 폼을 재생성하지 않는다. 기존 편집 세션의 임시저장/저장/되돌리기/종료 확인을 공유한다.
전체 악보 보기와 업로드·내보내기는 별도 대화상자로 열고 닫으면 원래 탭으로 돌아온다.
파일 탭의 현재 곡 악보 추가·교체는 한 항목이며, 새 곡 추가는 보관함에 둔다.

## 곡 정보 시각 체계
- 공통 저장 상태/되돌리기/다시 실행/이력/저장은 최상단 도구막대로 이동한다.
- 넓은 화면은 제목·칩·탭·편집 도구·닫기 순서, 좁은 화면은 최상단 영역 안에서 행을 나눠 터치 영역을 유지한다.
- 곡 정보는 제목 우선의 밝은 카드와 템포/타이밍 카드로 구분한다. 입력은 48px 이상 높이, 일정한 라벨/필드 간격과 포커스 테두리를 사용한다.
- Apple HIG Materials의 조작 영역과 콘텐츠 계층 분리 원칙 참고: https://developer.apple.com/design/human-interface-guidelines/materials
- 웹 CSS 구현이며 네이티브 Liquid Glass API 사용을 뜻하지 않는다.

## 설정 진입 타일 — 2026-09-21 승인 반영

악보 편집·내 악보 목록·악보 추가를 같은 120×120 흰색 정사각형 타일로 배치한다. 아이콘 위·이름 아래, 왼쪽 정렬, 일정한 간격을 유지하며 공간이 좁으면 줄바꿈한다. 곡이 없을 때는 편집 타일만 숨긴다. 기존 홈의 목록·추가 동작을 재사용한다. 파란 강조는 선택된 설정 메뉴에 사용한다.

## 악보 편집 탭 — 승인 배치 적용

전체 보기 두 버튼과 페이지·마디 선택은 공통 도구막대에 둔다. 큰 악보 미리보기와 선택 마디 설정을 좌우로 분리하고 좁은 화면에서 세로로 배치한다. 내부 박 위치는 접기 영역에 보존하고 삭제는 별도로 둔다. 박 수와 분모는 공통 숫자 드래그 및 휠로 조절하며, 분모는 2·4·8·16만 순회한다. 이름과 0.001초 시각은 키보드 입력을 유지한다.

## 곡 정보 — 2026-09-21 저장 통합

곡 정보 입력과 음원·악보 연결을 좌우에 배치하고 좁은 화면에서는 세로로 배치한다. 표시 제목·원제·가수·작사·작곡은 각각 한 행으로 표시하며 라벨은 좌측에 정렬한다. 중복 곡 정보 제목은 제거하고 마디 수는 연결 영역에 둔다. BPM은 기본 BPM으로 표시하며 드래그·휠을 지원한다. 첫 박 시각은 정밀 키보드 입력을 유지한다.

곡 정보 적용 버튼과 개별 처리 코드를 제거했다. 상단 저장의 기존 flushEditorForm → commit → persist 경로에서 입력 중인 제목·원제·가수·작사·작곡을 함께 저장한다. 템포/첫 박 변경은 기존 시간 보정에 영향을 주므로 전체 다시 맞추기 절차를 유지한다. 변경이 있는 상태의 닫기 확인, 임시저장·이력 동작도 유지한다.

## 파일 작업 통합 — 2026-09-21

파일 탭을 제거하여 곡 정보·악보 편집·가사 세 탭으로 구성한다. 곡 정보의 `악보-음원 연결` 박스 상단에 악보 교체·음원 교체, 중간에 타이밍 조정, 하단 구분선 아래에 내보내기를 둔다. 기존 교체·내보내기 동작을 재사용한다. 가사 탭은 전체 너비를 유지한다. 앞서 제안한 가사·파일 좌우 통합 목업은 폐기한다.
