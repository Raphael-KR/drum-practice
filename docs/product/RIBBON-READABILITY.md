# 한 줄 악보 가독성 연구 — 이력 안내

문서 역할: **이력 진입점**. 현재 적용할 계약은 [현행 배치·배율](../reference/score/rendering.md#svg-score-rules--8-연습-화면-전용-배치), [검수 절차](../how-to/verify.md#ui-review--화면악보재생-검수-절차)에서 읽는다. 이전 시안·계산식·측정값·미확인은 [ADR-0005](../decisions/0005-practice-layout-and-spacing.md)의 이관 원문으로 분리했다. 당시 HTML 저장·렌더러 버전·화면 수치·미배포 상태를 현행 지시로 읽지 않는다.
