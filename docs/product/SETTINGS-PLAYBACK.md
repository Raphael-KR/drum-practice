# 설정과 재생 정책

현재 기준: 0.7.6. 세부 화면 배치와 도움말은 [UX 원칙](UX-PRINCIPLES.md), 공통 폼은 [playback-forms.ts](../../src/modules/playback/playback-forms.ts)를 따른다.

## 설정 범위

- 악보 선택 화면의 설정에는 **화면 > 악보 제목 표시 순서**, **내 음원 목록 > 사용자 설정 백업·복원**를 둔다. 제목 순서는 목록·재생 화면에 함께 적용한다.
- 재생 화면의 설정 순서는 **화면 → 재생 → 악보 → 정보**다. 음원만으로 연습할 때는 악보 대신 내 음원 목록 섹션에 사용자 설정 백업·복원를 둔다. 제작 전용 편집·백업 메뉴는 악보제작기에만 둔다.
- 화면에는 줄 보기, 선택 가능한 악보 형식, 제목 표시 순서, 배율·균등 모드·음표 따라가기·전체화면 설정을 둔다. 선택할 수 없는 형식 행은 숨긴다.
- 양자 선택은 공통 분할 버튼 CSS를 사용한다. iPhone 세로의 볼륨은 음악/메트로놈을 한 줄씩 배치한다.
- 정보에는 앱 버전·소스 빌드 식별자·KST 빌드 시각·라이선스를 표시한다. 앱 버전 정본은 [app-versions.json](../../src/app-versions.json)이며 `package.json`과 구분한다.

## 기본값과 재생

새 곡과 새로 불러온 악보·음원은 음악 **50%**, 메트로놈 **100%**, 메트로놈 **켜짐**이다. 이미 저장한 곡과 연습 JSON 파일로 복원한 곡은 저장한 값을 유지한다.

**마디 처음부터 다시 재생**과 **카운트오프**는 독립 설정이며 기본 켬이다. 일반 수동 시작/재개에 적용한다. 속도 변경·루프 경계 등 연속 재생에는 새 카운트오프를 추가하지 않는다. 일반 카운트오프는 현재 연습 템포의 4분음표 네 번이며 박자표에 따라 준비 마디 수를 늘리는 기능과 구분한다.

연주 전이 있는 음원에서는 음원을 지연하지 않고 1마디 직전 마지막 네 박에 카운트를 겹친다. 실제 박과 고정 BPM의 시간 기준, 짧은 앞부분·중간 재개 동작은 [음원 연습](AUDIO-PRACTICE.md)을 따른다.

원곡 버튼은 실제 1배속으로 복귀한다. 연습 BPM 프리셋은 3×3이고 변환 상태는 숫자창과 프리셋 사이에 표시한다. 재생 중 화면 유지는 지원 브라우저에서 요청하며, OS 알림 차단이나 화면 유지 성공을 일괄 보장하지 않는다.

## 검증

현재 릴리스의 자동 검사·Safari·발행 근거는 [검증 현황](../operations/acceptance.md)에 모은다. 이전 문서의 테스트 수나 실기기 미확인 상태를 현재의 전체 검증 결과로 대신하지 않는다.

연습 파일은 내 음원 목록 전체의 정보를 하나의 JSON으로 저장하며 음원은 포함하지 않는다. 원본 음원 해시 대조·일괄 복원 정책은 [연습 파일](../architecture/PRACTICE-FILE.md)을 따른다.
