## 드럼킷 선택과 보존 라이브러리

결정 근거: [ADR-0019](../../decisions/0019-preserved-drum-kit-selection.md). 실행: [절차](../../how-to/render-drum-audio.md#drum-audio--보존-드럼킷으로-음원-제작).

<a id="garageband-drum-kits--선택-기준"></a>

### 선택 기준

악보에 사용할 드럼 음원을 새로 제작할 때는 이 문서를 먼저 읽고, 곡의 장르·분위기·연습 목적과 필요한 악기·주법에 맞게 **보존된 SoCal·Portland 중에서** 선택한다. SoCal을 고정 기본값으로 사용하지 않는다. 사용자가 키트를 지정하면 그 선택을 우선하되, 삭제된 키트는 현재 사용 가능한 후보로 취급하지 않는다.

- [키트 소개표](../../decisions/0019-preserved-drum-kit-selection.md#소개-자료와-읽는-법)에서 보존된 두 키트만 후보로 좁히고, 리듬·탐 높낮이·타격 구분 등 이번 연습에서 잘 들려야 하는 요소를 기준으로 선택한다. 자동 드러머의 연주 스타일과 키트 자체의 음색을 구별한다.
- 아래 프로젝트 보존본에서 실제 사용할 패치·악기 정의·샘플과 필요한 주법·음역·벨로시티 지원을 확인한다. 키트별 샘플 선택용 MIDI 변환이 필요하면 별도로 기록하며 악보의 승인된 MusicXML·GM 매핑을 바꾸지 않는다.
- 선택이 애매하면 같은 악보 이벤트·타이밍·벨로시티로 대표 구간을 비교한다. 소개에 따른 선택과 실제 청취로 확인한 결과를 구분하고, 미청취 결과를 청취 평가로 표현하지 않는다.
- **드럼 연습 악보는 가수란에 선택하여 사용하는 드럼킷 이름을 반드시 넣는다.** 예: SoCal 드럼킷, Portland 드럼킷. 특정 곡만의 예외가 아니다. MusicXML·Song·패키지의 메타정보 일치 규칙은 [저장 계약](musicxml.md#musicxml-canonical--저장-계약)을 따른다.
- 곡별 제작 기록에 선택한 키트, 선택 이유, 샘플 출처, 매핑·렌더 방식 및 검증 결과를 남긴다. 요청 범위 안의 키트 선택은 제작자가 판단하여 진행한다.
- 제공된 원음원 연결이나 MusicXML만 만드는 작업에 새 음원 제작을 추가하지 않는다. 기존 악보·음원을 이 결정만으로 일괄 교체하지 않는다.

<a id="garageband-drum-kits--제작-입력과-경계"></a>

### 제작 입력과 경계

사용할 보존 경로는 `/Users/raphael/Playground/drum-practice/local-libraries/garageband-drum-kits/`다. 현재 제작 후보는 SoCal·Portland와 이들이 참조하는 공통 퍼커션 의존성이다. Git 제외를 유지하며 샘플을 public·배포 자산으로 자동 추가하지 않는다. 작업 시작 때 manifest·실제 파일·해시·필요 주법 지원을 확인한다.

EXS 내부의 옛 설치 경로는 원본 식별자다. CLI는 manifest의 복사본 경로를 사용하고 크기·SHA256·샘플 참조를 검증하며 앱/시스템 원본으로 자동 우회하지 않는다. 설치 앱의 전체 효과 체인을 외부 샘플 믹서가 그대로 재현한다고 주장하지 않는다.

드러머와 실제 키트 연결은 설명 리소스의 DrumKitName 문자열 대신 동일 Identifier의 DefaultPatchGB와 실제 패치를 대조한다. 드러머 스타일 소개를 같은 MIDI의 자동 연주 변화나 직접 청취 평가로 해석하지 않는다.

<a id="garageband-drum-kits--소개와-실측-이력"></a>

### 소개와 실측 이력

키트 소개·선택 경위·보존/삭제 실측은 [ADR-0019](../../decisions/0019-preserved-drum-kit-selection.md)에서 확인한다. 보존 대상 외 키트는 제작 후보로 안내하지 않는다.
