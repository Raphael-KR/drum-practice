# 재생 설정과 탐색

문서 역할: **현행 Rule**. 현재 요구·계약과 지원 한계를 다룬다. [전체 정본](../../RULES-INDEX.md), [실행 안내](../../README.md), [결정 이력](../../decisions/README.md)을 함께 참고한다.

<a id="settings-playback--설정과-재생-정책"></a>

## 설정과 재생 정책

현행 설정·재생 Rule이다. 결정 근거는 [ADR-0006](../../decisions/0006-practice-navigation-and-overlays.md)을 따른다. 세부 화면 배치와 도움말은 [UX 원칙](ux.md#ux-principles--팀-ux-원칙과-맥락형-도움말), 공통 폼은 [playback-forms.ts](../../../src/modules/playback/playback-forms.ts)를 따른다.

<a id="settings-playback--설정-범위"></a>

### 설정 범위

- 악보 선택 화면의 설정에는 **화면 > 악보 제목 표시 순서**, **백업 > 사용자 설정 백업·복원**을 둔다. 제목 순서는 목록·재생 화면에 함께 적용한다.
- 재생 화면의 설정 순서는 **화면 → 재생 → 악보 → 정보**다. 음원만으로 연습할 때는 악보 대신 **백업** 섹션에 사용자 설정 백업·복원을 둔다. 제작 전용 편집·백업 메뉴는 악보제작기에만 둔다.
- 화면에는 줄 보기, 선택 가능한 악보 형식, 제목 표시 순서, 배율·균등 모드·음표 따라가기·전체화면 설정을 둔다. 선택할 수 없는 형식 행은 숨긴다.
- 양자 선택은 공통 분할 버튼 CSS를 사용한다. iPhone 세로의 볼륨은 음악/메트로놈을 한 줄씩 배치한다.
- 정보에는 앱 버전·소스 빌드 식별자·KST 빌드 시각·라이선스를 표시한다. 앱 버전 정본은 [app-versions.json](../../../src/app-versions.json)이며 `package.json`과 구분한다.

<a id="settings-playback--기본값과-재생"></a>

### 기본값과 재생

새 곡과 새로 불러온 악보·음원은 음악 **50%**, 메트로놈 **100%**, 메트로놈 **켜짐**이다. 이미 저장한 곡과 연습 JSON 파일로 복원한 곡은 저장한 값을 유지한다. 서버 악보 패키지의 제작자 볼륨 대신 이 연습 기본값을 적용한다.

**마디 처음부터 다시 재생**과 **카운트오프**는 독립 설정이며 기본 켬이다. 일반 수동 시작/재개와 재생 중 마커·섹션 바로가기·주변 마디 반복·저장 반복 구간의 시작점 선택에 적용한다. 정지 중 선택은 이동만 하고 재생을 누를 때 카운트한다. 카운트 중 새 대상을 선택하면 이전 카운트를 취소하고 다시 시작한다. 반복 해제·삭제 및 마커 등록·삭제에는 새 카운트를 추가하지 않는다. 속도 변경·루프 경계 등 연속 재생에는 새 카운트오프를 추가하지 않는다. 일반 카운트오프는 현재 연습 템포의 4분음표 네 번이며 박자표에 따라 준비 마디 수를 늘리는 기능과 구분한다.

연주 전이 있는 음원에서는 음원을 지연하지 않고 1마디 직전 선택한 박자의 한 마디분에 카운트를 겹친다. 일반 재생 전의 4분음표 네 번과 구분한다. 실제 박과 고정 BPM의 시간 기준, 짧은 앞부분·중간 재개 동작은 [음원 연습](audio-practice.md#audio-practice--음원-연습)을 따른다.

원곡 버튼은 실제 1배속으로 복귀한다. 연습 BPM 프리셋은 3×3이고 변환 상태는 숫자창과 프리셋 사이에 표시한다. 재생 중 화면 유지는 지원 브라우저에서 요청하며, OS 알림 차단이나 화면 유지 성공을 일괄 보장하지 않는다.

버튼별 동작과 예외는 [재생 이동 Rule](playback.md#playback-actions--버튼-이동-카운트오프)를 따른다. 주변 마디 반복을 선택하는 순간에도 구간 시작으로 이동한다. 일반 탐색·드래그·처음·되감기에는 버튼 이동 카운트오프를 적용하지 않는다.

<a id="settings-playback--검증"></a>

### 검증

현재 릴리스의 자동 검사·Safari·발행 근거는 [검증 현황](../../records/acceptance.md#acceptance--검증-현황)에 모은다. 이전 문서의 테스트 수나 실기기 미확인 상태를 현재의 전체 검증 결과로 대신하지 않는다.

연습 파일은 내 음원 목록 전체의 정보를 하나의 JSON으로 저장하며 음원은 포함하지 않는다. 원본 음원 해시 대조·일괄 복원 정책은 [연습 파일](../score/file-formats.md#practice-file--음원-연습-파일)을 따른다.

<a id="marker-slots--마디-마커-슬롯"></a>

## 마디 마커 슬롯

현재 재생 화면은 **5개** 슬롯을 사용한다. 정본 구현은 [marker-slots.ts](../../../src/modules/playback/marker-slots.ts), 화면 배치와 도움말은 [UX 원칙](ux.md#ux-principles--팀-ux-원칙과-맥락형-도움말)을 따른다.

- 마커는 해당 마디 시작에 둔다. 키보드의 물리 M 키로 추가/삭제를 토글하며 대소문자·한글 입력 상태와 무관하게 동작한다. 입력 필드 편집 중에는 단축키를 적용하지 않는다.
- 저장된 슬롯은 먼저 해당 마디로 이동하고, 그 위치에서 다시 누르면 삭제한다. 삭제한 슬롯은 빈 자리로 남겨 다른 버튼이 즉시 당겨지지 않게 한다.
- 새 마커를 추가하면 마디 순서로 표시한다. 가득 차면 가장 오래 등록한 마커를 교체한다. 화면 정렬과 등록 순서를 구분한다.
- 마커는 빨강 계열, 반복 구간은 주황 계열이다. 9개 구간 슬롯과 5개 마커 슬롯을 혼동하지 않는다.
- iPhone 세로에서는 재생 버튼 아래에 5개를 배치한다. 마디 이동 숫자는 별도 기능이며 마커 관리 창을 여는 버튼이 아니다.

<a id="playback-actions--재생-이동과-반복-구간-동작"></a>

## 재생 이동과 반복 구간 동작

문서 역할: **현행 Rule**. [설정 정책](playback.md#settings-playback--설정과-재생-정책)·[마커 슬롯](playback.md#marker-slots--마디-마커-슬롯)·[SVG 탐색](../score/rendering.md#svg-score-rules--9-음표-따라가기탐색화면-효과)을 함께 적용한다. 결정은 [ADR-0006](../../decisions/0006-practice-navigation-and-overlays.md), 실제 검수 순서는 [UI 절차](../../how-to/verify.md#ui-review--화면악보재생-검수-절차)를 따른다.

<a id="playback-actions--버튼-이동-카운트오프"></a>

### 버튼 이동 카운트오프

| 상황 | 결과 |
| --- | --- |
| 재생 중 마커·섹션 바로가기·주변 마디 반복·저장 반복 구간 선택 | 대상 시작점으로 이동 → 설정이 켜져 있으면 카운트오프 → 재생. 꺼져 있으면 바로 재생 |
| 정지 중 버튼 선택 | 대상 시작점으로 이동하고 정지 유지. 이후 재생 버튼에서 설정에 따라 카운트 |
| 카운트 도중 다른 대상 선택 | 기존 소리·카운트를 취소하고 새 대상에서 다시 카운트 |
| 활성 주변 반복 재클릭·반복 해제·구간 삭제 | 새 카운트 없음. 기존 해제/삭제 동작 유지 |
| 현재 마디 마커 재클릭·빈 마커 등록 | 기존 삭제/등록 동작 유지. 새 카운트 없음 |
| 구간 자연 반복·속도 변경·드래그·진행률·방향키·처음·되감기 | 버튼 이동 카운트오프 적용 대상이 아님 |

주변 마디 반복도 선택 순간 구간 시작으로 이동한다. 마커·바로가기가 활성 구간 밖으로 이동하면 기존처럼 반복을 해제한다. 안쪽으로 이동하면 반복은 유지한다. 저장 반복 구간 재선택은 같은 시작점에서 다시 카운트한다.

일반 카운트는 현재 연습 템포의 4분음표 네 번이다. 음원 연주 전 구간으로 이동하는 경우는 [연주 전 계약](audio-practice.md#audio-practice--연주-전과-1마디-1박)의 선택 박자 한 마디분에 카운트를 겹치며 별도 대기를 추가하지 않는다.

<a id="playback-actions--저장-구간-시작과-삭제"></a>

### 저장 구간 시작과 삭제

| 조작 | 결과 |
| --- | --- |
| 저장 구간 짧게 누르기 — 재생 중 | 해당 구간 시작에서 카운트오프 설정에 따라 카운트한 뒤 재생한다. 이미 활성인 구간도 다시 시작한다. |
| 저장 구간 짧게 누르기 — 정지 중 | 해당 구간 시작으로 이동하고 정지 상태를 유지한다. 시작 마디에서 다시 눌러도 삭제하지 않는다. |
| 저장 구간 길게 누르기 | 공통 말풍선에 구간 명칭·설명과 삭제 버튼을 표시한다. |
| 길게 누른 손 떼기 | 말풍선을 유지한다. 클릭·재생·이동·삭제를 실행하지 않는다. |
| 말풍선의 삭제 누르기 | 해당 저장 구간만 삭제한다. 활성 구간이면 반복을 해제하고 슬롯을 시작 마디순으로 정리한다. |
| 바깥 누르기 또는 Escape | 삭제하지 않고 말풍선을 닫는다. |

별도 휴지통 대기 상태와 타일 안의 삭제 아이콘은 추가하지 않는다. 빈 `+ 구간` 등록은 유지한다. 일반 버튼의 도움말은 기존처럼 손을 떼면 닫힌다. 스크롤·드래그·포인터 취소·화면 이탈·대상 교체 시에는 남은 말풍선을 닫는다. 도움말 전용 모드에서는 실제 삭제 동작을 제공하지 않는다.

<a id="note-playback-highlight--음표-따라가기"></a>

## 음표 따라가기

결정 근거: [ADR-0006](../../decisions/0006-practice-navigation-and-overlays.md). 실행: [절차](../../how-to/verify.md#ui-review--화면악보재생-검수-절차).

- 설정: 설정 > 화면 > **음표 따라가기**. 기본값 켜짐, 앱 공통 설정으로 저장. 곡을 바꾸거나 앱을 다시 열어도 유지하며, 토글 변경은 현재 화면에 즉시 반영한다. 홈에서도 변경 가능하며 선호값은 PDF 선택 여부와 독립적으로 기억한다. 단, 현재 화면이 PDF/검수이면 토글은 꺼진 비활성 상태로 표시하고 사용 불가 이유와 전환 방법을 안내한다. MusicXML 연습 화면으로 돌아오면 저장된 선호값을 복구한다. 저장이 차단되면 현재 세션에서 유지한다.
- 목표: MusicXML/SVG의 음표는 실제 시작 박자에 흰 중심과 청록색 광륜으로 점등하고, 빔은 현재 진행 부분에 짧은 빛이 연속적으로 지나간다.
- 범위: 한 줄/두 줄 MusicXML 연습 화면. PDF 원본과 비교 검수의 원본 도형은 변경하지 않는다.
- 기준: 픽셀 위치를 박자로 추정하지 않고 OSMD 음표의 악보 내 timestamp를 사용한다. 동시 타격은 동시에 전환한다. 오선과 가사에는 음표 색을 적용하지 않는다.
- 표시: 음표 시작에 밝게 켜지고 약 140ms 뒤 꺼진다(최대 ¼박, 다음 음표 시작 전까지). 지나간 음표에 색을 누적하지 않는다. 빔도 짧은 이동 구간만 강조한다. 일시정지는 그 위치를 유지하고, 탐색/반복은 현재 재생 위치에서 다시 계산한다. 카운트오프 중에는 강조하지 않는다.
- 저장: 원본 MusicXML의 색/음가를 바꾸지 않고 SVG 렌더 캐시에 타이밍 메타데이터를 추가한다. 기존 캐시는 자동 갱신한다.
- 검증: 음표 시작 전/정확한 시작/동시음, 빔 중간/끝, 되감기, 캐시 갱신, 전체 테스트와 빌드, Safari 실제 SVG 확인.

세부 표시·탐색 정본은 [SVG 규칙](../score/rendering.md#svg-score-rules--9-음표-따라가기탐색화면-효과)을 따른다.

<a id="paused-score-scroll--정지된-두-줄-악보의-세로-탐색"></a>

## 정지된 두 줄 악보의 세로 탐색

결정 근거: [ADR-0006](../../decisions/0006-practice-navigation-and-overlays.md). 실행: [절차](../../how-to/verify.md#ui-review--화면악보재생-검수-절차).

정지 시 마디를 원래 DOM 순서의 4마디 행으로 배치해 상하로 읽는다. 세로 읽기 위치를 재생 시각·음원 위치와 혼합하지 않는다. 브라우저의 native 세로 스크롤을 사용하며 반복 frame이 스크롤을 되돌리지 않는다.

화면 안에서 키보드 선택을 옮길 때 스크롤을 유지한다. 밖으로 나가는 새 선택은 아래 방향이면 둘째 줄, 위 방향이면 첫째 줄에 둔다. 정지 방향키는 선택만 옮기고 실제 재생 시각·진행선·진행 음영은 유지한다. 재생 시작은 보이던 위/아래줄을 유지하되 활성 반복의 시작 마디가 다르면 구간 시작을 우선한다. 화면 밖 시작은 기존 위줄 기준을 사용한다.

두 줄의 좌우 드래그/휠 탐색은 사용하지 않는다. 한 줄의 좌우 탐색, 정지 상하 탐색·탭 선택, 보기·크기 변경의 정렬은 [SVG 규칙](../score/rendering.md#svg-score-rules--9-음표-따라가기탐색화면-효과)을 따른다. 행 높이·간격은 [같은 정본의 배치 계약](../score/rendering.md#svg-score-rules--8-연습-화면-전용-배치)을 사용한다.

## 반복 구간의 개수와 등록

반복 구간은 9개이며 시작 마디 순서로 표시한다. 가득 차면 가장 오래 등록한 구간을 교체한다. Enter 두 번·더블클릭 두 번 또는 빈 슬롯 선택 후 시작·끝 마디 클릭/터치로 등록하며 드래그는 사용하지 않는다. 포함 경계·선택/재생 위치·취소와 스크롤은 [공통 탐색 계약](../score/rendering.md#svg-score-rules--9-음표-따라가기탐색화면-효과)을 따른다. 숨긴 과거 10–12번 데이터의 보존은 [화면 규칙](ux.md)을 따른다.
