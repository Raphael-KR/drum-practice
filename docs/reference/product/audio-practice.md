## 음원 연습

결정 근거: [ADR-0026](../../decisions/0026-device-local-audio-analysis.md). 실행: [절차](../../how-to/review-score.md#practice-files--완성-악보와-연습-정보-파일-사용-절차).

<a id="audio-practice--가져오기와-곡-정보"></a>

### 가져오기와 곡 정보

[음원 불러오기]에서 기기의 MP3를 선택한다. 음원은 브라우저에 보관하며 서버에 업로드하지 않는다. `.drumscore`는 서버 악보 목록에서 받는 기존 방식을 유지한다. 불러온 음원은 ‘내 음원 목록’에 표시하며 ‘내 악보 목록’과 구분한다. 즐겨찾기는 종류와 관계없이 제목 없는 최상단에 한 번만 표시한다.

곡명·가수는 항목별로 태그를 우선하고 없는 항목만 명확한 파일명 구조(가수 - 곡명)에서 보완한다. 파일명으로 이미 있는 태그를 덮어쓰지 않는다. 구분이 불확실하면 파일명을 로컬 제목으로만 쓰며 가수를 추측하지 않는다. 자동 분석 뒤 필요한 경우 [조정]에서 보정한다. 유효한 태그 BPM(20~300)은 악보/기준 BPM으로 사용한다. 태그 BPM이 누락·유효하지 않으면 파일명에 명시된 `120 BPM`, `BPM 120` 등의 값을 사용하고, 둘 다 없으면 분석 BPM으로 대체한다. 트랙 번호·연도 등 단위 없는 숫자는 BPM으로 추측하지 않는다. 실제 박 시각·템포 변화는 음원 분석을 유지하고 원곡 버튼은 1배속으로 재생한다. 캐시가 있더라도 태그만 다시 읽어 이전 캐시에도 BPM을 반영하며 박 분석은 반복하지 않는다. 원본 파일의 태그나 음원 바이트를 수정하지 않는다.

<a id="audio-practice--박자와-템포"></a>

### 박자와 템포

대표 BPM 분석은 프로젝트의 구현을 사용하고 전체 박 시각 추적에는 `music-tempo`를 사용한다. 추종 지원 길이는 4초~30분이다. 박 시각이 없는 기존 음원은 지원 범위에서 보완 분석하며 박자 맞추기에서는 분석된 박 시각을 자동으로 사용하며 추종 설정을 따로 제공하지 않는다. 분석 결과는 추정치이며 모든 녹음의 정확도를 보장하지 않는다.

- 원곡 모드: 음원 1배속. 분석된 실제 박 시각을 따라 메트로놈을 예약하고, 상단에 현재 BPM을 소수점 한 자리로 표시한다.
- 연습 BPM 모드: 고정 메트로놈 간격에 맞게 음원의 박 간격을 변환한다. 변환 중에는 BPM 창 안에 **BPM 변환** 상태를 표시한다.
- 연습 BPM 창 오른쪽 위 [원곡]은1배속 복귀, 아래 [악보/기준 BPM 숫자 + BPM]은 그 BPM으로 고정 연습한다. 선택한 버튼만 파란색으로 표시한다.
- [조정]에서 연주 시작점을 보정한다. 분석된 박 시각이 있으면 자동 추종한다. 악보 BPM은 항상 수정할 수 있고, 마디당 박 수·기준 음표는 하나의 [박자] 선택으로 제공한다. 새 음원은4/4가 기본이며 기존에 저장한 박자는 유지한다. 박자 자동 판별은 구현하지 않았다. 박 시각이 없는 자료는 고정 BPM으로 박 간격을 만든다.

<a id="audio-practice--기기-내-분석정보-재사용"></a>

### 기기 내 분석정보 재사용

음원·곡명·가수·박자 분석은 현재 기기/브라우저에서만 처리하고 저장한다. 파일 전체 바이트 SHA-256로 같은 파일을 찾고 분석기 버전·길이·박 배열의 유효성을 검사한 뒤 재사용한다. 서버 조회·등록 요청은 하지 않는다.

IndexedDB `drum-practice`의 버전 4와 `audioAnalyses` 저장소를 사용한다. 기존 `songs`·개인 마커·구간·설정은 유지한다. 열어 둔 곡은 저장된 Song의 분석을 그대로 사용한다. 새 파일 가져오기의 자동 결과를 캐시한다. 같은 분석을 반복하는 수동 재분석 버튼은 제공하지 않는다. 개인 수동 보정과 1마디 기준은 곡의 설정으로 유지한다.

캐시가 없거나 분석기 버전·길이·박 배열이 맞지 않으면 기기에서 다시 분석한다. IndexedDB 이용이 막히거나 저장에 실패하면 캐시를 생략하며 서버로 우회하지 않는다. 음원 보관 자체의 실패는 기존 저장 오류 안내를 따른다. 재사용해도 디코딩·파형 생성은 필요하다.

다른 기기·브라우저·접속 주소에서는 처음 한 번 새로 분석한다. 브라우저 사이트 데이터를 삭제하면 보관한 음원과 캐시도 삭제된다. 서버의 `.drumscore` 악보·음원 묶음 다운로드는 그대로 유지한다.

서버 분석 API·익명 등록·요청 제한·검토/승인 UI·인증키·로컬 SQLite 저장소는 제공하지 않는다. 적용된 과거 마이그레이션과 삭제 이력은 보존하며 남은 DB 바인딩은 앱 런타임에서 사용하지 않는다.

<a id="audio-practice--연주-전과-1마디-1박"></a>

### 연주 전과 1마디 1박

`audioPractice.barOne`은 `{time, source: estimated|manual}`인 로컬 기준이다. 추종에서는 저장된 박 중 가장 가까운 박에 맞춘다. 기준 앞 음원은 **연주 전**으로 보존하며 이후를 1마디부터 센다. 탐색 숫자 0은 연주 전이고 전체 마디 수에는 포함하지 않는다.

자동 후보는 첫 60초의 지속 에너지 진입과 반복 강세로 추정한다. 말·카운트 소리의 의미를 인식하는 기능은 아니다. 불명확하면 미확정으로 남긴다. 파형을 선택하고 [여기를 첫박으로]로 직접 지정할 수 있다. 저장 전 취소가 가능하며 재분석 때도 수동 기준을 우선한다. 기준이 없는 구형 자료는 기존 4박 묶음·무강세 표시를 유지한다.

카운트오프를 켜고 연주 전을 재생하면 첫 마디 직전 **선택한 박자의 한 마디분**에 기존 스틱 소리를 음원과 겹친다. 박 수는 선택한 분자, 박 단위는 분모를 따르며 4/4에서는 네 번이다. 원곡에서는 실제 박 시각, 연습 BPM에서는 변환된 일정 간격을 사용한다. 앞부분이 짧거나 중간에서 시작하면 남은 박만 울리고 음원을 지연시키지 않는다. 1마디부터 일반 메트로놈으로 이어진다. 카운트오프를 끄면 연주 전에는 음원만 들린다. 연주 시작점 이후의 수동 시작은 기존 재생 전 카운트오프 정책을 따른다.

이 과정에서 원본 음원, 저장된 박 시각, 마커·구간의 원본 초 단위 위치는 유지한다. 1마디 기준은 서버에 공유하지 않는다.

<a id="audio-practice--검증과-한계"></a>

### 검증과 한계

분석 결과는 신호 기반 추정치다. 특정 곡의 사용자 확인·HTTP/API·자동 검사 성공을 다른 녹음의 정확도나 실제 기기 출력 지연·변속 음질·청취 완료로 확대하지 않는다. 현재 확인 범위는 [검증 현황](../../records/acceptance.md#acceptance--검증-현황)에 둔다.

<a id="audio-practice--연습-정보-파일-저장불러오기"></a>

### 연습 정보 파일 저장·불러오기

목록 설정 또는 음원 재생의 설정 > 백업에서 내 음원 목록 전체를 `drumpractice_backup_YYYYMMDD_HHmmss.json` 하나로 저장한다. 음원 바이트는 포함하지 않는다. 곡 정보·악보 BPM·박 시각·수동 보정·1마디 기준·마커·구간·슬롯·곡별 재생 설정을 포함한다. 이미 기기에 있는 음원은 크기와 SHA-256으로 연결하고, 없으면 원본 음원 여러 개를 선택한다. 모든 음원이 연결된 뒤 별도 항목으로 일괄 복원하며 기존 자료를 덮어쓰지 않는다. 복원한 박 정보는 자동 재분석 대상에서 제외한다. 상세 계약은 [연습 파일](../score/file-formats.md#practice-file--음원-연습-파일)을 따른다.

<a id="audio-practice--박자-맞추기-파형-조작"></a>

### 박자 맞추기 파형 조작

- 파형 아래에 음원 플레이어를 둔다. 별도의 파형 둘러보기 슬라이더는 제거한다.
- 재생 초반에는 진행바가 왼쪽에서 가운데까지 이동한다. 중간에는 진행바를 가운데에 두고 파형이 흐르며, 마지막 화면에서는 파형이 멈추고 진행바가 오른쪽 끝까지 이동한다. 플레이어 탐색도 같은 배치를 사용한다.
- 파형은 휠·트랙패드·가로 드래그로 둘러본다. 둘러보기만으로 재생 위치나 첫 박을 바꾸지 않는다. 진행바가 화면 밖이면 숨기고 가장자리에 붙여 표시하지 않는다. 플레이어 탐색·재생 재개 시 자동 추종으로 돌아간다. 파형의 단일 클릭·탭은 해당 위치를 미리듣기 위치로 선택한다.
- 시작점은 `[여기를 첫박으로] 첫박 [nn.nnn]초` 순으로 한 영역에 모은다. 자동 추정·직접 수정 상태는 표시하지 않으며 저장 데이터의 출처는 유지한다.
- 입력란 밖에서 ←·→로 파형 막대 한 칸 간격만큼 이동한다. 해당 위치에서 일시정지하고 스페이스바로 재생한다. 첫 박 보정값은 지정 버튼을 누르기 전까지 유지한다.

<a id="audio-practice--박자-맞추기-전용-메트로놈"></a>

#### 박자 맞추기 전용 메트로놈
- 목표: 파형의 박 위치와 실제 음원을 클릭 소리로 비교한다.
- 범위: `[여기를 첫박으로]` 줄 맨 오른쪽에 연습 화면과 같은 메트로놈 아이콘 버튼을 배치한다. 박자 맞추기 전용이며 기본 켜짐이다.
- 동작: 기존 재생기의 클릭·스틱 음색을 사용하고, 첫 박 전 선택한 박자의 한 마디분 카운트오프와 이후 메트로놈을 음원의 현재 시각에 맞춘다. 창을 처음 열면 가능한 카운트오프 시작 위치부터 듣는다. 중간 탐색 시 남은 박만 재생하며 음원을 지연시키지 않는다.
- 설정 경계: 저장 시 연습 화면의 메트로놈 켜짐 상태와 카운트오프 설정을 변경하지 않는다. 박자 맞추기의 아이콘 버튼 하나로 클릭·카운트오프를 함께 제어한다.
- 검증: 소스 시각·속도·첫 박 기준 갱신, 탐색·일시정지·체크 해제·닫기의 예약 취소, 저장 설정 보존을 집중 검사한다. 실제 Safari/iPad 출력 청취 결과는 자동 검사 결과와 구분한다.

<a id="audio-practice--박자-맞추기-재생-속도"></a>

#### 박자 맞추기 재생 속도
- 브라우저 기본 메뉴 대신 Safari 기본 디자인을 참고한 회색·흰색의 얇은 한 줄 재생바를 사용한다. 재생 속도는 0.1×·0.25×·0.5×·1×만 제공하고 미디어 통계 메뉴는 제공하지 않는다.
- 음원 요소의 재생 엔진은 유지하며 재생/정지, 위치 탐색과 시간, 속도 펼침 메뉴만 제공한다. 음원 볼륨은100%·음소거 해제로 시작하며 앱의 음량 조작을 두지 않는다. 음량은 OS 하드웨어 키로 조절한다. AirPlay와 15초 앞뒤 이동 버튼은 제공하지 않는다.
- 재생 속도는 박자 맞추기 창에만 적용하고 저장된 악보 BPM·연습 BPM은 바꾸지 않는다. 메트로놈은 음원 시각과 재생 속도에 동기화한다.
- 브라우저가 선택한 속도를 거부하면 오류를 표시하고 실제 적용된 속도로 선택 표시를 돌린다. 0.1× 실기기 출력·음질은 해당 기기에서 별도로 확인한다.

- 파형 배율: 박자 맞추기 파형의 한 화면 표시 범위는5초로 한다. 5초보다 짧은 음원은 전체 길이를 표시한다. 시작/중앙/끝 추종과 스크롤·좌우 한 칸 이동은 이 범위를 공유한다.
- 지정된 첫 박 시각을 파형 한 칸(표시 폭의1/160)과 같은 폭의 노란선으로 표시한다. `[여기를 첫박으로]` 또는 첫 박 숫자 입력으로만 기준이 바뀌며, 재생·탐색만으로 기준이 이동하지 않는다. 화면 범위 밖에서는 숨긴다. 분석 눈금 사이의 직접 지정 시각도 표시하며 빨간 진행선은 별개로 유지한다.
- 박자 맞추기 전용 소리: 음원100% 기준으로 카운트오프 스틱 증폭값을3배(+9.54dB), 메트로놈 설정값을100%로 사용한다. 연습 화면의 저장된 음악·메트로놈 설정은 변경하지 않는다. 카운트오프는 출력 제한기를 경유한다. 브라우저 음원 요소와 Web Audio의 최종 합산 출력 전체를 제한하는 것은 아니며 실기기 청취는 별도로 확인한다.
- 탭 템포 버튼과 별도 탭 입력은 제공하지 않는다. 낮은 분석 신뢰도나 구형 자료에는 박 시각이 없을 수 있으며, 기존 숫자 입력 경로는 유지한다.

<a id="audio-practice--악보-bpm박자-선택"></a>

#### 악보 BPM·박자 선택
- 악보 BPM과 박자는 박 분석 유무와 관계없이 수정한다. 박자는4/4·2/4·3/4·6/8·9/8·12/8·2/2·3/8·5/4·7/8을 제공하며 목록 외 기존 저장값도 보존한다.
- 분석된 각 박을 선택한 기준 음표 한 개로 해석하고 마디당 박 수만큼 묶는다. 예를 들어6/8은 관측 박6개를8분음표로 묶는다. 복합박자의 점4분음표 맥박이나 곡 중간의 변박을 자동 판별·보정하는 기능은 아니다.
- 원본 박 시각·첫 박 기준·음원·마커·구간은 보존한다. 마디 강박과 한 마디 카운트오프는 선택한 박자에 맞춘다. 원곡은1배속을 유지하고 연습 BPM 변환과 현재 BPM 표시는 선택한 음표 길이를 반영한다.
- 관련 테스트·타입 검사로 저장·재열기와 시각 보존을 확인한다. 실제 Safari/iPad 화면·청취 검증은 별도다.

- 화면 명칭: 목록 버튼·창 제목은 [조정]. 내부 패널은 [박자 맞추기]와 [음원 정보] 소제목으로 구분한다.

- 목록 도움말에 [내 음원 목록]과 [음원 저장과 백업] 항목을 제공한다. 조정 방법, 박자 자동 판별·변박 제한, 브라우저 내 저장·사이트 데이터 삭제 위험, 분석 재사용, 음원을 제외한 JSON 백업과 동일 원본 연결 복원을 설명한다. 조정 화면 하단에는 이 안내를 반복하지 않는다.

<a id="audio-practice--조정-제목줄-동작"></a>

#### 조정 제목줄 동작
- 하단 취소·저장 버튼을 제거하고 고정 제목줄 오른쪽에 저장 픽토그램, 공통 닫기(X) 순서로 배치한다. 닫기는 저장 없이 취소하며, 저장 아이콘은 기존 저장하고 연습 동작을 수행한다. 폼 밖의 저장 버튼도 해당 폼에 연결하여 필수 입력 검증을 유지한다.

<a id="audio-practice--bpm-입력과-프리셋"></a>

### BPM 입력과 프리셋

프리셋은 모달 입력값을 바꾼 뒤 직접 입력·악보 BPM·원곡 버튼과 같은 적용 경로를 사용한다. 변환 중에는 메인 BPM 표시를 유지하고 완료 후 갱신한다. 실패하면 모달 값을 실제 적용값으로 되돌린다.

프리셋은 원음원 BPM에 비율을 곱한 뒤 `Math.ceil`로 올린 정수다. 최저 프리셋은 50%를 올림한 값이며 최저 속도 0.5배 검증을 유지한다. 예를 들어 136.232 BPM의 50% 프리셋은 69 BPM이고 실제 비율은 69/136.232다. 측정 BPM과 악보 BPM의 의미는 [정본 계약](../score/musicxml.md#musicxml-canonical--musicxml-정본-계약)을 따른다.

원곡에서 상단의 현재 BPM은 최근 최대 4박 평균을 소수점 한 자리로 표시하고 매 박 갱신한다. 정지·선택 이동에서는 유지한다. 박 시각이 없는 자료와 연습 모드의 고정 표시는 각 시간 기준을 따른다. 같은 숫자를 표시해도 원곡 1배속과 지정 BPM 변환을 혼용하지 않는다.
