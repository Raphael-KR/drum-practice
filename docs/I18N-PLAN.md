# 전체 한국어 i18n 전환

- 목표: 사용자 표시 문구 전체를 한국어 정본과 호출 코드로 분리한다.
- 범위: 웹앱·재생 HTML·오류·동적 문구·접근성·날짜/숫자 형식·초기 HTML.
- 완료 조건: 대상 소스의 미등록 한글 UI 리터럴 0, 보존 데이터 예외 목록, 기존 한국어 출력 유지.
- 제외: 전체 영어 번역·언어 선택기, 사용자 제목/가사/교정 자료 변경.
- 검증: AST 잔여 검사, 변수/카탈로그 검사, 전체 테스트·빌드·HTML 제외 검사·Safari 화면 확인.

## 검증 결과 — 2026-09-21
- 한국어 정본 703개, AST 참조 792개, 미등록 한국어 UI 0개. 콘텐츠 리터럴 670곳은 명시적 예외로 보존.
- 전체 58개 테스트 파일·245개 테스트 통과. TypeScript 및 프로덕션 빌드 통과.
- 재생 HTML에는 사용 문구 184개만 포함. 관리/저장소/원본 렌더러 제외 검사 통과.
- Safari에서 웹앱의 설정·정보·실제 악보 및 로컬 HTML 설정의 한국어 출력 확인. 전체 영어 번역과 언어 선택기는 구현하지 않음.
- 증거: docs/experiments/i18n/tests.log, html-settings.png 및 html-settings.txt.
