# 원곡 측정 BPM 초기 적용 — 이력 안내

문서 역할: **이력 진입점**. 현재 적용할 계약은 [정본의 측정정보](../reference/score/musicxml.md#musicxml-canonical--musicxml-정본-계약), [현행 템포 표시](../reference/product/audio-practice.md#audio-practice--박자와-템포)에서 읽는다. 이전 시안·계산식·측정값·미확인은 [ADR-0015](../decisions/0015-score-tempo-and-recording-estimates.md)의 이관 원문으로 분리했다. 당시 HTML 저장·렌더러 버전·화면 수치·미배포 상태를 현행 지시로 읽지 않는다.
