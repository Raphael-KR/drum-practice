# SVG 압축 캐시 초기 설계 — 이력 안내

문서 역할: **이력 진입점**. 현재 적용할 계약은 [SVG 현행 규칙](../reference/score/rendering.md#svg-score-rules--10-저장캐시안전), [정본](../reference/score/musicxml.md#musicxml-canonical--musicxml-정본-계약)에서 읽는다. 이전 시안·계산식·측정값·미확인은 [ADR-0004](../decisions/0004-browser-native-score-rendering.md)의 이관 원문으로 분리했다. 당시 HTML 저장·렌더러 버전·화면 수치·미배포 상태를 현행 지시로 읽지 않는다.
