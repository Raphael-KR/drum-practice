# MusicXML 초기 지원 계획 — 이력 안내

문서 역할: **이력 진입점**. 현재 적용할 계약은 [현행 입력 계약](../reference/score/musicxml.md#musicxml-input--musicxml-입력-계약), [정본](../reference/score/musicxml.md#musicxml-canonical--musicxml-정본-계약), [공통 조판](../reference/score/rendering.md#browser-musicxml-rendering--브라우저-공통-musicxml-조판-계약)에서 읽는다. 이전 시안·계산식·측정값·미확인은 [ADR-0004](../decisions/0004-browser-native-score-rendering.md)의 이관 원문으로 분리했다. 당시 HTML 저장·렌더러 버전·화면 수치·미배포 상태를 현행 지시로 읽지 않는다.
