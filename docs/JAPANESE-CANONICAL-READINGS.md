## 반영 내역과 싱크 경계

영어는 12개 단어 표시로 묶고 첫 음절 시작/마지막 음절 종료를 유지했다. 일본어 발음은 한글로, 영어는 영어로 표시한다. 최종 513개 표시 단위다.

- 21개 기존 표시 단위를 교정: 세/모 각 1개, 장음 기호 보완 9개, 촉음 표현 정리 10개. 기존 534개 음절의 시작 시각은 모두 유지.
- 今日出ていくわ의 마지막 와 1개 복원: 기본 예제는 40.820초의 구판 추정 시각을 복원했다. confirmed=false이며 의심 번호 205로 추적한다. 직전 쿠의 표시 종료만 와 시작으로 조정했다.
- 짧은 Apple STT는 이 와를 私와 분리하지 못했다. 새로 청취 확정했다고 간주하지 않는다.
- 사용자 편집으로 복원 시각이 이웃과 충돌하면 기존 시각을 보존하고 쿠와를 한 표시 단위에 묶는다. 새로운 시각을 임의로 만들지 않는다.
- 기존 청취 앵커 001/002/15마디 및 구절 앵커 003 보존. 새 읽기를 적용하기 전 판본은 lyricArchive에 보관한다.
- 空는 카라로 유지: 제공 한글과 기존 STT의 か/ら가 근거. 일본어 한자만으로 소라로 되돌리지 않는다. 灯는 제공 발음에 맞춰 히로 유지. 영어는 2026-09-19 사용자 정정에 따라 always bright로 표기한다.
- 전체 싱크 재계산이나 전체 청취 검증은 이번 범위가 아니다. 기존 의심 번호 069–204는 유지하되 바뀐 한글 표기를 갱신했다.
