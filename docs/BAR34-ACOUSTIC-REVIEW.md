# 34마디 음원 기반 재검사

사용자 요청에 따라 34마디 스베테오우시낫만 적용. 직접 청취 판정이 아니라 Apple STT, 원음/분리 보컬 강제 정렬 및 신호 변화량을 비교했다. 사용자 좌표 스=tick2, 테=tick4, 우=tick8을 우선 고정했다.

| 음절 | 적용 위치 | 근거 |
|---|---|---|
| 스 | 1박 +½ | 사용자 확인, STT는 문맥에 따라84.72/84.90초로 변동 |
| 베 | 1박 +¾ | 원음85.10, 보컬85.08, 보컬 변화점85.12초; 추정 |
| 테 | 2박 | 사용자 확인, Apple STT 두 구간 모두85.20초 |
| 오 | 2박 +½ | 기존 유지, STT85.56, 정렬85.44~85.52초 |
| 우 | 3박 | 사용자 확인, STT 두 구간 모두85.92초 |
| 시 | 3박 +½ | 원음86.22~86.24, 보컬86.04, 변화점86.215초; 불확실 |
| 낫 | 3박 +¾ | 원음86.32, 보컬86.34; 추정 |

시의 원음/보컬 차이 때문에 정답 확정으로 표시하지 않는다. 파형 변화점은 악기·모음 에너지 변화도 포함하므로 단독 발음 경계 증거가 아니다. STT ‘全’은 스·베, ‘失’은 우·시·나에 걸친 표기이며 글자별 타임스탬프를 음절로 균등 분할하지 않았다. AFM 3 Core Advanced 비교4건은 모두 uncertain으로 시간 결정에 사용하지 않았다.

Apple STT 총 약0.56초(컴파일 제외), 2개 문맥. 강제 정렬은 원음/보컬 각2개 시작 문맥. 스의 DTW84.66초는 이전 소리를 흡수하므로 사용자 위치로 대체했다. 변경 전 데이터·실험 출력은 docs/experiments/bar34-review/에 보존. 베·시·낫은 confirmed=false, 사용자 확인으로 위장하지 않는다. 다른 가사 데이터는 유지한다.
