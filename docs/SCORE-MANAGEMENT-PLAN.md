# 승인 목업 적용

- 목표: 설정 > 악보를 편집·파일로 통합하고 손실 없이 관리한다.
- 범위: 웹앱 UI, MusicXML 가사 텍스트, 편집 초안·최근 10 저장본, 통합 파일 내보내기, 전체 보관함 백업, 단일 곡 재생 HTML.
- 완료 조건: 3탭 공통 편집·원본 악보/전체 가사 보기·파일 선택 내보내기·접힌 백업 관리 동선 작동. 편집 중단/되돌리기/복원으로 자료 보존.
- 제외: 보컬 PDF 추출, 다국어 병렬 가사, 온라인 가사 검색, 음표 표기 규칙 변경, 원격 게시.
- 검증: 순수 로직과 저장소 회귀, 통합 UI, 전체 테스트/빌드, Safari 실제 화면·격리 QA 곡. 실물 iPad는 별도 검증.

## 결정
- 가사 칩은 가사 데이터 보유 여부. 일반 텍스트는 canonical MusicXML의 miscellaneous-field에 줄/섹션과 함께 저장하며 가짜 음절 위치를 생성하지 않는다. 리듬 가사와 전체 문서를 구분한다.
- 칩: MusicXML 파랑 / PDF 빨강 / 가사 초록 / 음원 보라. 없음은 회색+없음.
- 설정 > 악보: 곡 요약, 편집, 파일. 편집은 악보/가사/곡 정보 탭. 원본 악보는 악보 탭에 둔다.
- 파일: MusicXML, 원본 PDF 악보, 가사 업로드, 음원, 내보내기. 마지막 행도 같은 간격, 화살표 없음.
- HTML은 단일 곡 재생용: 보관함·악보 관리 제거, 편집 이력/초안 제외.
- 전체 곡 백업/복원은 내 악보 목록 하단의 접힌 ‘백업 관리’. 복원 전 전체 검증, 동일 ID 교체 확인, 기존의 다른 곡은 보존. 브라우저 공통 연습 설정도 포함.
- 편집 초안은 확정본과 별도 보존. 편집 종료는 저장/버리기/계속. 입력 중인 폼도 초안에 포함. 저장 이력 최근 10개, 복원 전 현재 상태 보존.
