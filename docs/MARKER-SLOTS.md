# 마디 마커 슬롯

2026-09-20 사용자 확정: 3개 슬롯, 네 번째 다른 마디부터 가장 오래 생성한 마커 교체.

- 연주 컨트롤의 마커 버튼과 M 키는 현재 마디 처음에 바로 마킹한다. 재생을 멈추거나 관리 창을 열지 않는다.
- 같은 마디를 다시 마킹하면 중복을 만들지 않고 최신 생성 순서로 갱신한다.
- 저장 배열은 생성 순서, 화면 슬롯은 악보 순서. 화면 정렬은 교체 순서를 바꾸지 않는다.
- 빈 슬롯도 표시한다. 슬롯에는 마디 번호를 표시하고 누르면 그 마디 처음으로 이동한다.
- 조정 버튼은 하단 맨 왼쪽, 마커 3개는 같은 영역 오른쪽. 좁은 화면에서 반복 프리셋은 왼쪽 안에서 줄바꿈한다.
- 한 줄/두 줄 PDF·SVG 악보와 검수 화면 양쪽의 마디 제목에 깃발을 표시한다. 원본 음악 표기를 변경하지 않는 연습용 표시다.
- 진행률 숫자를 탭하면 기존 이름 변경/삭제 관리 창에 접근할 수 있다.
- 이전 버전에서 마커가 3개보다 많으면 마지막 3개를 슬롯에 표시하며 로딩만으로 기존 데이터를 삭제하지 않는다. 새 마킹 시 최신 3개로 정리된다.

## 검증

- 49파일 202테스트 및 TypeScript/portable/Vite 빌드 통과.
- 회귀 검사: 빈 슬롯, 마디 처음 정렬, 생성 순서 교체, 표시 정렬, 같은 마디 갱신, JSON 저장/복원, 즉시 마킹(관리 창 미열림), 조정 맨 왼쪽, 악보 표시.
- Safari 1133×744 / 744×1133: 복제한 QA 곡에서 검증. 9마디 마킹→깃발/슬롯 즉시 표시, 최신 슬롯 10/11/12 정렬, 9마디 표시 제거, 10슬롯 선택→23.367초(10마디 처음) 이동.
- 검수 PDF/SVG 양쪽 깃발 및 가로/세로 하단 배치 스크린샷 직접 확인. 세로 repeat-controls 가로 넘침 없음.
- 로컬 비추적 증거: docs/experiments/marker-slots-landscape.png, marker-slots-portrait.png, marker-slots-compare.png.
- 기존 곡을 변경하지 않고 별도 ID의 QA 복제 곡을 사용했다. 실물 iPad 터치 검증은 아님.
