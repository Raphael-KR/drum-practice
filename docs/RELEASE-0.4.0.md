# 0.4.0 — 2026-09-21

## 변경
- 재생 전용 SVG+PDF 합본 HTML 및 웹앱 동작 공유, 두 줄 가로 이동 제거, 전체화면·새로고침과 화면 너비 대응.
- UI 공통 명명·i18n·접근성 정의, 재생바 그룹, 도움말 진입 버튼.
- 곡 정보·악보 편집·가사 탭 재구성, 상단 저장 통합, 숫자 드래그·휠, 원본 곡 메타데이터 복구.
- 악보-음원 연결에 파일 교체·내보내기 통합. 전체 다시 맞추기는 실행 전 확인/취소.
- 가사 기본 전체 표시, 화면 이동과 목록 필터 공간 분리.

## 유보
- 영어 전체 번역, 맥락형 도움말 콘텐츠 및 엄격한 전체 QA 잔여 항목은 1.0 직전 검토.
- 악보 제작 프로그램 분리는 향후 계획. docs/EDITOR-SEPARATION-ROADMAP.md 참조.
- 실제 iPad Edge 오프라인 실행 검증은 기존 사용자 검수와 구분하며 이번 릴리스에서 새로 완료했다고 주장하지 않는다.
