# 음원 연습 — 현재 동작

기준: 공통 0.7.6 / 2026-10-13. 검증은 [검증 현황](acceptance.md), 화면 문구·배치는 [UX 원칙](UX-PRINCIPLES.md)을 따른다.

## 가져오기와 곡 정보

[음원 불러오기]에서 기기의 MP3를 선택한다. 음원은 브라우저에 보관하며 서버에 업로드하지 않는다. `.drumscore`는 서버 악보 목록에서 받는 기존 방식을 유지한다.

곡명·가수는 태그를 우선 읽고 명확한 파일명 구조를 보조로 사용한다. 구분이 불확실하면 파일명을 로컬 제목으로만 쓰며 가수를 추측하지 않는다. 자동 분석 뒤 필요한 경우 [박자 맞추기]에서 보정한다. 원본 파일의 태그나 음원 바이트를 수정하지 않는다.

## 박자와 템포

대표 BPM 분석은 프로젝트의 구현을 사용하고 전체 박 시각 추적에는 `music-tempo`를 사용한다. 추종 지원 길이는 4초~30분이다. 박 시각이 없는 기존 음원은 지원 범위에서 보완 분석하며 사용자가 추종을 끈 상태는 존중한다. 분석 결과는 추정치이며 모든 녹음의 정확도를 보장하지 않는다.

- 원곡 모드: 음원 1배속. 분석된 실제 박 시각을 따라 메트로놈을 예약하고, 상단에 현재 BPM을 소수점 한 자리로 표시한다.
- 연습 BPM 모드: 고정 메트로놈 간격에 맞게 음원의 박 간격을 변환한다. 변환 중에는 BPM 창 안에 **BPM 변환** 상태를 표시한다.
- 연습 BPM 창의 원곡 버튼: 표시는 악보/기준 BPM이고 동작은 1배속 복귀다.
- 자동 추종이 맞지 않으면 [박자 맞추기]에서 추종을 끄고 고정 BPM·첫 박을 보정할 수 있다.

## 같은 파일의 분석정보 재사용

키는 파일 전체 바이트의 SHA-256와 분석기 버전이다. 현재 계약은 [audio-analysis-contract.ts](../src/audio-analysis-contract.ts)의 **v4**, API는 `/api/audio-analysis/v4/<sha256>`이다.

| 저장 위치 | 내용 |
| --- | --- |
| 기기 브라우저 | 음원, 파형, 원본 파일명, 개인 마커·구간·설정, 수동 보정, 1마디 기준 |
| 서버 | 해시, 분석기 버전, 자동 곡명·가수, 길이, BPM, 첫 박, 박자표, 신뢰도, 선택적 전체 박 시각 |

JSON은 최대 256KiB, 박 배열은 최대 20,000개다. 허용 필드·범위·단조 증가·길이를 검사한다. v4의 박 시각이 없는 기존 행은 유효한 자동 박 시각으로 보완할 수 있다. 이미 박 시각이 있으면 최초 값을 유지하며 개인 수동 값을 공용 캐시에 덮어쓰지 않는다.

조회 제한은 4초, 저장 제한은 8초다. 일시 오류만 1회 재시도하고 실패·404·계약 불일치 시 기기 분석으로 진행한다. 서버 저장 실패는 연습을 막지 않는다. 캐시가 있어도 해시 계산·디코딩·파형 생성은 기기에서 필요하다.

개발 서버는 5173의 Vite middleware와 `data/runtime/audio-analysis.sqlite`를 사용한다. 공개 사이트는 같은 계약의 Worker/D1을 사용한다. 로컬 DB를 공개 DB로 자동 복제하지 않는다. 서버 값은 자동 추정 결과이며 검수된 정답 저장소가 아니다.

## 연주 전과 1마디 1박

`audioPractice.barOne`은 `{time, source: estimated|manual}`인 로컬 기준이다. 추종에서는 저장된 박 중 가장 가까운 박에 맞춘다. 기준 앞 음원은 **연주 전**으로 보존하며 이후를 1마디부터 센다. 탐색 숫자 0은 연주 전이고 전체 마디 수에는 포함하지 않는다.

자동 후보는 첫 60초의 지속 에너지 진입과 반복 강세로 추정한다. 말·카운트 소리의 의미를 인식하는 기능은 아니다. 불명확하면 미확정으로 남긴다. 파형을 선택하고 [여기를 1마디 1박으로]로 직접 지정할 수 있다. 저장 전 취소가 가능하며 재분석 때도 수동 기준을 우선한다. 기준이 없는 구형 자료는 기존 4박 묶음·무강세 표시를 유지한다.

카운트오프를 켜고 연주 전을 재생하면 마지막 네 박에 기존 스틱 소리를 음원과 겹친다. 원곡에서는 실제 박 시각, 연습 BPM에서는 변환된 일정 간격을 사용한다. 앞부분이 짧거나 중간에서 시작하면 남은 박만 울리고 음원을 지연시키지 않는다. 1마디부터 일반 메트로놈으로 이어진다. 카운트오프를 끄면 연주 전에는 음원만 들린다. 연주 시작점 이후의 수동 시작은 기존 재생 전 카운트오프 정책을 따른다.

이 과정에서 원본 음원, 저장된 박 시각, 마커·구간의 원본 초 단위 위치는 유지한다. 1마디 기준은 서버에 공유하지 않는다.

## 검증과 한계

0.7.6의 회귀·Safari 예약 시각·공개 API 결과는 [검증 현황](acceptance.md)과 [개발 기록](../history.md)에 있다. 붉은 노을의 연주 시작 후보는 사용자 청취로 확인했지만 다른 라이브 전체의 정확도를 뜻하지 않는다. 실기기 출력 지연과 변속 음질은 별도로 청취해야 한다.
