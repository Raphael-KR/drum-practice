# 가사 싱크 청취 피드백 누적

사용자가 “모은 것 반영해줘”라고 요청할 때 일괄 적용한다. 위치 전달만으로 앱·가사 데이터를 수정하지 않는다. 사용자가 고유번호와 함께 보내는 위치는 해당 행의 첫 번째 의심 음절이 시작하는 순간이다. 별도 지정이 없으면 이 규칙을 적용하며 음절을 다시 묻지 않는다. 001은 이미 반영했다.

| 고유 번호 | 대상 음절 | 전달 위치 | 음원 시각 | 마디 시작 후 | 박 위치 (1부터) | 상태 |
|---|---|---|---|---|---|---|
| 002 | 사 (첫 번째 의심 음절) | 10마디 · 2박 + ¼ (4/4) | 24.268초 | 0.901초 | 2.412 | 사용자 청취 확인 · 일괄 반영 대기 |
| 003 | 소 (첫 번째 의심 음절) | 11마디 · 2박 + ¼ (4/4) | 26.872초 | 0.952초 | 2.491 | 사용자 청취 확인 · 일괄 반영 대기 |

## 002 전달 원문

```text
Real Paradis - 바람과 언덕의 발라드
10마디 · 2박 + ¼ (4/4)
음원 24.268초 · 마디 시작 후 0.901초 · 박 위치 2.412 (1부터)
표시는 현재 ¼박 구간 기준입니다.
```

정정 이력: 002의 이전 전달 시각 24.347초는 철회하고, 최신 전달 시각 24.268초로 대체했다. 이후 사용자가 ‘사’ 시작임을 확인했다.
