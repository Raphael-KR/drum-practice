# 가사 싱크 청취 피드백 누적

사용자가 “모은 것 반영해줘”라고 요청할 때 일괄 적용한다. 위치 전달만으로 앱·가사 데이터를 수정하지 않는다. 여러 음절이 있는 행은 대상 음절을 확인한 뒤 적용한다. 001은 이미 반영했다.

| 고유 번호 | 대상 음절 | 전달 위치 | 음원 시각 | 마디 시작 후 | 박 위치 (1부터) | 상태 |
|---|---|---|---|---|---|---|
| 002 | 미지정 (목록: 사 · 카) | 10마디 · 2박 + ¼ (4/4) | 24.268초 | 0.901초 | 2.412 | 기록 완료 · 대상 음절 확인 필요 · 앱 미반영 |

## 002 전달 원문

```text
Real Paradis - 바람과 언덕의 발라드
10마디 · 2박 + ¼ (4/4)
음원 24.268초 · 마디 시작 후 0.901초 · 박 위치 2.412 (1부터)
표시는 현재 ¼박 구간 기준입니다.
```

정정 이력: 002의 이전 전달 시각 24.347초는 철회하고, 최신 전달 시각 24.268초로 대체했다. 대상 음절은 아직 미지정이다.
