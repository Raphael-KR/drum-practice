# 가사 싱크 청취 피드백 누적

현재 대상: [교정 목록](LYRIC-SYNC-SUSPECTS.md)의 굵은 음절 또는 영어 단어 시작. 통합한 기존번호도 같은 항목으로 접수한다.

사용자가 “모은 것 반영해줘”라고 요청할 때 일괄 적용한다. 위치 전달만으로 앱·가사 데이터를 수정하지 않는다. 사용자가 고유번호와 함께 보내는 위치는 해당 행의 첫 번째 의심 음절이 시작하는 순간이다. 별도 지정이 없으면 이 규칙을 적용하며 음절을 다시 묻지 않는다. 001은 이미 반영했다. 이후 전체 가사 교체·재싱크 요청에 따라 002·003도 v2에 반영했다. 앞으로 들어오는 개별 위치는 계속 누적한다.

## 002 전달 원문

```text
Real Paradis - 바람과 언덕의 발라드
10마디 · 2박 + ¼ (4/4)
음원 24.268초 · 마디 시작 후 0.901초 · 박 위치 2.412 (1부터)
표시는 현재 ¼박 구간 기준입니다.
```

정정 이력: 002의 이전 전달 시각 24.347초는 철회하고, 최신 전달 시각 24.268초로 대체했다. 이후 사용자가 ‘사’ 시작임을 확인했다.

## 003 전달 원문

## 069 전달 원문 (접수 F001, 이후 대상 확정)

```text
Real Paradis - 바람과 언덕의 발라드
9마디 · 3박 · 5번째 8분음표 구간 (4/4)
음원 22.095초 · 마디 시작 후 1.280초 · 박 위치 3.006 (1부터)
표시는 현재 ¼박 구간 기준입니다. - な(나)
```

9마디 ‘나다라카나’에는 나가 두 번 있으므로 시간 근접성만으로 대상을 결정하지 않았다. 첫 나는 교정 번호 069(v2-l1), 끝 나는 v2-l5이며 기존 목록에 별도 번호가 없다. F001은 접수 식별자이며 교정 목록의 001과 다르다.

후속 확인: 사용자가 “첫번째 나 이다”라고 명시했다. F001은 069번(v2-l1)에 대응하며 시작 시각 22.095초로 확정 기록했다. 앱은 일괄 반영 요청까지 변경하지 않는다.

## 070 전달 원문

```text
Real Paradis - 바람과 언덕의 발라드
10마디 · 1박 · 1번째 8분음표 구간 (4/4)
음원 23.367초 · 마디 시작 후 0.000초 · 박 위치 1.000 (1부터)
표시는 현재 ¼박 구간 기준입니다. - 070
```

현재 앱 추정 22.700초에서 사용자 전달 23.367초로 정정할 위치를 기록했다. 실제 적용 시 다음 나(v2-l5, 현재 23.138초)와 순서가 충돌하므로 주변 음절 순서를 함께 재검토한다. 지금은 주변 시각을 추정 변경하지 않는다.
