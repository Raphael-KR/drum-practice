# 교정 목록 재정리 전 근거 (069–205)

v2에서 남긴 **136개 검토 항목**의 번호를 유지하고 복원한 와를 **205번**으로 추가했다. 영어는 단어로 묶어 표시하므로 여러 기존 번호가 같은 단어를 가리킬 수 있다. 최종 표시 단위는 513개다. 오류 확정 목록이나 정확도 점수가 아니다. 목록 밖 항목도 청취 검증을 마쳤다는 뜻은 아니다.

기존 001–068은 [구판 목록](LYRIC-SYNC-SUSPECTS-V1.md)에 보존한다. 새 목록은 **069부터** 부여해 번호를 재사용하지 않는다. 전달하는 시각은 해당 번호의 첫 음절 시작이다. 위치 피드백은 누적 후 요청 시 반영한다.
