## 결론

요청된 전 음절 청취 검증은 수행하지 못했다. 현재 도구에는 원음을 모델의 청각 입력으로 전달해 발음 시작을 직접 판정할 경로가 없다. Apple STT/Whisper의 숫자와 텍스트는 직접 청취 정답이 아니다. 청취로 확인된 정답 시각이0개이므로 현재 정확도, 평균 절대 오차, 보정 전후 정확도 개선율은 산출할 수 없다.

입력 문맥 의존성이 큰 구간은8·17·25·33·40·49·56~57·73·85·99마디 등에 있다. 상당수가 구간의 처음/끝에 위치한다. 이것은 모델의 경계 처리 문제 후보이며 실제 악보 시각이 틀렸다고 단정할 수 없다.

## 실제 정확도 평가에 필요한 자료

556개 음절 각각의 독립적인 청취 시작시각, 확인자, 애매한 발음의 허용 구간이 필요하다. 이후 동일한 정답에 대해 보정 전/후 평균·중앙·95백분위 절대오차, ±100ms 내 비율과 악화된 음절 수를 비교할 수 있다. 이 허용범위는 향후 평가 기준 예시이며 실제 정확도 수치가 아니다.

로컬 `docs/experiments/syllable-sync/listening-review.csv`에556개 행과 수정 전/후 시각을 준비했다. 청취 시각·확인자 칸은 빈 상태로 남겼다. 측정하지 않은 값을 채우지 않았다. 정량 감사 결과는 같은 폴더의 accuracy-limit-review.json에 있다. 이 검토에서는 앱 시각을 추가 변경하거나 되돌리지 않았다.
