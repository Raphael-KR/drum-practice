# 웹앱·재생 HTML 터치 동작 일치 검수

## 목표와 기준

- 목표: 웹앱과 재생 HTML에서 같은 악보 탐색 동작을 제공한다.
- 범위: 정지 상태의 한 줄 네이티브 가로 스크롤, 두 줄 가로 드래그 및 세로 스크롤. SVG/PDF 모두 적용.
- 완료 조건: 네이티브 터치로 악보가 손가락 방향을 따라 이동하고, 두 줄 탐색은 정지된 재생 위치를 바꾸지 않는다. 탭 선택·재생·정지와 마커/반복 회귀가 없어야 한다.
- 악보 데이터, 음원, 표기 매핑, 사용자 보관함은 유지한다. 커밋/배포는 별도다.
- 검증: 통합·전체 테스트, TypeScript/Vite 빌드, Device Hub iPad mini Safari 네이티브 입력 및 캡처.

## 반영 내용

웹앱 `src/main.ts`·`src/style.css`에도 HTML의 정지 탐색 동작을 반영했다. 공통 입력기는 `src/score-gestures.ts`를 사용한다. 한 줄은 브라우저 스크롤로 움직이며 진행선과 위치 표시는 화면에 고정한다. 두 줄은 연속 마디를 양쪽에 준비하고 손가락 이동량만큼 화면을 옮긴다. 세로 스크롤과 탭 선택은 재생 위치/뷰포트 유지 원칙을 따른다.

빈 마디 자리에는 실제 마커가 없으므로 마커 동기화는 `data-index`가 있는 실제 마디만 처리한다. 형식/스타일 전환 시 이전 네이티브 스크롤 상태를 지운다.

## 실패와 재검수

- 최초 통합 검사에서 빈 자리의 마커 요소에 접근한 오류가 발생했다. 실제 마디만 동기화하도록 수정했다.
- 이전 테스트는 두 줄 가로 휠이 재생 시간을 바꾸기를 기대했다. 사용자 최신 결정에 맞춰 시간 유지와 화면 이동을 함께 검증하도록 변경했다.
- jsdom은 실제 너비가 0이므로 가로 이동 검증에 1000px 뷰포트를 명시했다. 25개 UI 통합 테스트 통과.
- 네이티브 두 줄 검수에서 악보가 비어 보였다. 기존 `.two-rows .measure`의 강제 자동 너비가 새 탐색 행의 마디 너비까지 덮었다. 자동 너비 규칙을 재생용 그리드의 직접 자식으로 한정했다.
- 전체 병렬 검사에서 기존 bundled-score 검사가 5초 제한을 초과했다. 작업자 수를 4개로 제한하여 전체 56파일·236테스트를 재실행했고 모두 통과했다. 제한 시간을 늘리거나 검사를 제외하지 않았다.

## 기기와 한계

Device Hub, iOS27, iPad mini(A17 Pro) 시뮬레이터. 웹앱은 `http://127.0.0.1:5173/`, HTML은 `http://127.0.0.1:5174/combined-touch.html`. DOM 이벤트 흉내가 아닌 Xcode 네이티브 터치 입력을 사용한다. 실기기 Edge의 오프라인 검증과는 별개다.

## 실행 결과

- 전체 자동 테스트: 56파일, 236개 통과 (`app-touch-tests-final.log`). TypeScript 및 Vite 빌드 통과 (`app-touch-build-final.log`).
- 웹앱 한 줄: 네이티브 좌우 입력으로 이동, 고정 진행선 확인.
- 웹앱 두 줄: SVG/PDF 모두 좌우 300px 스와이프에 같은 방향/거리로 이동, 정지 시간 유지. 세로 입력으로 다음 행 탐색 확인.
- 한 번 탭: 23마디 선택 후 기존 스크롤 위치 유지. 두 번 탭: 카운트오프 진입 확인.
- 캡처 직접 검토: [PDF 두 줄 이동](experiments/html-playback/app-touch-v2-pdf-rows-left.png), [SVG 마디 선택](experiments/html-playback/app-touch-v2-select.png).
- 실제 재생: 23마디 선택 후 카운트오프가 끝나면 상단 21–24마디, 하단 25–28마디로 배치되어 23마디가 상단에 놓인다. 한 번 탭 정지 확인. [실제 재생 캡처](experiments/html-playback/app-touch-v2-playing.png).
- 기존 합본 HTML: 한 줄 네이티브 스와이프 후 진행선 고정, 두 줄 300px 이동 후 정지 위치 유지 확인. [HTML 스크롤 캡처](experiments/html-playback/app-touch-html-left.png).
- 현재 로컬 웹앱(5173)에서 변경된 CSS가 제공되는 것을 HTTP로 재확인했다. 커밋·원격 배포·버전 변경은 이번 작업에서 실행하지 않았다.

네이티브 입력별 상세 증거: [실행 기록](experiments/html-playback/WEBAPP-NATIVE-TOUCH-QA-2026-09-21.md). 검수 세션 종료 응답 `Session stopped` 확인.
