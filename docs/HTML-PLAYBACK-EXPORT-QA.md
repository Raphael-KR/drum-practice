## 채점 규칙

## 제품 검수 판정

계획 100점은 구현 착수 준비를 뜻한다. 제품 검수는 계획의 R01–R10을 별도로 각각 10점으로 평가한다. 각 행의 모든 하위 시나리오가 실제 증거로 통과해야 점수를 준다. 미실행/플랫폼 차단은 0점이다. 제품 100점 전에는 완료라고 보고하지 않는다. 계획을 수정해 기존 실패 시나리오를 삭제하거나 필수 기능을 축소하는 것은 허용하지 않는다.
