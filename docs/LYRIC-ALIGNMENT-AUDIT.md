# 가사 정렬 검증 상태 — 2026-09-19

## 확인된 방법과 한계

기존 자료는 보컬 분리 음원에 MLX Whisper 강제 정렬을 수행한 뒤, 일본어 토큰을 한글 발음으로 대응시켰다. 여러 한글 음절이 한 토큰에 대응하면 그 토큰 구간을 균등 분배했다. 일부 문장 시작은 별도 파형 기준 보정, 후렴 시작은 공통 리듬 틀을 적용했다. 전 음절을 사람이 듣고 확인한 결과가 아니다.

- 전체 표시 음절: 556개
- 여러 음절을 포함한 토큰: 140개 / 그 안의 음절 306개
- 토큰 확률0.5미만: 56개 (이 확률은 시간 정확도의 확률이 아님)
- 전 음절 청취 검증: 미수행. 현재 세션에는 직접 청취·발음 경계를 판정할 오디오 입력 도구가 없다.
- 이번 조사에서 실제 앱 가사 시각은 변경하지 않았다. 기존 confirmed=false 유지.

## 후속 완료 기준

각 음절의 발음 시작을 원음 또는 보컬 분리 음원으로 확인하고 시작시각·확인자·방법을 기록해야 한다. 자동 재정렬만으로 confirmed=true를 설정하지 않는다. 보정 이후에는 원곡 속도와 느린 속도에서 음악-가사-진행선의 일치를 별도로 검증한다.

상세 자동검토 목록은 로컬 docs/experiments/lyric-audit/tokens.json. 원천은 기존 aligned_vocals.json과 full_lyrics.py를 조사했으며, 외부 서비스로 음원을 전송하지 않았다.
