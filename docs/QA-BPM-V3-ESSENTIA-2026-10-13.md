# 개선 분석기 v3와 Essentia 재비교

- 목표: 개선한 현재 분석기를 Essentia와 동일 조건에서 다시 비교한다.
- 범위: 같은 로컬 MP3 16곡, 첫 90초·44.1kHz·40~240BPM, 각 3회 교대 실행.
- 완료 조건: BPM·박 위치·분석 시간의 새 실측과 기존 기준 대비 결과를 기록한다.
- 제외: 앱 코드 추가 변경, 음원 업로드·수정, 캐시 쓰기, 커밋·푸시·발행.
- 검증: 96회 실행 결과·원본 해시·소스 해시 확인, 동일 척도의 기존 기준 비교.

## 결과

개선 분석기의 120→80 오류는 해소됐고, 이번 16곡 재측정에서 두 분석기의 BPM은 15곡에서 서로 1% 이내였다. 남은 붉은 노을 차이는 악보 기준과 녹음의 동일성 확인이 필요하다. BPM 추정 용도에서는 현재 구현을 유지할 근거가 충분하다. Essentia의 장점은 박 시각 목록이며, 마디 첫 박을 바로 알려주는 것은 아니다.

| 항목 | 개선 현재 분석기 v3 | Essentia.js |
|---|---:|---:|
| 기준 9곡 ±2% 일치 | 8/9 | 9/9 |
| 기준 9곡 ±1% 일치 | 8/9 | 8/9 |
| 붉은 노을 제외 8곡 ±2% 일치 | 8/8 | 8/8 |
| 곡별 분석 중앙값의 중앙값 | 20.1ms | 2233.9ms |
| 곡별 분석 중앙값 범위 | 19.5–51.7ms | 2219.9–2248.2ms |
| 실제 MP3 실행 | 48/48 성공 | 48/48 성공 |

분석 시간 중앙값은 현재 구현이 약 111배 짧았다. 이번 측정 수치이며 기기/열/백그라운드 상태를 통제한 성능 보증은 아니다. Essentia는 BPM과 함께 개별 박 시각까지 산출하므로 계산 범위도 더 넓다.
정답이 있는 16곡 전체의 정확도는 아니다. 8개 인쇄 악보와 1개 기존 패키지 설정을 BPM 참고 기준으로 썼다. 다른 7곡은 독립 정답 미확보이며, 둘이 일치한다고 정답으로 간주하지 않는다. 붉은 노을의 Lv2 악보 134와 실제 파일 템포의 동일성은 확인되지 않았다. ±2%에서만 생기는 8/9 대 9/9 차이로 Essentia의 확실한 우위를 주장하지 않는다.

## 박 위치

기존 바람과 언덕의 발라드 94BPM/0.388971초, Loveholic 136.232BPM/0.193초 격자와 5~85초 구간을 비교했다. ±70ms 내 1:1 매칭 F1이며 수작업 정답 정확도가 아니다. 특히 Loveholic 기준은 기존 신호 분석 추정값이다. 나머지 14곡의 박 위치 정답은 미확보다.

| 곡 | 출력 | 격자 일치 F1 | 가까운 기준 박까지 거리 중앙값 |
|---|---|---:|---:|
| 風と丘のバラード | 현재 BPM+시작점 고정 격자 | 100.0% | 21.4ms |
| 風と丘のバラード | Essentia 박 시각 목록 | 100.0% | 27.7ms |
| 風と丘のバラード | Essentia 첫 tick+BPM 고정 격자 | 0.0% | 193.3ms |
| Loveholic | 현재 BPM+시작점 고정 격자 | 82.4% | 38.1ms |
| Loveholic | Essentia 박 시각 목록 | 100.0% | 18.3ms |
| Loveholic | Essentia 첫 tick+BPM 고정 격자 | 0.0% | 166.4ms |

BPM만 바꿔서 개선한 현재 구현은 첫 박 추정 알고리즘을 유지한다. Essentia의 실제 ticks는 두 기존 격자와 잘 맞지만, 첫 tick을 기준으로 고정 메트로놈을 만들면 위상이 어긋난다. 도입한다면 안정적인 ticks로 시작 위상을 별도 추정해야 한다. 이번 시험에는 그 후처리를 적용하지 않았다. 두 방식 모두 이번 호출에서 박자표/마디 첫 박을 자동 판정하지 않는다.

## 재현 조건과 검증

- Apple M4 Pro, macOS / Chromium 152.0.0.0. 동일한 첫 90초, 44.1kHz, 40~240BPM. Essentia.js 0.1.3 / Essentia 2.1-beta6-dev, RhythmExtractor2013 multifeature.
- 현재 분석기는 실제 앱 방식인 스테레오 RMS 에너지 합성, Essentia는 signed mono 평균. 동일 MP3 디코딩 버퍼를 사용하고 각 분석기 전처리는 해당 방식대로 수행했다.
- 각 곡 3회씩, 곡/회차마다 실행 순서 교대. 실제 첫 곡으로 워밍업. 현재 코드와 이전과 동일한 Essentia를 둘 다 새로 실행했다. 이전 측정 시간을 재사용하지 않았다.
- 시간은 채널 합성·분석·결과 추출/벡터 해제를 포함한다. 파일 읽기·MP3 디코딩·모듈 다운로드/초기화는 제외했다. 직전 앱 기본 32kHz의 약 0.015초와 직접 비교하지 않는다.
- 96회 실행 완료, 같은 곡/분석기의 세 번 BPM 동일. 원본 16개 SHA-256은 ID3 갱신 후 기록과 일치. 앱 소스 해시도 직전 수정 완료 상태와 일치.
- 독립 로컬 시험 공간만 사용했고 음원·캐시·사용자 목록을 변경하거나 서버에 음원을 전송하지 않았다. 앱 변경, 버전 상승, 커밋·푸시·발행 없음.
- 이번 데이터셋의 한 곡으로 보정한 뒤 같은 데이터셋을 재검사한 결과다. 새로운 미지의 곡에 대한 일반화 성능은 별도 검증이 필요하다.
- 첫 90초 밖 템포 변화와 실제 iPhone/iPad 시간은 미검증이다. STT·AFM은 신호 수치 비교에 적합하지 않아 호출하지 않았다.
