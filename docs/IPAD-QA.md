# iPad mini 웹앱 기능 검증

대상: http://127.0.0.1:5173/, iOS 27.0 iPad mini (A17 Pro), 가로 1133×744 포인트.
방법: Xcode MCP Device Interaction, 실제 Safari 화면과 접근성 계층의 hitPoint로 조작.
범위: 기존 HTML과 공유하는 연습 기능을 웹앱에서 검증. 외부 업로드·원본 수정은 제외한다.
완료 기준: 각 조작 전후 상태와 캡처를 확인하고, 발견한 문제는 수정·재검증하거나 명확히 미완료로 표시한다.
검증 한계: 시뮬레이터의 화면·재생 시간은 실물 iPad의 음질·출력 지연·드럼 연주 평가를 대신하지 않는다.

## 기본 검사

- 26개 자동 테스트 통과.
- TypeScript 검사 통과.
- 개발 서버 HTTP 200.

## GUI 검사 범위

재생/정지, 탐색, 1% 속도 변경, 메트로놈 스위치, 반복 재진입, 마커 생성/이동/삭제, 한 줄/두 줄 보기와 크기 조절 표시, 전체화면, 8개 도구 메뉴, 오류 알림 표시/닫기.

증거는 로컬 전용 docs/experiments/round24* 파일이다.

## 확인 결과

- 재생/일시정지: 0초에서 11초 이상 진행 후 정지.
- 속도: 99%와 100% 전환. 음정 유지 처리 중 최초 캡처는 과거 값이었으나 처리 완료 후 정상.
- 메트로놈: 클릭 체크 해제/선택 상태 전환. 실제 출력 음질·클릭 청취 평가는 제외.
- 탐색: 슬라이더로 59마디 이동. 손을 놓은 뒤 이전 마디 말풍선이 남는 결함을 발견하고 change에서 숨기도록 수정, 시뮬레이터 재검증 통과.
- 두 줄: 25~28 / 29~32마디 악보와 가사 표시, 악보 크기 메뉴 숨김 확인.
- 반복: 25~29 첫 박 구간 저장 후 10초 간격 캡처에서 1:08 → 1:07로 복귀, 현재 27마디로 반복 재진입 확인. 테스트 구간 삭제.
- 전체화면: 진입은 성공하나 최초 레이아웃의 하단 버튼 잘림 발견. compact 가로 레이아웃 범위를 높이800까지 확장하고 Safari 종료 오버레이 공간 추가. 실제 전체화면에서 하단 버튼 y666~710과 제목 x88을 확인하여 재검증 통과.
- 접근성: 탐색 이후 aria-valuetext가 이전 마디로 남는 결함 발견. 현재 재생 마디로 매 프레임 갱신하도록 수정. 탐색59마디→처음1마디에서 Slider 접근성 값도1로 갱신되는 것 확인.


- 마커: 테스트 마커 생성(27마디) → 처음으로 이동 → 마커 선택으로27마디 복귀 → 테스트 마커 삭제.
- 메뉴: 소리·준비/악보 편집/가사 편집/곡 정보/파일·안내 표시 및 닫기 확인. 원본 내용은 수정하지 않았다.
- 오류: 실제 로딩 오류가 한 줄 알림으로 표시되고 터치하면 닫힘 확인.

## 저장 곡 재열기 결함과 수정

검사 중 새로고침 이후 저장 곡의 악보 Blob에 대해 Image.decode가 Loading error를 반환했다. bytes를 직접 읽어도 The object can not be found here가 발생했다. 브라우저 내부 원인까지 확정하지 않았으나, 저장된 Blob의 원본 바이트를 읽을 수 없는 것은 확인했다.

저장을 ArrayBuffer+MIME 형식(bytes-v1)으로 바꾸고, 읽을 때 독립 Blob으로 복원한다. 정상적인 기존 Blob 형식도 읽을 수 있다. 모든 미디어를 읽은 뒤 쓰기 트랜잭션을 열어 미디어 읽기 실패가 기존 곡을 덮어쓰지 않도록 했다. 반복 저장/재읽기 및 실패 시 보존 자동 검사 통과.

현재 예제만 프로젝트 public/demo 원본 미디어로 복구했다. 곡 JSON은 localStorage에 사본을 두고, 트랜잭션 후 다시 읽어 복구 전후 동일(true) 확인. 다른 곡·원본 파일은 건드리지 않았다. 일회용 복구 페이지는 검사 후 public에서 제거했고 로컬 실험 증거로만 보관했다. 복구 후 저장 곡 로드 성공.

## 범위 한계

실물 iPad의 오디오 청취·클릭 출력·레이턴시, 전체 곡의 가사 타이밍 정확도, 새 PDF 입력과 파일 내보내기/복원, 악보·가사 편집 저장은 이번 GUI 검사 범위가 아니다. 해당 기능 전체의 무결함이나 최종 사용자 연주 수용을 주장하지 않는다.

## 최종 상태

bytes-v1로 설정 저장 후 Safari 새로고침 → 내 곡 재열기 → 실제 악보 표시 성공(`round24-final-loaded`). 한 줄 보기,100%,클릭 켜짐,1마디,일시정지로 복원. 테스트 마커/반복 삭제. DeviceInteractionEndSession에서 Session stopped 확인. 루트 에이전트도 전체화면 수정·복구 결과·최종 재열기 캡처를 직접 확인했다. 결과 요약은 `docs/experiments/round24-results.json`.
