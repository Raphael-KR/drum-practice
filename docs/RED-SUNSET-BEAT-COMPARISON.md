# 붉은 노을 — 기존 자동 분석과 새 악보 박 시각 전곡 비교

2026-10-15. 사용자 승인: 자유 엔딩 제외 전곡 비교 검사.

- 목표: 기존 음원 자동 분석과 현재 수록 악보의 박별 차이 위치·크기를 확인한다.
- 범위: 기존 로컬 재현 분석 JSON, 수록 `.drumscore`의 Song·canonical XML, 동일 원본 MP3.
- 완료 조건: 자유 엔딩을 제외한 모든 박의 고정 순번 대응, 박별·마디별 시각 차이와 집계 저장.
- 제외: 앱 코드·악보·음원·기기 저장값 수정, 분석값 보정, 커밋·발행.
- 검증: 음원/PCM 해시, Song/XML 시간 일치, 박 개수·마디 대응 검사, 전체 차이 계산. 청취 확정은 수행하지 않는다.

## 입력과 대응 기준

- 기존값: `.tmp/red-sunset-41/analysis.json`. 41마디 문제 조사 당시 같은 MP3를 FFmpeg 32kHz stereo로 디코딩하고 앱 자동 분석 경로로 재현한 결과다. 578박, 자동 1마디 12.990초. **사용자 iPad의 캐시를 추출한 값이 아니다.**
- 새 값: `public/scores/red-sunset.drumscore`의 `manifest.song.measures[].beatTimes`. 패키지 source XML과 canonicalXML의 전체 137마디 시각·박 배열·박자가 manifest와 일치함을 검사했다.
- 원본 MP3와 패키지 음원 SHA-256 모두 `e1af6bbfb2f9ed16e6c7e91ff1a30f9e97f198de5a537cddabecd51ac7047a29`.
- 동일 MP3를 다시 디코딩한 PCM과 기존 분석 입력 `.tmp/red-sunset-41/audio.f32` SHA-256 모두 `e59d21379d6d8a4dc658e3f69461f443b0a1566f41b79f78fda674b5d5497568`.
- 새 악보 1마디는 녹음된 카운트다. 기존 박 배열의 연주 시작 직전 4박과 비교한다. 본문은 **새 악보 N마디 = 기존 자동 분석 N−1마디**로 대응한다.
- 새 악보 1~133마디, 532박을 모두 비교했다. 본문만은 2~133마디 528박이다. 자유 엔딩 134~137마디와 음원 꼬리는 제외했다.
- 비교값은 **기존 자동 분석 시각 − 새 악보 시각**이다. 음수는 기존 분석이 빠름, 양수는 기존 분석이 늦음이다. 시간 이동·배속 보정·가장 가까운 박으로 재매칭하지 않았다. 새 악보 133마디에 대응하는 기존 마지막 박은 244.360초로 새 엔딩 시작244.100초를 넘지만, 박 순서의 누적 차이를 숨기지 않기 위해 비교에 포함한다.

## 악보 없이 찾은 첫 박 후보와의 교차 확인

사용자는 기존 조사에서 음원만으로 찾은 +0.210초 후보를 비교 근거로 활용하도록 승인했다. `.tmp/red-sunset-41/variant-10.json`의 추종 계수10 결과에서 연주 시작12.990초 뒤 40×4박 지점은83.580초다. 악보를 사용하지 않은 이 후보와 새 악보42마디 첫 박83.560초는20ms 차이다.

- 기존 자동 분석: 83.370초.
- 음원만으로 찾은 보정 후보: 83.580초(+210ms).
- 새 악보 대응 첫 박: 83.560초(+190ms).

따라서 이 지점에서 기존 분석이 약0.2초 빨랐다는 판단은 새 악보만의 시각에 의존하지 않는다. 다만 동일 음원에서 얻은 두 추정이며, 원곡 타격을 별도 측정한 절대 정답은 아니다. 후보를 만든 계수10 결과는 전체573박으로 기존578박과 달라, 이 한 지점의 수렴을 전곡 계수 변경이나 전체 배열 교체 승인으로 확대하지 않는다. 원래 배열끼리의 전곡 비교 표와 수치는 그대로 유지한다.

## 해석과 한계

대부분은 약25~30ms의 작은 차이지만, 중간의 일시적인 앞섬과 마지막 본문에서의 누적 지연이 분리되어 나타난다. 전곡에 하나의 고정 시차를 적용해서 해결할 패턴은 아니다.

새 악보의 시각도 악보 리듬과 혼합음원 신호를 이용해 추정했으며, 본문은 마디 안에서 균등 보간한다. 따라서 위 수치는 **두 방식의 차이**이며 실제 드러머의 모든 타격에 대한 절대 오차가 아니다. 기존 iPad 사용자 청취 확인을 전곡 박별 정답 확인으로 확대하지 않는다. 39~43 및126~133마디가 후속 실제 음원 대조의 우선 구간이다.
