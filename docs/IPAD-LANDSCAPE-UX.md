# iPad mini 가로 연습 화면

목표: 곡을 들으며 악보·가사를 같은 시선에서 읽고 위치를 탐색한다.
범위: 로컬 웹앱 UI, 곡 메타데이터, 독립 HTML 내보내기.
완료 조건: 기본 배율 유지, 페이지 스크롤 없음, 항상 보이는 기능 버튼, 마디 풍선 탐색.
제외 범위: 외부 업로드/배포, PDF·음원 원본 변경, 실제 iPad 검증을 대신하는 완료 주장.
검증: 빌드/회귀 검사 및 승인된 로컬 브라우저에서 viewport·포인터·파일 실행 확인.

Apple 공식 사양의 2266×1488 화면을 참고해 1133×744 CSS px, DPR2를 시뮬레이션 기준으로 사용한다. 이는 Safari의 실제 사용 가능 높이를 보장하지 않으므로 1133×660도 확인한다. https://www.apple.com/ipad-mini/specs/

상단: 가수 - 제목, 원곡 ♩ = 94, 파일 저장/전체화면. 웹앱에서만 곡 선택·추가.
중앙: 현재 마디/박 → 기존 배율 악보 → 바로 아래 가사 → 마디 풍선 진행 슬라이더.
하단: 처음/재생/마디 이동, 1% 속도 조절, 클릭, 마커 바로가기, 기능 버튼.

| 항상 보이는 버튼 | 열었을 때 바로 조작 |
|---|---|
| 구간 반복 | A/B 마디·박, 현재 위치 지정, 저장·반복, 끄기 |
| 마커 | 추가, 이동, 이름 수정, 삭제 |
| 소리 · 준비 | 음악/클릭 음량, 준비 마디, 반복 준비 |
| 화면 | 표시 방식, 악보 배율, 원본 보기 |
| 악보 편집 | 영역·마디 시간·박·분할/병합/복제/순서 |
| 가사 편집 | 시각/글자 수정, 음절 분할, 추가·삭제, 목록 페이지 |
| 곡 정보 | 가수/제목 저장, BPM/첫 박, 추정·탭·전체 재정렬 |
| 파일 · 안내 | ZIP 백업/복원 및 HTML 파일 보관 안내 |

곡 메타데이터 저장과 전체 시간 재정렬을 분리해 제목 변경 때문에 정렬이 변하지 않게 한다. 각 기능의 열기→조작은 1~2회이며 텍스트 입력, 목록의 여러 페이지 탐색, 파괴적 편집 확인은 별도다. 원본 여러 쪽과 긴 가사/마커 목록은 페이지 버튼으로 넘긴다. 주 연습 화면의 악보 crop 크기 산식은 유지하고 stage 높이의 310px 하한과 여분 31px를 제거한다.

작업 상태는 연습 화면 하단에서 제거했다. ‘파일 · 안내’의 최근 작업 기록에서 현재 화면을 연 동안의 최근 5건(시각 포함)을 확인한다. 일반 상태는 이곳에서만 표시하고 오류는 기존 일시 알림과 기록에 함께 남긴다. 기록은 영구 저장하지 않는다.

오류 표시 변경: 자동 소멸 알림 대신 악보 위 상태줄에 한 줄 ‘알림 · 오류 내용 · ×’ 버튼을 둔다. 사용자가 누르면 닫히며 긴 문구는 말줄임한다. 전체 오류는 파일·안내 작업 기록에 남는다. 편집 중에는 해당 창 상단에 표시한다.

악보 크기 슬라이더는 한 줄 보기에서만 표시한다. 두 줄 보기로 바꿀 때 숨기되 저장된 배율은 유지하고 한 줄로 돌아오면 다시 표시한다.
