## 성능 관측의 한계

- 전체 곡 음악 클릭 예약은 시간 모델과 부동소수점 오차 내 일치했다. 스피커 출력 파형·청감 측정은 아니다.
- 정상 관측 프레임(dt<100ms)의 마디 경계 이동 최대 7.2px. 화면 크기 모사 전환 부근에는 1010.9ms 프레임 간격/91.8px 이동도 있었다. 화면 동기화 100ms 목표의 실기기 충족을 주장하지 않는다.
- 속도 변경은 음정을 보존하는 오디오를 준비하는 동안 일시정지한다.
- 가사 겹침은 글자 상자만 좌우로 조정해 해결했다. 1024px 화면에서 최대 18.11px 조정, 시간 데이터는 유지한다.
