# 붉은 노을 앱 반영

2026-10-15 사용자 요청: 남은 문제 수정, 앱 목록 반영, 검사·테스트·빌드 허가.

- 목표: 최신 제작본을 목록에서 열고, 박별 시각과 연음 숫자를 보존하여 재생한다.
- 범위: 공통 Song/XML 시간 계약, 원곡/연습 재생, 공통 SVG, 붉은 노을 수록 패키지.
- 완료 조건: 패키지·XML 왕복에서 박 시각 보존, 원곡 1배속/연습 고정 박, 131마디 연음 숫자 3개, 목록에서 열기.
- 제외: 원본 MP3/PDF 수정, 기존 음원전용 저장 자료 덮어쓰기, 커밋·푸시·공개 발행.
- 검증: 실제 제작 데이터 기반 집중 검사, 전체 드럼 테스트, 타입 검사·앱 빌드, 로컬 Safari 렌더·재생 확인. 실물 iPad 청취 확인은 별도다.

## 적용 기준

build-03을 입력으로 보존한다. 음원전용 앱41마디는 PDF42마디에 대응하는 후보이며, 새 악보는 PDF 번호를 유지한다. 83.560초를 PDF41에 적용하지 않는다.

마디별 `beatTimes`를 선택적인 음원 연결 정보로 정본 `drum-practice:score:v1`에 저장한다. 값이 없으면 기존 시작/끝 균등 보간을 유지한다. 실연의 미세한 그루브를 자동 추적하는 기능이 아니라 제작자가 전달한 템포 지도이며, 기존 Loveholic 연결은 변경하지 않는다. 제작용 `recording-grid:v1`은 근거로 보존하고 런타임에서 암묵적으로 적용하지 않는다.

원곡에서는 원본 오디오 1배속과 해당 지도에 맞춘 메트로놈을 사용한다. 연습에서는 악보 사분음표 위치로 변환해 일정한 BPM을 사용한다. 녹음 앞부분과 마지막 악보 이후의 음원 꼬리를 보존한다.

자유 엔딩134–137의 시각은 제작자의 잠정 추정값이다. 소비 코드 검증을 실제 연주와의 청취 확정으로 보고하지 않는다.

## 반영 결과와 검증

- 수록 파일: `public/scores/red-sunset.drumscore`. 일반 곡 목록에 `붉은 노을 · YB`로 추가했다. 기존 음원 전용 항목은 별개로 보존한다.
- 앱용 산출물: `data/production/red-sunset/final/app-01/`. 입력 build-03과 원본 음원은 변경하지 않았다. 패키지 SHA-256 `85ba0757df43574f3ca372096590fa27b833ecf646e04d9cb1e56d61ef1676a7`; 원본 음원 SHA-256 `e1af6bbfb2f9ed16e6c7e91ff1a30f9e97f198de5a537cddabecd51ac7047a29` 유지.
- 공통 OSMD의 연속 연음 숫자 생략을 해제했다. 캐시 정책 v22로 재생성하며 131마디의 숫자 3개를 화면에서 확인했다.
- 제작기에서 마디 경계 이동은 박별 상대 시각을 보존하고, 명시적인 균등 BPM 재배치는 박별 지도를 제거한다. 분할·병합 및 가사 격자·진행률도 같은 박 시각을 사용한다.
- 카운트오프는 앱의 공통 설정을 따른다. 제작 패키지의 `countIn: 0`은 현재 앱의 공통 ON/OFF 설정을 덮어쓰지 않는다. 녹음된 카운트는 음원 그대로 보존한다.
- 전체 드럼 테스트 115파일/640개, TypeScript, 두 앱 분리 빌드·경계 검사, 공통 재생 구조 검사, diff 검사 통과. 기존 번들 크기 경고는 유지한다. 로그: `.tmp/red-sunset-41/drum-tests.log`, `build-apps.log`.
- Safari MCP는 탭 생성에서 `Transport closed`로 실패했다. 승인된 로컬 범위의 ego-browser로 목록 → 가져오기 → 137마디 악보 열기와 131마디 SVG를 확인했다. macOS Chromium 검증이며 iPad Safari 검증이 아니다.
- 실제 MP3를 브라우저 AudioContext로 디코딩한 길이 267.833469초. PDF42/135마디에서 원곡·연습 네 경우의 메트로놈 예약 시각이 박 지도와 일치했다. 135마디 원곡 간격은 0.503333/0.704667/0.906초, 연습 100BPM은 모두 0.6초다. 원곡은 원본 버퍼 1배속을 유지하며 카운트오프 끝과 재생 시작도 일치했다.
- 재생 검사는 음악을 음소거하고 클릭 예약값을 계측한 결과다. 음원과 실제 타격의 청취 일치를 입증하지 않는다. 근거: `.tmp/red-sunset-41/playback-runtime-audit.json`, `app-m131.png`, `data/production/red-sunset/final/app-01/package-audit.json`.
- 버전 0.7.11 유지. 소스 빌드번호 갱신. 커밋·푸시·공개 발행은 수행하지 않았다. 자유 엔딩의 잠정 시각과 실물 iPad 청취 확인은 남아 있다.
