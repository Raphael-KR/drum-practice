# 가사 싱크 교정 목록 — 현재 악보 기준

일본어 정본과 영어 원문 표기가 반영된 현재 가사 기준이다. 기존 137개 검토 항목에서 같은 영어 단어 시작을 가리키는 중복 12개를 합쳐 **125개 시작점**으로 정리했다. 새 음원 분석 결과가 아니라 기존 의심 근거를 최신 표시 가사에 대응한 목록이다. 오류 확정 목록은 아니다.

## 전달 방법

- 아래 표의 **굵은 음절/영어 단어가 시작하는 순간**에 위치 복사 버튼을 눌러, 고유번호와 함께 보내면 된다.
- 한글은 표시한 음절 시작, 영어는 단어 전체의 시작을 확인한다. 앞뒤 가사는 위치 구분용이다.
- 같은 단어로 합친 번호는 `대표번호 (기존번호 …)`로 표시했다. 어느 번호로 보내도 같은 시작점으로 처리한다. 번호를 새로 매기거나 재사용하지 않았다.
- 시간 순서로 정렬했다. 나중에 추가된 **205**는 16마디 위치에 놓았다.
- 위치는 누적만 하고, “모은 것 반영해줘” 요청 때 앱에 반영한다.
- 001 Ah, 002 사, 15마디 코는 이미 청취 확인되어 제외했다. 071은 구판 003과 같은 구절이지만 새 첫 발음 카의 재확인 항목으로 유지했다.
