## 범위와 판정 기준

정지 상태에서 한 줄은 네이티브 가로 스크롤로 악보가 손가락을 따라 움직이고 진행선은 고정한다. 두 줄은 가로 드래그로 악보를 이동하며 재생 위치를 변경하지 않는다. 두 줄 세로 스크롤은 그대로 유지한다. SVG/PDF 양쪽에서 확인한다. 재생·정지·탭 선택 회귀도 확인한다.

## 환경

- Device Hub / Xcode 27, iOS 27.0 (24A434), iPad mini (A17 Pro) 시뮬레이터, UDID `9ECBE1E1-D908-45A7-AF31-5F9FEAB568E2`.
- Safari에서 `http://127.0.0.1:5174/combined-touch.html` 실행. 재생 데이터·런타임은 파일 내장, HTTP는 파일 전달용이다. 실기기 Edge의 오프라인 파일 실행을 대신한 증거가 아니다.
- `DeviceInteractionSynthesize`의 네이티브 터치 입력 사용. DOM 합성 PointerEvent나 스크롤 속성 대입으로 터치 성공을 판정하지 않는다.
- 연결된 실기기도 시도했지만 StartSession이 `Cannot select specified device`를 반환했고 조작 가능한 목록에는 시뮬레이터만 있었다. 승인 거부나 실기기 정상 동작으로 단정하지 않는다.

## 발견과 수정

1. 두 줄 가로 스와이프가 약12px 후 끊겼다. 자식 음표의 암묵적 pointer capture가 상위 악보로 이동할 때 발생한 `lostpointercapture`가 버블링하여 새 드래그를 취소했다. 악보 표면 자체가 capture를 잃은 경우만 취소하도록 수정했다.
2. 한 줄 진행선을 스크롤 콘텐츠 밖에 두어 악보만 이동하게 했다.
3. 두 줄 렌더 함수의 지역변수 선언 순서 오류 및 키보드 처리에 들어간 휠 처리 코드를 제거했다. 한 줄/두 줄 전환 시 스크롤 상태를 초기화한다.
4. 악보에서 드래그 중 텍스트 선택·길게 누르기 메뉴가 끼어들지 않도록 악보 영역의 텍스트 선택을 막았다.
5. 두 줄 가로 휠도 악보 이동으로 통일했다. 가사 배치는 화면 가장자리가 아닌 이동하는 악보 줄을 기준으로 한다.

## 자동 검증

- 56개 테스트 파일 / 236개 테스트 통과. 터치 캡처가 자식에서 표면으로 넘어갈 때 계속 드래그하는 회귀 테스트와 네이티브 스크롤이 탭/탐색으로 처리되지 않는 테스트 포함.
- TypeScript, Vite, 재생 HTML 빌드 및 관리/저장소/렌더러 미포함 번들 검사 결과는 최종 실행 로그로 확인한다.
