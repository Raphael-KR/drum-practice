# iPad 연습 조작 개선안

상태: 2026-09-20 사용자 피드백을 반영한 웹앱 구현. 검증 결과와 기기 검증 경계는 QA-IPAD-TOUCH-2026-09-20.md 참조.
정본: 이 문서와 src/ 구현. docs/prototypes/ipad-practice-controls.html은 최초 제안 시안이며 최신 앱 화면과 다를 수 있다.

목표: 연주 중 악보에서 손을 멀리 옮기지 않고 재생·정지·탐색·반복을 조작한다.
범위: 가로 iPad 우선, 세로 대응. 웹앱 입력·연습 컨트롤·설정 구조.
완료 조건: 아래 동작을 iPad에서 오작동 없이 수행하고, 기존 악보·가사·음원·저장을 보존한다.
제외: 악보 표기 매핑 변경, 음원/가사 재정렬, 별도 HTML 내보내기·외부 배포.
검증: 실제 iPad 터치 시나리오 + Safari 화면 + 제스처 상태 전이·저장 회귀 검사.

## 사용자 확정 방향

- 정지된 두 줄 보기의 상하 휠·트랙패드 스크롤은 음원 위치와 독립적으로 전체 악보를 세로 탐색한다. 좌우 탐색은 재생 위치를 이동한다.
- 상단 전체화면 버튼은 설정 > 화면으로 이동. “전체화면으로 악보 보기”를 켜면 악보 열기 동작에서 자동 전체화면을 요청한다. 설정은 이 브라우저에 저장한다.
- 전체 곡 진행률을 퍼센트로 표시한다. 좌우·상하 드래그로 1%씩 이동하고 탭하면 마커 창을 연다.
- 메트로놈 생성 신호의 음량·타격감을 높이고 합산 피크를 제한한다. 사용자가 저장한 음악/메트로놈 음량 값은 유지한다.

- 악보는 재생 중 단일 탭으로 정지, 정지 중 단일 탭으로 마디 선택, 두 번 탭으로 해당 마디부터 재생.
- 악보를 좌우로 드래그해 기존 진행 슬라이더처럼 탐색.
- 숫자 조절을 좌우·상하 드래그로 통일하고 스피너 화살표 제거.
- 제목 옆 현재 연습 BPM에서 BPM 설정 창 열기. 하단 BPM/−5/숫자/+5 제거.
- 메트로놈을 제목줄 내 악보 목록 왼쪽에 배치.
- 연주 컨트롤은 악보 바로 아래, 화면·재생·악보·정보는 설정 안으로 이동.
- 가로를 주로 사용하며 세로도 지원.
- 빠른 반복은 **현재 마디를 중심으로 앞뒤 1/2/3/4마디**. 현재 마디 포함 총 3/5/7/9마디.

## 적용 배치

제목줄: 곡 제목 / ♩=현재 BPM / 메트로놈 / 내 악보 목록 / 설정.

악보 아래 첫 줄: 되감기(드래그 숫자) · 현재 위치 복사 / 중앙 큰 재생·정지 / 진행률 % · 마커 · 소리.
그 아래: 현재 마디 중심 [앞뒤 1][앞뒤 2][앞뒤 3][앞뒤 4] · 현재 반복 범위 · 조정 · 해제.
기존 긴 진행 슬라이더는 화면에서 제거. 진행률 숫자와 악보 드래그가 탐색을 담당한다.
가로는 가능한 한 한 줄씩 유지하고 세로는 컨트롤 그룹을 줄바꿈한다. 숫자를 줄여 터치 영역을 희생하지 않는다.

## 악보 제스처 계약

| 입력 | 동작 |
|---|---|
| 재생 중 한 번 탭 | 손을 떼면 즉시 정지. 두 번째 탭 대기 때문에 정지를 늦추지 않는다 |
| 정지 중 한 번 탭 | 260ms 내 두 번째 탭이 없으면 터치한 마디 첫 박을 선택하고 정지 유지. 원터치로 재생하지 않으며 화면 위치를 그대로 유지 |
| 두 번 탭 | 첫 탭 당시 지정한 마디 첫 박부터 재생. 재생 시작 시 해당 마디 행을 위쪽에 배치. 카운트오프는 앱 공통 설정을 따름 |
| 오른쪽 드래그 | 이전 구간으로 이동 |
| 왼쪽 드래그 | 이후 구간으로 이동 |
| 드래그 중 | 진행을 잠시 멈추고 이동 위치·마디를 표시. 8px 안팎 이동을 탭과 구분하는 초기 기준으로 시험 |
| 드래그 종료 | 선택 위치를 확정. 원래 재생 중이면 선택 위치부터 이어 재생, 원래 정지면 정지 유지. 마디 처음으로 재보정하지 않음 |
| 정지 중 마우스 휠·두 손가락 스크롤 | 두 줄 보기의 상하는 전체 악보를 읽는 세로 스크롤(음원 위치 유지). 좌우는 기존 재생 위치 탐색. 한 줄/검수 모드의 휠 동작은 유지 |
| 시스템 취소/멀티터치 개입 | 탭으로 처리하지 않고 조작 시작 위치로 복원 후 정지 |

두 번 탭 판정은 같은 손가락의 짧은 간격 탭을 뜻한다. 두 손가락 탭이 아니다.
모든 악보 표시 방식에 같은 입력 규칙을 적용한다. PDF/SVG 검수에서 재생 중 한 번 탭 정지와 스페이스/정지 버튼은 캡처 복사 동작도 유지한다. 더블탭의 첫 탭도 즉시 정지하므로 이때 캡처가 복사될 수 있다. 드래그의 일시 정지는 캡처하지 않는다.
재생 버튼과 키보드 입력은 계속 제공한다. VoiceOver의 두 번 탭은 앱의 독자 제스처로 가로채지 않는다.

## 반복 UX

- 25마디에서 앞뒤1=24–26, 앞뒤2=23–27, 앞뒤3=22–28, 앞뒤4=21–29.
- 최초 버튼 입력 시 중심 마디를 고정한다. 반복 중 옵션 변경은 같은 중심에서 범위만 변경한다.
- 재생 중 설정하면 현재 흐름을 이어가다가 구간 끝에서 A로 돌아온다. 정지 중 설정하면 자동 재생하지 않는다.
- 현재 마디로 중심을 옮기는 별도 버튼과 전용 동작은 제거했다(2026-10-04). 반복을 해제한 뒤 원하는 위치에서 구간을 다시 설정한다.
- 시작/끝은 음영+경계선으로 표시하고 범위를 '23–27마디 · 5마디 반복'으로 쓴다. 사용자는 마지막 포함 마디를 선택하며 내부 exclusive end는 숨긴다.
- 곡 시작/끝에서는 실제 존재하는 마디까지만 선택하고 실제 총 마디 수를 표시한다.
- '조정'을 열면 시작·끝 마디 숫자를 드래그한다. '박 단위'에서 ¼박 조절을 제공한다. 조정 중에는 초안이며 적용/취소를 구분한다.
- 수동 조정하면 빠른 옵션 선택을 해제하고 '사용자 구간'으로 표시한다. 저장은 반복 실행과 분리하여 이름 입력 없이 먼저 연습할 수 있게 한다.
- 반복 범위 밖으로 두 번 탭/드래그하면 반복을 끈다. 마지막 구간은 메모리에 보존하고 반복이 꺼진 이유를 짧게 알린다.

## 공통 숫자 조절기

- 오른쪽/위=증가, 왼쪽/아래=감소. 첫 우세 방향으로 축을 고정해 대각선이 두 번 더해지지 않게 한다.
- 숫자 자체에 충분한 터치 영역을 둔다. 숫자 밖 여백에서는 설정 창의 세로 스크롤이 동작한다.
- BPM·마디 수·준비 마디는 1씩, 박은 ¼박씩, 배율·음량은 각 단위에 맞게 조절한다. 필드별 최솟값·최댓값을 유지한다.
- 조절 중 값만 미리 표시하고 손을 놓을 때 적용한다. 특히 BPM 음원 변환을 드래그 매 프레임 호출하지 않는다.
- BPM은 큰 숫자 조절판을 연다. 일반 숫자 입력은 직접 드래그하거나 키보드로 입력할 수 있다. 모든 숫자 입력에 같은 드래그 컴포넌트를 연결하며 동적으로 생긴 편집 입력도 포함한다.
- 기존 BPM 숫자 더블탭 리셋은 없애고 BPM 창 안의 명시적인 '원곡 94 BPM' 버튼으로 모은다. 승인된 숫자 조작 통일 방식을 따른다.
- 키보드 방향키/접근성 증감 대체 조작을 제공한다.

## BPM·메트로놈·소리

- 헤더의 음표=숫자는 원곡 고정값 대신 현재 연습 BPM을 표시한다. 탭하면 기존 프리셋 격자 형태를 유지한 팝오버를 연다.
- BPM 창에는 큰 드래그 숫자, 프리셋, 원곡 복원 버튼을 둔다. 화면 폭 안에 맞추어 표시한다.
- 메트로놈은 제목줄의 한 번 탭 켜기/끄기. 켜진 상태를 색과 선택 상태로 표시한다.
- 하단 '소리'는 음악/메트로놈 음량과 준비 마디를 작은 팝오버에서 바로 조절한다.
- 마커는 탭 한 번으로 현재 마디를 추가하고 짧은 이름은 나중에 편집한다. 자주 쓰는 마커는 하단에서 바로 이동한다.

## 설정

톱니바퀴에서 iPad 스타일의 그룹 목록을 연다. 넓은 화면은 카테고리/내용 2열, 600px 이하에서는 위쪽 가로 카테고리와 아래쪽 상세 내용으로 표시한다.

| 그룹 | 내용 |
|---|---|
| 화면 | 세 가지 보기, 한줄 악보 크기, 전체화면 버튼, 자동 전체화면 옵션 |
| 재생 | 마디 처음부터 다시 재생, 카운트오프 — 앱 공통·기본 켬 |
| 악보 | PDF/MusicXML·가사·곡 정보 관리, 원본/편집, 내보내기·백업·복원 |
| 정보 | 제품 버전(소스 식별자)·KST 빌드 시각, 최근 작업 기록 |

재생 정책의 정본은 [설정과 재생 정책](SETTINGS-PLAYBACK.md)이다. 카운트오프는 현재 연습 템포로 4분음표 스틱 소리 네 번이며 세부 설정은 두지 않는다.

숫자·설정 창을 연 상태에서 뒤 악보로 이벤트가 전달되지 않아야 한다. 변경 가능한 악보/가사 데이터는 적용/취소를 유지한다.

## 시안 및 검증

- docs/prototypes/ipad-practice-controls.html: 대화용 배치/상호작용 시안. 음악 재생·저장·원본 악보 렌더링을 실행하지 않는 시각 시뮬레이션이다.
- 실제 앱에서 Safari 가로 1133×744, 세로 744×1133 배치, 상단 BPM 창, 앞뒤2→23–27마디/총5마디 표시, 자동 전체화면을 확인했다.
- 실제 iPad 하드웨어의 터치 감도·두 손가락 스크롤·스피커 청취는 별도 확인 대상이다. 데스크톱 Safari 화면 크기 검사를 실제 iPad 검증으로 대신하지 않는다.

참고: Apple HIG Gestures, Accessibility, Popovers, Sheets. 큰 터치 영역·짧은 직접 조작·넓은 화면의 팝오버/좁은 화면의 시트 원칙을 참고했다. 이 앱의 마디 탐색 제스처 자체를 Apple 표준 동작이라고 주장하지 않는다.

## 브라우저 제약과 검증 경계

- 자동 전체화면은 사용자 악보 열기 클릭/폼 제출에서 비동기 로딩 전에 요청한다. 초기 HTML 자동 로딩이나 브라우저 정책상 거부 시 악보는 계속 로딩하고 설정에 안내를 표시한다.
- Fullscreen API는 사용자 동작이 필요하다: https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen
- 두 줄 모드에서 정지 중 상하 스크롤은 전체 악보를 마디 순서대로 세로 탐색한다. 음원 위치·마커·반복 구간은 변경하지 않는다. 정지한 마디에서 읽기를 시작하며, 재생하면 해당 재생 위치의 두 줄 따라가기로 돌아온다. 좌우 스크롤/드래그는 기존 재생 위치 탐색을 유지한다.
- 새 음량의 신호 측정과 실제 iPad 스피커에서의 청취 만족도는 별도 검증한다.
