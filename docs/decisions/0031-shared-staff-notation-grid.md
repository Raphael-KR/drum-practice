# 모든 오선 부착 표기에 공통32분음표 그리드를 적용한다

2026-11-11 결정과 11월 12일 문구 구체화의 기록이다. 이후 승인된 [ADR-0032](0032-common-sixty-fourth-unit.md)가 기본 단위를 64분음표로 대체한다. 모든 표기·모든 조판의 적용 범위, 원본 보존과 검증 구분은 유지한다. 아래 본문은 대체 전 결정이다.

## Context and Problem Statement

기존4/4 한 마디32칸·가사 앵커 결정이 균등 보기 또는 가사만의 하위 규칙으로 좁게 해석됐다. 사용자는 “오선에 붙어 있는 모든 표기는32분음표 그리드를 사용하는 거야. 알겠어? 이걸 분명한 악보 작성 상위 규칙으로 명시해.”라고 지시했다. 최근64분음표 언급은 사용자가 과거 결정을 잘못 기억한 것이라고 철회했다.

## Considered Options

- 균등 보기 또는 가사만32분음표 그리드를 적용하고 나머지는 별도 기준을 둔다.
- 모든 오선 부착 표기가 같은32분음표 기준 시간축과 앵커를 사용하도록 상위 규칙으로 명시한다.

## Decision Outcome

두 번째 방식을 채택한다. 음표·쉼표·가사·표제·지시문·셈여림·구간선·주법 등 모든 오선 부착 표기에 적용한다. 사분음표당8칸,4/4 한 마디32칸이다. 순차 가사의 시작점 중복 금지는 [ADR-0030](0030-distinct-lyric-onsets.md)의 하위 저장 조건으로 유지한다.

기존 [32분음표·가사 앵커 결정](../records/archive/adr-0005-practice-layout-and-spacing-sources.md#균등-모드-최종-정정-고정-마디32분-격자-2026-10-04)을 특정 보기의 예외로 취급하지 않는다. 이전 지시문 표시 이동의0.0625박 탐색 규칙도 새 상위 단위인0.125박으로 대체한다. 원본에 명시된 연음·더 짧은 음가를 유리수 위치로 보존하는 것과 표기별로 별도의 시간축을 만드는 것은 구분한다.

### 승인 문구 구체화 — 2026-11-12

검토에서 “그리드를 사용한다”만으로는 그리드에 맞춘 임의 음절 분할·이동, 글자 가장자리와 음악적 기준점의 혼동, 원본 리듬 예외의 확대 해석을 막기 어렵다고 판단했다. 사용자는 단위와 원점·위치 결정·배치 기준점·충돌에 따른 표시 이동·원본의 세분 리듬 보존·저장과 검증의 6개 조항을 승인하고 기준 문서 수정을 지시했다.

승인 문구는 [상위 Rule](../reference/score/production.md#score-production-rules--오선-부착-표기의-32분음표-그리드)에 반영한다. 모든 표기·모든 조판 방식의 적용 범위를 유지하며, 원본 또는 승인된 작곡·교정 기준으로 위치를 먼저 정하도록 구체화했다. 특히 그리드 준수와 원본 위치 일치를 별도로 판정한다. 이 구체화는 과거의 개별 가사 교정이나 현행 구현 전체가 원본과 일치한다는 사후 승인이 아니다.

### Consequences

- 상위 Rule은 production.md 한 곳에 두고 입력·저장·조판 Rule, 제작 절차·스킬·프로젝트 지침은 이를 참조한다.
- 기호/글자/테두리의 고유 폭과 조판 여백·세로 높이를 시간 격자와 혼동하지 않는다. 음악적 적용 앵커와 충돌 회피 표시 앵커는 같은 기준으로 기록하며 적용 시점을 바꾸지 않는다.
- 이 문서화로 기존 정본·앱·저장본을 자동 변경하지 않는다. 현재 구현의 이전 탐색 단위와 새 규칙 간 차이는 별도 이행 항목으로 명시하고, 문서 정리만으로 코드 반영 완료를 주장하지 않는다.

### Confirmation

문서·참조·앵커 정합성과 적용 범위는 [실행 기록](../records/archive/staff-grid-rule-20261111.md)에서 확인한다. 코드/조판 실행·악보 일괄 변환은 이번 문서화 범위가 아니다.
