# 모든 MusicXML 화면에 시간 비례 배치를 적용한다

## Context and Problem Statement

일반/균등·한 줄/두 줄 조판의 좌표와 자산이 달라 시작 여백과 변박 폭이 일치하지 않았다. 사용자는 기존 균등식을 두 앱의 공통 조판 기준으로 채택하고, 정식 출시 전 구형 앱 자료의 호환 지원을 종료하기로 했다.

## Considered Options

- 일반/균등 설정과 별도 row/grid 자산을 유지한다.
- 기존 시간 비례식을 모든 MusicXML 화면에서 공유하고, 변박과 초과 행만 공통 처리한다.

## Decision Outcome

두 번째를 채택한다. 시작 여백을 제외한 리듬 폭은 음악적 시간에 비례한다. 음표·가사·진행선·탐색은 같은 좌표를 사용한다. 전체 보기의 원본 줄 구성과 한 줄 보기의 흐름을 유지한다. 전체 보기와 두 줄은 네 마디 기준 폭을 넘는 줄 전체만 같은 배율로 줄이고 짧은 줄의 오른쪽 여백은 허용한다.

2026-11-13 전체 보기의 누락을 정정했다. 최장 변박 줄에 맞춰 캔버스를 넓히면 나머지 일반 줄도 화면에서 작아지므로, 일반 4/4 네 마디 줄의 native 폭을 기준으로 한다. OSMD 그리기 전에 초과 시스템만 두 축을 함께 축소하며 원본과 개별 시간 좌표는 보존한다. [실제 출력 확인](../records/archive/full-score-row-fit-20261113.md)에 Real Paradis 81–84마디와 짧은 줄의 결과를 기록한다.

같은 날 숨긴 음자리표의 생성·공간을 제거한 뒤, 줄 끝 여백만으로 폭을 맞춘 화면에서 첫 음표와 중간 마디선이 줄끼리 어긋남을 사용자가 확인했다. 이에 **첫 줄의 실제 박자표 등 시작 기호 폭을 각 줄 첫 마디에 공통으로 확보**한다. 박자표가 없는 줄도 같은 시작 공간을 사용하며 숨긴 음자리표의 폭은 다시 넣지 않는다. 더 넓은 실제 시작 기호는 그 줄의 필요 폭을 유지한다. native 끝 기호 등으로 남는 폭 차이만 마지막 마디 뒤쪽에서 흡수한다. 박당 거리·음표 크기·변박 초과 줄 축소와 짧은 줄의 오른쪽 빈 공간은 유지한다. 이 후속 변경은 정적 검사만 수행하며 앞선 화면 결과를 새 코드의 출력 검증으로 대신하지 않는다.

같은 날 사용자는 원본 PDF를 확인한 뒤 `붉은 노을` 엔딩의 **134–135 / 136–137을 각각 두 마디로 유지하고 두 줄 모두 전체 폭으로 펼치는 예외**를 승인했다. 정본 v3의 선택 필드 `fullWidthSystems`에 줄 첫 마디의 안정 ID를 기록한다. 공통 조판기는 지정한 전체 보기 줄의 남는 폭을 사분음표 수에 비례해 배분한다. 글리프·문자 크기, 시작·끝 기호 공간과 135마디의 6/4 등 음악 데이터는 유지한다. 두 줄은 다른 줄보다 박당 거리가 커지는 명시적 예외이며, 미지정 짧은 줄과 연주 1줄·2줄 보기에는 적용하지 않는다. 곡명을 앱 코드에 넣지 않고 정본에 기록된 조판 의도를 읽는다.

가사 묶음은 [ADR-0033](0033-final-lyric-groups.md)을 따른다. 실제 원음절 텍스트 상자의 겹침만 묶고 줄 끝·줄 경계·다음 묶음 침범과 기호 충돌을 위한 사전 최소 폭은 추가하지 않는다. 후속 보완은 실제 사례로 결정한다.

`uniformSpacing` 타입·UI·분기와 row/grid 중복 생성 경로를 제거한다. 정본 v3·완성 패키지 v2·앱 DB schema 5로 전환한다. 구형 곡은 원본과 제작 이력을 먼저 별도 보존하고 활성 목록·파생 캐시를 초기화한다. MusicXML 파생 SVG는 완성 패키지에서 제외한다. 구형 패키지·제작 전체 백업은 거부하며 사용 가능한 정본에서 새로 만든다.

### Consequences

- [ADR-0005](0005-practice-layout-and-spacing.md)의 보기별 간격 정책을 대체한다. native 글리프·종횡비·오선 제3선 정렬은 유지한다.
- [ADR-0022](0022-portable-score-and-practice-files.md)의 완성 패키지 v1 부분을 갱신한다. 음원 연습 JSON과 원음원 보존 계약은 유지한다.
- 정본 전환은 악보제작자, 공통 앱 조판·수록·저장은 앱 담당이 수행한다. 원본·원음절 작업 파일·검증 및 과거 기록은 삭제하지 않는다.
- 최초 열기의 재조판과 승인된 활성 데이터 초기화가 필요하다. 두 줄 초과 행에서는 그 줄의 박당 화면 거리가 다른 줄보다 작아진다.

### Confirmation

최초 구현은 사용자 지시에 따라 정적 검사와 실제 파일 구조·해시 대조만 수행했다. 이후 별도 요청으로 진행한 [두 앱 화면 검증](../records/archive/time-proportional-ui-20261113.md)과 [전체 보기 폭 정정](../records/archive/full-score-row-fit-20261113.md)은 각각 당시 입력과 범위의 결과다. 정본 XSD와 앱 정적 검사를 실제 출력 성공으로 대신하지 않는다.
