# 악보 템포와 원곡 측정값을 분리한다

## Context and Problem Statement

Loveholic의 기보136 BPM과 음원 추정136.232 BPM·첫 박0.193초를 혼동해 악보 템포를 바꾸거나 박별 실연 그루브를 추종할 우려가 있었다. 2026-10-13 사용자는 일정한 메트로놈 연습과 원곡1배속을 확정했다.

## Considered Options

* 원곡 추정 속도·실연 미세 시차로 악보 템포와 연습 격자를 바꾼다.
* 악보 템포는 보존하고 해시에 결합된 추정값을 별도 메타정보로 둔다.

## Decision Outcome

후자를 채택한다. recording-tempo:v1의 필드와 Loveholic의 기존 일정 연결을 보존한다. 연습은 고정 메트로놈 박, 원곡은1.0배속으로 사용한다.

### Consequences

측정값은 프로젝트 확장 메타정보이며 표준 MusicXML tempo를 덮어쓰지 않는다. 새 마디·박별 실연 추종 분석을 이 결정에서 도출하지 않는다.

### Confirmation

현재 계약은 [MusicXML 정본](../reference/score/musicxml.md#musicxml-canonical--musicxml-정본-계약), 입력은 [매핑 Rule](../reference/score/notation.md#score-musicxml-osmd-mapping--악보의-musicxml--osmd-매핑-규칙)을 따른다. 아래 PASS·측정·기기 결과는 당시 범위이며 이번 문서 분리에서 앱 시험을 재실행하지 않았다.

- **연습 박 기준 — 사용자 결정(2026-10-13): 선택한 연습 속도에 따른 일정한 메트로놈 박을 기준으로 한다.** 실연의 개별 타격이 앞서거나 늦는 그루브를 박별 시간표에 반영해 연습 격자를 흔들지 않는다. 악보에 기보된 리듬·음가·박자 변경은 보존한다. Loveholic은 기존 첫 박0.193초와 일정한136.232 BPM 기반 음원 연결 시간표를 유지하고 추가 마디·박별 실연 추종 분석/교정을 수행하지 않는다. 악보 BPM136 유지·원곡 측정값 별도 표시·원곡 배속1.0 결정도 유지한다.

- 악보 템포와 음원 측정값은 분리한다. Loveholic의 사용자 결정(2026-10-13)은 표준 tempo와 Song.bpm=136 유지, 별도 원곡 추정값136.232·첫 박0.193 저장이다. `drum-practice:recording-tempo:v1` miscellaneous-field에는 `version`, `scoreBpm`, `bpmEstimate`, `firstBeatEstimateSeconds`, `audioSHA256`, `method`, `status`를 JSON으로 둔다. 앱은 원곡 추정값을 표시하되 ‘원곡’ 재생은 배속1.0으로 한다. 이 필드가 있다는 이유로 표준 악보 템포나 기존 마디 시각을 덮어쓰지 않는다. 측정값은 해당 음원 해시와 결합된 추정치이며 일반 MusicXML 앱의 필수 기능이 아닌 이 프로젝트의 메타정보다.

##### 표시와 저장
MusicXML `drum-practice:recording-tempo:v1`은 별도 측정정보다. 연습 BPM 프리셋과 숫자 입력은 원음원 BPM(측정정보가 없으면 Song.bpm)을 기준으로 목표BPM/원음원BPM 배속을 계산한다. 측정정보는 설정 → 정보에서 “악보136 BPM · 원곡 측정 약136.232 BPM · 첫 박 약0.193초 (신호 분석 추정)”으로 표시한다. 원곡 버튼은 측정BPM을 목표BPM으로 환산하지 않는다. 원곡 버튼은 정확한1.0 배속을 지정한다.

기존 player 저장본은 곡ID·악보BPM·음원SHA256이 일치하고 해당 필드가 없을 때만 XML에 필드 하나를 추가한다. DB 저장은 기존 canonicalXML을 비교하여 동시수정 시 적용하지 않는다. media·Song·연습설정·마디/가사·SVG 캐시는 업데이트하지 않는다. 새 패키지는 제작자 final-03을 public/scores/loveholic.drumscore에 수록했다. 실제 브라우저의 저장본은 다음 악보 열기 시 적용된다.

측정값은 신호분석 추정이며 실제 청취로 확정한 값이 아니다. 실제 iPad 청취 및 카운트오프ON/OFF 출력 비교는 별도 미검증이다.

2026-10-13 사용자 결정: BPM 창의 상시 설명 두 줄을 제거한다. 측정정보는 설정 → 정보에 두고 드래그 설명은 숫자판 툴팁과 BPM 도움말에 둔다.

2026-10-13 추가 결정: 원곡 버튼은 “원곡”만 표시하고 배속1.0을 지정한다. 수동BPM은 해당 목표BPM에 맞춰 조절한다(러브홀릭100BPM은100/136.232 배속). 원곡복귀 시 현재BPM 표시136, 악보BPM136은보존한다.

2026-10-13 최종 표시 결정: 원곡1배속 상태에서는 헤더와 연습BPM 숫자판에 악보BPM136을 표시한다. 수동조절에서는 원음원BPM 기준으로 계산한 지정BPM을 표시한다. 수동136BPM과원곡1배속은화면숫자가같아도재생비율은구분하며 원곡버튼활성표시는 실제배속1.0인지에따른다. 측정136.232는설정→정보에서만표시한다.

###### 원곡/연습 템포 구분 (2026-10-13)
상단 원곡 BPM은 소수점 한 자리로 최근 최대 4박 평균을 표시한다. 매 박만 값이 갱신되며 정지·선택 이동에서는 유지한다. 연습 모드에서는 선택한 BPM을 고정 표시한다. 같은 숫자도 원곡(자연스러운 템포)과 연습(고정 박 간격)을 구분하고 프리셋 선택 표시를 중복하지 않는다. 변환 중에는 기존 준비 진행률을 사용한다.

###### 연습 BPM 입력 경로 통일 (2026-10-21)
- 프리셋은 모달의 BPM 입력값을 먼저 바꾼 뒤, 직접 입력과 동일한 적용 함수를 호출한다. 악보 BPM·원곡 버튼도 같은 입력 경로를 사용하며 원곡 모드의 의미는 유지한다.
- 변환 중에는 메인 화면의 BPM을 유지하고 변환 완료 후 갱신한다. 변환 실패 시 모달 입력값을 현재 적용값과 다시 동기화한다.
- 프리셋은 원곡 BPM에 비율을 곱한 뒤 Math.ceil로 올린 정수 BPM을 사용한다. 최소 입력값도 50%를 올림한 값이다. 설정 검증의 최저 속도 0.5배는 유지한다. 예: 추정136.232 BPM의 최저 프리셋은69 BPM이며 실제 비율은69/136.232이다. (2026-10-21 사용자 정정)
