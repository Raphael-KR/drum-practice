# 개인 음원과 분석 캐시는 기기 내부에서 처리한다

## Context and Problem Statement

서버 분석 공유·익명 등록·검토/승인과 개인 음원 연습의 운영 경계를 단순화하기로 했다. 원래 결정 시기는 2026-10-14~15이며, YAML 날짜는 이번 문서 정리일이다.

## Considered Options

* 분석 API·서버 DB·승인 UI를 유지한다.
* 분석과 해시 기반 재사용을 현재 브라우저 안에서만 수행한다.

## Decision Outcome

2026-10-14 사용자 최종 결정으로 후자를 채택한다. 서버 .drumscore 다운로드는 유지하고 서버 분석 API·자료·인증 경로는 폐기한다. 로컬 캐시 실패가 네트워크 우회로 이어지지 않는다.

### Consequences

과거 원격 DROP 적용·테이블 확인은 배포 기록에 보존한다. 공급자 내부 백업까지 삭제됐다고 주장하지 않는다. 디코딩 상한은 메모리 전체 보증과 다르다. 새 기능·삭제·전송·배포 승인을 추가하지 않는다.

### Confirmation

현행 계약과 실행 절차는 [음원 Rule](../reference/product/audio-practice.md#audio-practice--음원-연습), [보안 Rule](../reference/engineering/security.md#site-security-hardening--공개-사이트-보안과-음원-분석-경계), [발행 기록](../records/releases.md#sites-publication-history--sites-발행공개-확인-기록)에서 확인한다. 아래 당시 검증 수치·실패·미확인은 해당 환경의 기록이며 이번 작업에서 앱·악보 검증을 다시 수행한 결과가 아니다.

##### 남기는 보호 조치

- `server/player-worker.ts`는 HTML 문서와 정적 자산만 제공한다. `/api/` 요청은 404이며 분석정보 읽기/쓰기 경로가 없다. 서버 악보 다운로드는 유지한다.
- Worker 문서 응답: nosniff, Referrer-Policy, X-Frame-Options, HTTPS HSTS. CSP의 frame-ancestors/object/base는 강제하고 전체 리소스 CSP는 보고 전용이다. JS/CSS 정적 전달에도 모두 같은 헤더가 적용된다고 보증하지 않는다.
- 음원 사전 검사: 전체 읽기 전 100MiB, 디코딩 전 30분/2채널/32kHz PCM 256MiB 상한. 메타정보가 거짓일 수 있으므로 디코더의 모든 메모리 사용을 보증하지 않는다.
- 브라우저 캐시: 분석기 버전·해시·유효 숫자/박 배열 검사. 저장 실패 시 기기에서 분석하며 네트워크로 우회하지 않는다. 음원 원본과 기존 보관함·수동 설정은 보존한다.

###### 2026-10-13 — 음원 불러오기 (통합 가져오기 결정 변경)
- 서버의 기존 악보·음원 묶음은 유지한다. 로컬 파일 선택은 [음원 불러오기]로 음원만 받는다. 악보는 목록의 [악보 불러오기]로 내려받는다. 음원 항목에는 `음원` 배지와 `박자 맞추기` 버튼을 표시한다.
- BPM·첫 박을 자동 추정하고 곡명·가수 태그를 읽어 확인 창 없이 저장·연습 화면으로 이동한다. 태그가 없거나 손상되면 명확한 `가수 - 곡명` 파일명을 분리하고 가사/영상 접미사를 정리한다. 구조화된 태그 제목과 파일명이 일치하면 업로더 가수 태그를 보정한다. 구분이 불명확하면 파일명을 로컬 제목으로만 사용하며 가수를 추측하지 않는다. 4/4를 기본으로 사용하며, 필요할 때만 [박자 맞추기]에서 보정한다. 보정 창에서 취소하면 기존 값은 유지한다. 원본 파일은 변경하지 않는다.
- 음원 연습은 파형과 박 눈금을 표시한다. 악보 이미지·악보 보기·음표 효과는 표시하지 않는다. 공통 재생/마커/구간 UX를 유지하며 휴대폰에서도 9개 구간을 노출한다.
- 음원은 현재 브라우저에 보관한다. 같은 파일의 해시·곡명/가수·자동 박자 분석값까지 현재 브라우저에서 저장·재사용함을 안내한다. 다른 기기에서는 처음 한 번 새로 분석한다. 음원과 분석정보는 서버로 전송하지 않으며 검토/승인 UI는 제공하지 않는다. 캐시 조회/저장 실패는 연습을 막지 않는다. 새 음원은 전체 박 시각 추적으로 템포 변화를 따른다. 실제 강박 판정 없이 탐색용 4박 묶음으로 표시한다. 박 정보 없는 기존 음원은 열 때 자동으로 보완한다. 이미 분석한 음원의 추종 끄기 설정은 존중한다. 추종 결과가 맞지 않으면 따라가기를 끄고 고정 BPM으로 보정한다. 추적 중에는 상태를 표시하고, 분석 오류는 표시하고 기존 자료를 보존한다. 4초 미만·30분 초과는 고정 BPM 경로를 유지한다.
