# 재생 위치·선택·구간 표시를 분리한다

## Context and Problem Statement

2026-10-03~13에 마커·선택·구간 입력과 두 줄 탐색을 정정했다. 정지 선택과 실제 재생 시각을 함께 움직이거나 드래그를 구간 등록으로 해석하면 사용자의 탐색을 방해했다.

## Considered Options

* 정지 선택을 재생 위치와 결합하고 구간을 드래그로 등록한다.
* 재생·선택을 분리하고 탭/클릭·더블클릭·Enter로 구간을 등록한다.

## Decision Outcome

후자를 채택한다. 마커는 빨강, 구간은 오렌지, 선택은 파란 테두리다. 화면 유지·마지막 줄·가사 앵커·음표 빛나기의 현행 조건은 규칙 §8·9를 따른다.

### Consequences

초기 선택 파란 배경과 정지 더블클릭 재생, 구간 드래그는 후속 결정으로 대체되었다. 원본 SVG에 UI 표시를 굽지 않는다.

### Confirmation

현재 기준은 [SVG 규칙](../reference/score/rendering.md#svg-score-rules--svg-전체-악보-생성-규칙)을 따른다. 아래 검증·버전·수치는 당시 기록이며 이번 문서 이관에서 시험을 재실행한 결과가 아니다.

### 9. 음표 빛나기 — 화면 효과

- MusicXML 한 줄/두 줄 연습 화면에만 적용한다. PDF와 비교 검수에는 적용하지 않는다.
- 정확한 음표 시작에 켜지고 약140ms 안에 꺼진다. 최대¼박이며 다음 음표 시작에서 이전 효과를 끈다. 동시음은 동시에 켜진다.
- 흰 중심·청록 광륜, 머리가 가장 밝고 기둥/빔은 은은하게 표시. 밝기는 점등 후 감쇠한다.
- 빔은 해당 성부에 연결된 실제 음표 X좌표를 따라 짧은 빛이 이동한다. 지나간 부분을 누적 색칠하지 않는다.
- 카운트오프에는 숨긴다. 되감기·반복·탐색 시 현재 위치로 재계산한다.
- 효과의 타이밍 메타데이터는 SVG 캐시에 담되, 실제 색 효과는 화면 overlay로 만든다. 오선·가사와 원본 XML 색은 변경하지 않는다.

#### 연습 마커 표시
- 연습 화면의 마디 마커는 깃발 문자 대신 붉은색(`#f52d35`) 내부와 짙은 테두리의 북마크를 사용한다.
- 기존 12px 문자 표시의 두 배인 24×24px로 표시한다. 활성 마디에서도 색상·크기를 유지한다.
- 악보제작기·드럼연습실·악보 비교 화면은 `src/shared/ui/marker-icon.ts`의 공통 모양을 사용한다. 원본 악보 SVG에는 삽입하지 않는다.

- 2026-09-23: 연습 화면의 마디 너비·연속 위치·두 줄 배치·가사 기준선은 `src/modules/playback/playback-layout.ts`를 악보제작기와 드럼연습실이 함께 호출한다. MusicXML 원본 및 전체 SVG 페이지 나눔 규칙은 변경하지 않는다.
- 연습 프레임의 진행률·음표 강조·반복 경계 및 영역 높이는 `src/modules/playback/playback-frame.ts`에서 공유한다. 전체 SVG 출력 자체의 변경이 아닌 연습 뷰 공통화이다.

### 2026-10-03 PDF 대응 음표의 가사 위치

PDF의 파란 가사는 검증된 `Region.lyricAnchors`가 있으면 lyricId와 현재 scorePosition의 마디/quarterOffset이 일치할 때만 대응 음표 중심에 배치한다. 좌표는 원본 PDF 영역 기준이며 표시 자르기를 함께 변환하고 crop의 실제 너비로 계산한다. 이 좌표는 일반 가사 겹침 방지의 가로 이동으로 바꾸지 않는다. SVG 또는 사용자가 음악적 위치를 바꾼 가사는 기존 표시 위치 계산을 유지한다. XML·박 진행선은 그대로다. Loveholic265직접대응·4추정 및 실제 검증은 [PDF 가사 위치 수정](../records/songs/loveholic.md#loveholic-pdf-lyric-placement--loveholic-pdf-가사-위치-수정--2026-10-03)을 따른다.

#### 2026-10-03 정지 중 마디 탐색 레이어
- 한 줄/두 줄 및 PDF/MusicXML 공통 마디 컴포넌트에 비상호작용 레이어 적용. 정지 중 현재 선택 마디는 옅은 파란색 + 파란 테두리, 마우스 hover는 옅은 파란색으로 표시한다.
- 마커 마디는 빨간색 레이어 + 상단 빨간선. 선택과 겹치면 빨간색을 유지하고 파란 테두리를 병기한다. 마커 배지도 유지한다.
- 재생 중 선택/hover 강조는 해제하고 기존 진행 표시와 마커 레이어를 유지한다. 터치에는 hover 효과를 강제하지 않는다.

#### 2026-10-03 마디·박자 표시 통일
- 한 줄 보기 진행선 위 마디·카운트·박자는 하나의 파란 박스와 흰 글자로 표시한다.
- 한 줄/두 줄 모두 각 마디 번호 뒤에 박자를 표시한다.

### 반복 구간 선택 (2026-10-13, 드래그 폐기)
빈 슬롯을 누르면 [구간 선택]을 표시하고 마우스 원클릭/터치 탭으로 시작·끝 마디 등록을 준비한다. 터치 드래그는 native 악보 스크롤이며 구간 선택으로 처리하지 않는다. 구간 드래그/pointer capture/경계 자동 스크롤은 제거했다. 마우스 더블클릭과 키보드 Enter 등록은 빈 슬롯 준비 없이 사용할 수 있다. 선택 범위에는 오렌지 강조를 표시하고 선택 중 자동 정렬을 멈춰 화면 이동을 방지한다.

#### 두 줄 일시정지와 탐색 순서 (2026-10-04, 최종 사용자 승인)
정지하면 전체 악보를 원래 마디 순서로 복원한다. 진행 중이던 마디가 아래줄에 있었다면 정지 후에도 아래줄에 두고, 위줄에는 직전 줄을 표시한다. 예: 재생 중 위9~12/아래5~8 → 정지 후 위1~4/아래5~8. 위줄에서 멈춘 경우는 위줄을 유지한다. 마지막 줄은 직전 줄 아래에 둔다. 전체 목록의 DOM 순서를 바꾸지 않으며, 정지 시 스크롤 위치만 맞춘다. 이후 드래그/휠 탐색은 정상 순서로 동작하고 반복 frame이 사용자 스크롤을 되돌리지 않는다.

#### 두 줄 재생 시작 위치 유지 (2026-10-04)
재생 시작 시 실제 시작 마디의 화면 위치를 확인한다. 아래줄에 보이던 마디는 아래줄에서, 위줄 마디는 위줄에서 시작하도록 줄 교체 기준을 설정한다. 이후 기존의 교대 표시 규칙을 유지한다. 앞뒤 반복이 활성화되어 시작 마디가 바뀌면 반복 구간 처음부터 시작하는 규칙을 우선한다. 화면 밖 마디는 기존 위줄 시작 기준을 사용한다.

#### 두 줄 정지 탐색의 화면 유지 (2026-10-13)
정지 상태에서 현재 표시된 두 줄 안의 마디로 선택을 옮길 때는 전체 악보와 스크롤 위치를 유지한다. 윗줄에서 아래 화살표, 아랫줄에서 위 화살표는 같은 열 선택만 옮긴다. 화면에 완전히 보이지 않는 마디로 이동한 경우에만 기존 선택 마디 따라가기 정렬을 적용한다. 최초 표시/크기 변경/보기 전환은 기존 정렬을 유지한다. 실제 마디 영역과 stage 영역으로 판정하며 SVG 원본·마디 시각·재생 중 줄 교체·진행 음영은 변경하지 않는다.

#### 재생 위치와 키보드 선택 분리 (2026-10-13)
한 줄·두 줄 재생선은 같은 빨간색(#e53935)을 사용한다. 파란 진행 음영은 실제 재생선 이전에만 표시한다. 정지 중 방향키는 선택 마디만 옮기며 재생 시각·진행선·음영은 유지한다. M 마커 및 Enter 구간 등록은 선택한 마디를 사용하고, 재생을 누르면 선택한 마디부터 시작한다. 포인터로 재생 위치를 직접 이동하는 기존 동작은 유지한다.

#### 선택 마디 테두리만 표시 (2026-10-13)
정지 중 선택 마디는 파란 테두리만 표시하고 선택용 파란 배경은 사용하지 않는다. 선택 마디를 hover해도 선택용 배경은 생기지 않는다. 실제 재생선 이전의 진행 음영과 마커의 빨간 표시 규칙은 유지한다.

#### 두 줄 방향키 탐색의 줄 위치 유지 (2026-10-13)
화면 안의 선택 이동은 스크롤을 유지한다. 화면 아래로 벗어나는 선택은 새 선택 줄을 두 번째 줄에 배치한다. 화면 위로 벗어나는 선택은 첫 번째 줄에 배치한다. 따라서 아래줄에서 ↓를 누르면 한 줄만 스크롤하고 선택은 아래줄에 남는다. 재생 위치와 진행 음영은 그대로 유지한다.

#### 저장한 연습 구간 표시 (2026-10-13)
화면의9개 반복 슬롯에 등록된 구간은 반복 재생 활성 여부와 무관하게 해당 마디 전체를 옅은 오렌지색으로 표시하고 하단 오렌지선을 둔다. 구간이 겹쳐도 음영을 중첩하지 않는다. 선택 마디의 파란 테두리는 함께 유지하고 마커의 빨간 표시는 우선한다. 삭제/교체 후 표시를 갱신하며 과거 숨긴10~12번째 슬롯은 표시하지 않는다.

#### 태블릿 구간 등록 (2026-10-13)
구간 슬롯을 눌러 선택 모드에 들어간 뒤, 터치 입력은 시작 마디 탭과 끝 마디 탭으로 끝 마디까지 포함해 등록한다. 첫 탭 이후 시작 마디와 끝 마디 대기 안내를 표시한다. 손가락 이동8px 초과/스크롤의pointercancel은 탭으로 처리하지 않으며 시작 마디 대기는 유지한다. 브라우저의 가로·세로 스크롤을 허용하고 일반 마디 탐색 제스처로 전달하지 않는다. 역방향/한 마디 등록도 지원한다. 슬롯 재클릭·Esc·바깥 터치는 취소한다. 마우스는 더블클릭, 키보드는 Enter로 등록한다. 구간 드래그는 제거했다.

#### 마커/구간 색상 통일 (2026-10-13, 사용자 정정)
마커는 빨간색 계통, 구간은 기존 드래그 선택의 오렌지색 계통을 사용한다. 구간 저장 버튼·편집 메뉴·활성 반복 버튼·선택 미리보기·저장 구간 음영/시작끝 경계를 공통 range 색상 변수로 통일한다. 마커 악보 음영도 빨간색으로 맞춘다. 선택 커서의 파란 테두리와 실제 재생선 이전 파란 음영은 기존 규칙을 유지한다.

#### 빈 구간 슬롯 (2026-10-13)
데이터가 없는 구간 버튼은 흰 배경과 기본 테두리/글자색을 사용한다. hover해도 흰 배경을 유지한다. 등록 대기(armed)와 저장된 구간은 오렌지색 규칙을 유지한다.

#### 구간 선택 진입 시 화면 위치 유지 (2026-10-13)
정지 상태에서 구간 슬롯을 눌러 선택 모드에 들어갈 때 악보 트랙을 다시 만들거나 현재 재생 마디로 스크롤하지 않는다. 보고 있는 두 줄과 스크롤 위치를 유지한다. 진행 중에는 기존 일시정지의 순서 복원만 적용하며 구간 선택을 위한 추가 재구성은 하지 않는다.

#### 정지 중 더블클릭 구간 등록 (2026-10-13)
정지 중 악보 더블클릭/두 번 탭으로 재생하던 동작을 공통 재생 화면에서 제거한다. 첫 더블클릭은 구간 시작, 다음 더블클릭은 끝 마디까지 포함해 등록한다. Enter와 같은 대기 상태·슬롯 배정/FIFO/정렬을 공유하며 Enter/더블클릭을 섞어 사용할 수 있다. Esc는 취소한다. 더블클릭은 선택 커서만 해당 마디로 옮기며 실제 정지 시각은 유지한다. 재생 중 제스처와 빈 슬롯 터치 등록은 유지한다.

#### 빈 슬롯의 태블릿 구간 선택 (2026-10-13)
빈 슬롯은 [구간 선택]을 표시하고 태블릿에서 시작·끝 마디를 탭해 등록한다. 마우스 구간 드래그와 자동 스크롤은 제거한다. 마우스 더블클릭/키보드 Enter로 직접 시작한 경우 이 문구를 표시하지 않으며 기존 시작/끝 대기 안내를 유지한다.

#### [구간 선택]에서 마우스 원클릭 등록 (2026-10-13)
빈 슬롯을 눌러 [구간 선택] 상태가 되면 터치 탭과 마우스 원클릭 모두 첫 마디/끝 마디 지정으로 처리한다. 이동8px초과와pointercancel은선택하지않고시작대기는유지한다. 마우스캡처는영역밖이동감지용이며드래그구간등록/자동스크롤은하지않는다. 모드밖에서는기존더블클릭/Enter등록을유지한다.

> 두 줄의 좌우 드래그/휠 탐색은 사용하지 않는다. 한 줄의 좌우 탐색, 정지 상하 탐색·탭 선택, 보기·크기 변경의 정렬은 [SVG 규칙](../reference/score/rendering.md#svg-score-rules--9-음표-따라가기탐색화면-효과)을 따른다. 행 높이·간격은 [같은 정본의 배치 계약](../reference/score/rendering.md#svg-score-rules--8-연습-화면-전용-배치)을 사용한다. 과거 28px 하단 여백·재생 시 무조건 위줄 이동 시안은 현행 규칙을 대신하지 않는다.
