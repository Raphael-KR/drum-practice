# 서로 다른 가사 음절의 음악적 시작점을 구분한다

시작점 중복 금지 결정은 유지한다. 아래 2026-11-11 기록의 32분음표 단위는 후속 [ADR-0032](0032-common-sixty-fourth-unit.md)의 64분음표 공통 기본 단위로 대체됐다. 단위 변경은 기존 가사의 재분할·이동 승인이 아니다.

## Context and Problem Statement

Real Paradis의 순차 음절이 일반·균등 보기에서 겹쳤다. 전환 전후 정본에 같은 시작을 가진30쌍이 있었으며 voice 분리와 MusicXML 문법 적합성만으로는 이 곡의 순차 발음 의미를 보증하지 못했다. 사용자는 “음절의 시작값을 달리 하는 것으로 해결하라”, “가사의 각 음절의 시작값이 겹치지 않는 것을 악보 작성의 원칙으로” 정하고 모든 현행 악보를 검사하도록 지시했다. 처음 전달된64분음표 언급은 사용자가 과거 결정을 불확실하게 기억한 데 따른 착오라고 후속 정정했다. 사용자는 기존32분음표 그리드 결정을 가사에도 적용했어야 한다고 재확인했다.

## Considered Options

- 같은 시작을 유지하고 voice 또는 SVG/앱 좌표만 나눈다.
- 전체 가사를 새 격자로 다시 양자화한다.
- 중복 음절의 시작·필요 음가를 제작 근거에 따라 정본에서 교정하고 현행 악보 전체를 검사한다.

## Decision Outcome

세 번째 방식을 채택한다. 새 제작·교정은 서로 다른 음절의 곡 전체 음악적 시작점을 구분한다. 별도 성부여도 같은 시작은 위반이며 text 없는 extend는 새 음절이 아니다. 길이 구간 중첩은 시작점 동일과 구분한다. 마디 경계를 포함해 유리수로 검사한다. 가사 작성·앵커는 기존32분음표 그리드(사분음표1박당8칸, 4/4 한 마디32칸)를 기준으로 한다. 이 정책은 구형 파일을 여는 즉시 자동 이동·삭제하라는 뜻이 아니다.

[ADR-0029](0029-shared-staff-lyric-voices.md)의 같은 보표·독립 성부 저장은 유지하고, 동시 시작 허용을 새 작성 기준으로 해석하는 부분을 대체한다. 시작이 다른 음절의 음가 구간이 겹칠 때 별도 성부를 쓰는 방식과 구형 동시 시작의 읽기·원문 보존은 유지한다. [ADR-0013](0013-score-based-lyric-positions.md)의 악보 우선·실제 가창 재측정 제외도 유지한다.

[기존32분음표·가사 앵커 결정](../records/archive/adr-0005-practice-layout-and-spacing-sources.md#균등-모드-최종-정정-고정-마디32분-격자-2026-10-04)을 가사와 무관한 표시 규칙으로만 좁혀 해석하지 않는다. 이는 새64분음표 정책을 채택하는 결정이 아니다. 원본에 명시된 연음·더 짧은 음가는 원래 결정처럼 분수 위치를 보존하며 별도 근거/검토로 구분한다.

### Consequences

- 공통 제작 검사는 중복을 보고하며 교정 위치를 자동 생성하지 않는다. 교정은 곡별 판단과 근거 표로 분리한다.
- 앱에서 표시만 이동하거나 epsilon·삭제·병합으로 검사를 통과시키지 않는다. 원본·음악·ID/문구·음원을 보존한다.
- 현행 목록과 보관본을 구분하고, 수록 외 현행 정본까지 검사한다. 앱 수록·DB 변경·배포는 제작 교정과 별도다.

### Confirmation

[실행 계획](../plans/lyric-onsets-20261111.md)과 [Real Paradis 교정·전수검사 기록](../records/archive/lyric-onsets-20261111.md)에 실제 검사·교정·미검증 범위를 남긴다. 정책 채택은 실제 화면/청취 검증 완료를 뜻하지 않는다.
