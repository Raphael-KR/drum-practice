# 오선 부착 표기의32분음표 상위 규칙 문서화 — 2026-11-11

이 문서는 당시 결정·검증 기록이다. 후속 [ADR-0032](../../decisions/0032-common-sixty-fourth-unit.md)가 기본 단위를 64분음표로 대체했다. 아래 0.125 단위 도구 변경 지시도 대체됐으며 [새 문서 반영·구현 상태](staff-grid64-rule-20261112.md)를 따른다.

- 목표: 사용자가 확정한 모든 오선 부착 표기의 공통32분음표 기준을 악보 작성 상위 Rule로 명시한다.
- 범위: 제작/입력/저장/조판/도구 Rule과 실행 절차·스킬·프로젝트 지침·Rule 목록·MADR 참조.
- 완료 조건: 하나의 상위 정본에서 모든 표기의 범위·단위·앵커를 정의하고 반대되는 하위 조항을 정리한다.
- 제외: 앱/제작 도구 코드·MusicXML·수록 자료·DB·history.md 변경, 렌더링·시험 자료 생성·커밋·배포.
- 검증: 문서/링크/앵커, 남은 하위 규칙 검색, 비대상 파일 해시 보존·Git diff 공백 검사.

## 반영

사용자 원문: “오선에 붙어 있는 모든 표기는32분음표 그리드를 사용하는 거야. 알겠어? 이걸 분명한 악보 작성 상위 규칙으로 명시해.”

정본은 [제작 상위 Rule](../../reference/score/production.md#score-production-rules--오선-부착-표기의-32분음표-그리드)이다. 음표·쉼표·가사·섹션·연주 지시·셈여림·크레센도/디크레센도·아티큘레이션·주법·스티킹 등 모든 오선 부착 표기를 대상으로 명시했다. 사분음표당8칸,4/4 한 마디32칸이며 특정 보기나 가사로 범위를 축소하지 않는다. 기호의 자체 크기·조판 여백·세로 위치와 공통 음악적 가로 앵커는 구분한다. 원본의 명시 연음/더 짧은 음가는 기존 결정대로 같은 기준 격자 위의 유리수 위치로 보존한다.

입력/저장/SVG Rule, 절차와 스킬·프로젝트 AGENTS 및 Rule 목록은 상위 정본으로 연결했다. [ADR-0031](../../decisions/0031-shared-staff-notation-grid.md)에 이유·대체된 해석·이행 경계를 기록하고 기존 ADR-0030을 하위 가사 조건으로 연결했다.

## 발견한 하위 충돌과 이행 경계

조판 Rule의 연주 지시 표시 이동0.0625박과 균등 보기의32분음표 격자는 별개라는 조항이 상위 지시와 충돌했다. 문서의 표시 offset 탐색 단위를0.125박(32분음표)으로 정정하고 divisions96에서12divisions임을 명시했다. 공통 도구 Rule도 상위 단위를 참조하도록 바꿨다. 과거 원문·검증 기록은 재작성하지 않았다.

실제 `tools/score-production/musicxml/common/direction-offset.mjs`는 아직 `STEP = 1 / 16`이다. 이번 요청은 상위 규칙의 문서화이므로 구현을 조용히 바꾸지 않았다. 향후 이 도구로 새 제작을 할 때 상위0.125박 단위로 수정·검증해야 하며, 문서 정리만으로 도구 반영 완료 또는 기존 악보 전수 적합을 주장하지 않는다. 일반/균등 조판의 실제 좌표 반영도 별도 구현·검증 대상이다.

로컬 증거 `data/production/staff-grid-rule-20261111/`에 변경 전 문서와 비대상 해시·최종 검증을 보존한다. 기존 다른 작업의 dirty 변경은 유지했다. 앱/도구 코드·악보·수록 자료·history는 이번 작업에서 바꾸지 않았다.

## 승인 문구 구체화 — 2026-11-12

- 목표: 사용자가 승인한 선언문과 6개 조항을 기준 문서에 그대로 반영한다.
- 범위: 제작 상위 Rule, 연결된 MusicXML·SVG Rule의 표현, 기존 ADR과 이 실행 기록.
- 완료 조건: 적용 범위를 유지하면서 단위·위치 결정·기준점·표시 이동·원본 리듬 예외·검증 기준을 명확히 구분한다.
- 제외: 앱·제작 도구 코드·악보·수록 자료·DB·history.md 변경, Git 커밋·push·merge와 외부 인계.
- 검증: 승인 문구 대조, 하위 규칙·절차·스킬의 참조 확인, 문서 링크·앵커와 diff 공백 검사.

사용자 승인: “상기 제안 승인. 상기 내용으로 기준 문서를 바꿔라.”

### 변경과 판단

제작 상위 Rule의 선언문과 세부 조항을 승인안으로 교체했다. 그리드만 보고 음절을 임의 분할·이동하지 않도록 위치 결정의 근거를 명시하고, 근거가 부족한 위치는 미확정으로 남기도록 했다. 그리드 준수와 원본 위치 일치는 각각 검증하도록 구분했다.

MusicXML의 가사 시작점 계약은 단위·위치 결정·예외를 상위 Rule에 연결하고 미확정 위치의 처리 문구를 맞췄다. SVG의 표시 offset 단위는 박자 해석에 혼동이 없도록 “32분음표 길이(사분음표의 ⅛)”로 표현했다. 기존 같은 줄 제한·최소 여백·높이 분리 조건은 유지했다.

승인 이유와 해석 보완은 기존 [ADR-0031](../../decisions/0031-shared-staff-notation-grid.md)에 추가했다. 프로젝트 지침·제작 절차·스킬·Rule 목록의 상위 정본 링크가 이미 존재하므로 규칙 본문을 다시 복제하지 않았다. 문서의 기존 명시 앵커도 유지했다.

`direction-offset.mjs`의 `STEP = 1 / 16` 잔여 구현을 다시 확인했다. 위에서 기록한 구현 이행 과제는 그대로 남으며, 이번 문구 정리가 코드 수정이나 악보 전수 검증을 뜻하지 않는다. 변경 전 문서와의 대조 범위는 `production.md`, `musicxml.md`, `rendering.md`, ADR-0031 및 이 실행 기록의 다섯 파일이다.

### 검증 결과

- 승인 선언문과 6개 조항의 본문 일치, 적용 대상과 기존 하위 계약 참조 유지 확인.
- `scripts/checks/check-docs.mjs`: Markdown 165개, 로컬 링크 4,693개, Markdown 앵커 링크 3,429개 통과. 이력 문서의 폐기 주소 링크 119개는 기존 이관 목록으로 확인하며 외부 URL·절대경로·비 Markdown 앵커는 이 검사의 대상이 아니다.
- `git diff --check`: 공백 오류 없음.
- 코드·악보·화면의 실행 검증은 수행하지 않았다. 이번 결과는 문서 정합성 검사다.
