# 현행 악보 정본 전수 감사 — 2026-11-12

문서 역할: **현행 기준에 따른 전체 검토 보고서·수정 우선순위**. 판정은 [64분음표 공통 기본 단위](../../reference/score/production.md#score-production-rules--오선-부착-표기의-공통-기본단위)와 [ADR-0032](../../decisions/0032-common-sixty-fourth-unit.md)를 적용한다. 이 보고서는 새 Rule이나 교정 완료 기록이 아니다.

이번 갱신에서는 결론·곡별 상태·항목별 판정과 [수정 우선순위](#correction-priorities)를 새 기준으로 다시 작성했다. 정본·Rule·앱 코드·패키지는 변경하지 않았다. 이전 보고서는 로컬 재현 근거의 `grid64-report-update/before-documents.json`에 보존한다.

후속 사용자 승인 세 항목을 포함한 교정·검증과 6곡의 로컬 앱 수록을 완료했다. 실제 결과와 남은 가사 근거의 한계는 [교정·검증 기록](canonical-corrections-20261112.md)을 따른다. 아래 판정은 교정 전 입력에 대한 감사 결과로 보존한다.

## 결론

현행 6곡의 드럼 음표·음가는 보존된 원본 판독·작곡 명세와 일치하고 저장 구조도 유효하다. **이전 표시 offset 9곳은 64분음표 기준에 맞으므로 단위 오류 교정 대상에서 제외한다.** 가사 시작 항목 1,085개의 시작·길이도 새 단위에 맞으며, 원본의 연음 21개는 정확한 분수 리듬으로 유지한다. 이 기준 변경만으로 기존 음표·가사를 다시 나누거나 이동하지 않는다.

남은 정본 교정 대상은 붉은 노을의 일부 크레센도·지시 적용 박, 섹션 필수 속성 39곳과 글꼴 기록 4곡이다. 가사 위치의 근거 부족과 문서의 적용 범위는 별도 검토 대상으로 유지한다. **단위 적합은 원본 위치 일치·최소 여백·앱 지원 완료를 뜻하지 않는다.** 검사기·편집·균등 조판 등의 구현 미반영도 별도 후속 작업이다.

## 정본 항목별 판정

### 1. 붉은 노을의 크레센도 시작·끝

원본 PDF `data/production/red-sunset/source/source.pdf`의 선 끝과 음표 좌표를 대조했다. 표의 박 번호는 1부터 세며, `quarterOffset`은 마디 시작 0부터 세는 사분음표 단위다.

| 구간        | 현행 XML                            | 원본 대조 결과·권고                                                                             |
| ----------- | ----------------------------------- | ----------------------------------------------------------------------------------------------- |
| 48–49마디   | 48마디 1박 시작 → 49마디 끝         | 48마디 **2박**에서 시작한다. 끝은 49마디 **4박 음표**에 대응하므로 종료점도 함께 교정 검수한다. |
| 96–97마디   | 96마디 1박 시작 → 97마디 끝         | 같은 원본 패턴이다. 96마디 **2박** 시작, 97마디 **4박 음표** 종료를 기준으로 교정 검수한다.     |
| 110–111마디 | 110마디 **1.5박** 시작 → 111마디 끝 | 원본 시작은 110마디 **2박**이다. 시작 `quarterOffset=0.5`를 `1`로 교정할 대상이다.              |
| 112–113마디 | 112마디 2박 → 113마디 2.5박         | 이전 사용자 교정값과 원본이 일치한다. 유지한다.                                                 |

48·96마디 원본 시작 x=347.360974는 2박 머리 x=345.175303에 대응한다. 110마디 시작 x=74.244645는 2박 머리 왼쪽과 정확히 같다. 49·97마디 끝 x=547.374410은 마지막 4박 음표 줄기 x=546.441934 부근이며, 마디 끝 x=566.7973과는 약 19.42pt 차이다. 112–113마디는 원본 시작 x=319.836298, 끝 x=472.646563으로 기존 교정 근거와 일치한다.

**판단:** 원본의 음악적 위치를 보존하는 Rule을 유지하고 정본을 교정한다. 종료점은 원본의 음표 대응과 새 공통 조판 출력을 함께 확인한다. SVG 좌표 보정으로 잘못된 XML 위치를 숨기지 않는다.

원인 근거: `red_sunset.py`의 고정 wedge 표에 기존 값이 남아 있다. 기존 `red_sunset_verify.py`는 전곡 음표·음가·악센트·연음을 검사하지만 wedge 시작·끝을 원본과 대조하지 않는다. 따라서 기존 전곡 음표 검사 통과가 이 위치의 정확성을 보증하지 않았다. 재발 방지를 위해 교정 시 해당 입력 표와 독립 기대값 검사도 갱신해야 한다.

근거: `hairpin-source-audit.json`, `source-hairpin-candidates.json`, 원본 2·3쪽 PNG, `audit.json`의 전체 방향 지시 목록.

### 2. 붉은 노을 105·134마디의 음악적 적용 박

현행 두 `words`는 **XML cursor=0**에 있고, `<offset sound="no">`만 각각 174·168 divisions(1.8125·1.75 quarter)로 지정됐다. 따라서 음악적 적용 시점은 둘 다 1박이며, 뒤로 옮긴 것은 표시 위치뿐이다.

- 105마디 `H.H OPEN (o) →`: 원본 글자 시작 x=479.711035가 2박 음표 왼쪽과 정확히 같다.
- 134마디 `손발 안맞춰도 좋으니 맘껏 후려주세요!`: 원본 글자 시작 x=88.570342, 2박 머리 x=88.651474로 차이는 0.081pt다. 사용자의 “2박에서 시작” 지시와도 부합한다.
- 비교용 30마디 글자 시작은 1박 머리에서 0.519pt 차이이며, 현재 음악적 적용 시점 0과 일치한다.

[과거 교정 기록](../songs/red-sunset.md)은 표시만 옮기고 음악적 cursor 0을 유지했다고 명시한다. 이 사실과 최신 “적용 박도 원본과 동일” 기준은 구분해야 한다.

**판단:** 원본·사용자 지시를 기준으로 두 지시의 적용 시점을 `quarterOffset=1`로 교정하는 것을 권한다. 표시 offset은 그 음악적 위치에서 별도로 다시 찾는다. 기존 offset 숫자를 그대로 재사용하면 표시가 한 박 더 밀린다. 문서의 적용 박 보존 규칙을 완화할 사유는 확인하지 못했다. 이번에는 값을 바꾸지 않았다.

근거: `word-source-anchors.json`, 원본 3·4쪽 PNG, `audit.json`. 섹션 충돌 때문에 원본 자체가 오른쪽으로 배치된 다른 지시의 적용 박까지 단순한 글자 x좌표로 결정하지 않는다.

### 3. 표시 offset 9곳 — 새 기본 단위에 적합

현재 공통 기본 단위는 사분음표의 1/16, 즉 0.0625다. 아래 9곳은 모두 그 정수배다. 음악적 적용 박과 별개인 표시 이동량의 단위만 판정한 결과다.

| 곡·마디                   | 현행 표시 offset(quarter) | 64분음표 칸 수 |
| ------------------------- | ------------------------: | -------------: |
| 갑자기 5                  |                    0.4375 |              7 |
| 붉은 노을 30·78           |                    0.8125 |             13 |
| 붉은 노을 34·58·66·82·106 |                    1.0625 |             17 |
| 붉은 노을 105             |                    1.8125 |             29 |

**판단:** 이전 단위 위반 판정을 해소한다. 새 단위에 맞춘다는 이유로 이 값들을 이동·반올림하지 않는다. 다만 붉은 노을 105마디는 §2의 음악적 적용 박 문제가 별도로 남아 있다. 그 적용 박을 교정하면 표시 offset도 새 기준점에서 다시 계산해야 한다. 134마디도 같은 이유로 재계산한다.

`common/direction-offset.mjs`의 `STEP = 1 / 16`은 현행 기준과 일치한다. 이를 0.125로 바꾸라는 이전 권고는 철회한다. 글꼴·섹션 속성·음악적 기준점·조판기가 바뀐 구간에서는 동일한 공통 조판기·Pretendard·폭으로 0.0625씩 탐색해 최소 여백·같은 줄·높이 분리·재열기를 검수한다. 나머지 offset까지 충돌이 없거나 최소라고 이번 정적 검사로 보증하지 않는다.

### 4. 섹션 위치 필수 속성 39곳

[현행 조판 입력 계약](../../reference/score/rendering.md#svg-score-rules--공통-xml-위치-계약)은 `default-x="0"`, `relative-x="0"`, `halign="left"`, `justify="left"`를 명시하도록 요구한다.

- 갑자기 12곳·붉은 노을 14곳: `relative-x="0"`만 없다.
- 탐탐 무빙 연습 7곳·시작 전 손 풀기 6곳: 위 네 속성이 모두 없다.
- Loveholic 8곳·바람과 언덕의 발라드 9곳: 네 속성이 모두 있다.

**판단:** 정본에 누락 속성을 보완한다. `relative-x` 미기재가 곧 눈에 보이는 정렬 오류라는 뜻은 아니다. 현재 렌더러 기본값으로 맞아 보이는 것과 명시적 작성 계약 충족은 별개다. 보완 후 실제 테두리 바깥선 정렬을 검사한다.

### 5. Pretendard 기록 미반영 4곡

[글꼴 Rule](../../reference/score/rendering.md#svg-score-rules--악보-텍스트-글꼴)은 XML의 `word-font`, `lyric-font`, 텍스트 `font-family`에도 Pretendard를 기록하도록 한다.

- 바람과 언덕의 발라드: 기본 word/lyric 글꼴이 없고 섹션 9곳에 `YuMincho`가 남아 있다.
- Loveholic·탐탐 무빙 연습·시작 전 손 풀기: 기본 word/lyric 글꼴과 텍스트의 Pretendard 지정이 없다.
- 갑자기·붉은 노을: 기본 두 글꼴과 명시된 텍스트 글꼴이 Pretendard다.

**판단:** 네 정본의 텍스트 글꼴 기록을 통일한다. 음악 기호 글꼴은 건드리지 않는다. 현재 앱이 글꼴을 통일해 보여주는 것만으로 입력 누락을 완료 처리하지 않는다. 글꼴 변경 뒤 지시문 배치를 다시 검수한다.

## 원본 정확성 미확정으로 구분할 사항

### 바람과 언덕의 발라드 가사 30쌍

515개 가사 시작·길이는 모두 현행 64분음표 기본 단위로 표현되며 같은 시작은 없다. 기존 32분음표 값도 새 기본 단위의 정수배이므로 재분할할 필요가 없다. 다만 [11월 11일 교정 기록](lyric-onsets-20261111.md)은 24마디의 30쌍을 기존 ¼박 구간에서 두 ⅛박으로 나눈 **편집 판단**으로 설명한다. 초 단위 아카이브는 앞뒤 순서의 근거이며, 정확한 ⅛박 위치·길이의 원본 악보 근거는 아니다. 원본 드럼 PDF에도 해당 가사 음가가 있다는 근거가 확보되지 않았다.

영향받은 60개 항목 중 22개는 기존 `confirmed=true`를 유지한다. 이는 이전 확인 상태 보존이며 새 위치가 원본과 맞는다는 증거가 아니다.

**권고:** 그리드 검사를 통과했다는 이유로 원본 일치로 승격하지 않는다. 이 위치들은 편집 교정·근거 미확정 상태를 명확히 하고, 원본 또는 명시적으로 승인된 교정 기준을 확보한 다음 필요한 값만 고친다. 이전 중복 시작으로 자동 복구하거나 다시 임의 분할하지 않는다. Rule은 유지한다. 문서에서는 `confirmed`가 문구 확인인지 위치 확인인지, 구형 확인 상태의 보존인지 구별할 기준을 보완할 필요가 있다.

### Loveholic의 판독 추정·갑자기의 마디 문구

Loveholic 269개와 갑자기 301개는 ID·문구·시작·전체 길이가 보존된 PDF 가사 판독 자료와 전수 일치했다. Loveholic 48·99·107·109마디의 네 위치는 기존 추정으로 기록되어 있고, 이번에도 원본 음가 확정으로 승격하지 않는다.

갑자기의 불확실한 7문구는 시간값 없는 `measureLyrics`로 유지된다. ID·마디 ID·문구·배치 값이 판독 자료와 같다. 임의 박을 만들지 않은 처리는 현행 계약에 맞으므로 유지한다. 실제 가창 시각·길이를 추가 측정할 필요는 없다.

## 유지할 데이터와 검증 근거

다음 중 64분음표 단위 집계·정본/패키지 해시는 이번 보고서 갱신에서 확인했다. XSD·원본 판독 대조·공통 API 왕복 등은 입력과 코드가 유지된 기존 감사 증거다.

- 6곡 모두 MusicXML 4.0 XSD 통과. 단일 드럼 파트, 성부 시간축·마디 길이·음가/타입·chord·backup·매핑 참조 검사에서 위반 없음. 가사 소유 성부를 드럼 쉼표로 오인하지 않았다.
- 실제 모든 드럼 마디가 보존 판독/작곡 자료와 일치한다. 원본 개별 의미의 새 독립 이중 판독이나 “전곡 정확도 100%”를 뜻하지 않는다.
- 바람과 언덕의 발라드 72·100마디의 12개 여섯잇단음표, 붉은 노을 131마디의 9개 셋잇단음표는 원본 리듬과 일치하는 기본 단위의 예외다. 정확한 분수 위치·음가를 유지하며 64분음표로도 반올림하지 않는다.
- 가사 시작 항목 1,085개: 64분음표 기준 시작·전체 길이의 이탈 0, 동일 음악적 시작 0. 기존 감사의 소유 note ID·음절 ID 중복 0과 가사 음표의 숨김·가사 표시·무음 속성·단일 보표 소유 블록도 유지된다.
- 현행 divisions 48·96·4는 필요한 기존 음가를 표현한다. 기본 단위 통일만으로 16으로 고정하거나 일괄 환산하지 않는다.
- 붉은 노을 O+ 6곳은 같은 음표의 `harmonic`·`stopped` 순서, 같은 Y·좌우 X 기록을 유지한다. Loveholic 반열림 20곳은 `half-muted smufl="pictHalfOpen1"`이다. 이번에 실제 SVG 잉크 간격까지 다시 측정한 것은 아니다.
- 전사 4곡의 원본 표제 존재·기존 표제 대응을 확인했다. 붉은 노을의 임의 `기보된 카운트`는 현행 정본에 없다. 원본 글꼴의 ToUnicode 문제로 문자 추출에서 빠진 Verse/Chorus 표제는 PDF 화면으로 구분했으며 누락이라고 판정하지 않았다.
- 원본 줄 구성은 Real Paradis 28줄·Loveholic 32줄·붉은 노을 35줄의 시작점과 일치한다. 갑자기는 위 반복 경계 1곳을 별도로 기록했다.
- 표시 제목/원제, 실제 가수 및 연습곡의 SoCal·Portland 드럼킷 이름이 유지된다. `시작 전 손 풀기`는 두 제목이 모두 정확하다.
- Loveholic의 악보 BPM 136, 음원 추정 BPM 136.232·첫 박 약 0.193초는 분리 저장되어 있다. 다른 곡의 원래 BPM·음원 연결도 재읽기에서 유지됐다.
- 수록 6패키지의 `source`와 `canonicalXML`은 현행 제작 XML과 바이트까지 같다. ZIP CRC·자산 크기·원음원 SHA·대체 원본 PDF SHA를 확인했다.
- 현재 공통 `readScorePackage`, `readCanonical`, `writeCanonical`로 실제 자료를 메모리에서 재읽기·직렬화했다. 6곡 모두 결과 XML이 입력과 바이트까지 같고 두 번째 저장도 안정적이다. Song의 의미 변화는 없었다. 없는 작곡자/작사자 값이 빈 문자열로 정규화되는 경우만 별도로 기록했다.

전수검사에서 발견한 사실과 수정 제안을 이 기록에 남겼다. 검사기의 전체 객체 비교는 제작 판독 자료에만 있는 provenance 필드, 패키지의 선택적 빈 문자열 정규화까지 차이로 표시했으므로 계약 필드와 별도로 판정했다. 대체 PDF 형식을 잘못된 키로 조회한 첫 진단은 읽기 중 실패했으며 실제 manifest의 `source.type`으로 확인했다. 자료·정본을 수정하여 검사를 맞춘 사례는 없다.
