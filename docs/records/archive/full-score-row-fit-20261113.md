# 전체 SVG의 기준 줄 폭과 변박 줄 축소 — 2026-11-13

## 목표와 범위

사용자가 지적한 Real Paradis 전체 보기의 폭 오류를 두 앱의 공통 조판 경로에서 수정한다. 일반 4/4 네 마디 줄은 좌우 여백까지 채우고, 81–84마디처럼 넘치는 줄만 두 축을 같은 비율로 줄인다. 원본 줄 구성·정본·시간축·가사와 연주 1줄/2줄 동작은 유지한다. 짧은 줄은 늘리지 않는다.

## 원인과 수정

- 시간 비례 조판과 첫 줄 지시 공간은 공유했지만 전체 보기에는 초과 줄 축소가 연결되지 않았다. OSMD의 수평 캔버스가 가장 긴 줄에 맞춰 커졌고 이미지 전체를 화면에 맞추면서 일반 줄까지 작아졌다.
- 수정 전 일반 줄의 오선 폭은 1,209.9784 SVG단위, 81–84마디는 1,358.4352단위, 전체 viewBox 폭은 약 1,459.0352단위였다. 84마디의 5/4 리듬과 줄 끝 4/4 예고 기호도 폭을 차지한다.
- `full-score-width.ts`가 일반 4/4 네 마디 줄의 native 폭을 기준으로 공통 `rowScale`을 적용한다. OSMD가 시스템을 그리기 전에 변환 그룹을 만들고 그 안에 음표·가사·기호·번호·오선을 함께 그린다. 완성 SVG의 기호를 개별 이동하거나 곡별 예외를 넣지 않는다.
- 연속 세로 배치는 축소된 skyline/bottomline을 사용한다. 마디 영역·오선 위치도 그리기와 같은 변환을 공유한다. 제목·부제·BPM·가수와 캔버스 좌우 여백을 기준 폭에 맞춘다.
- 전체 보기 캐시를 `full-score-continuous-v12-row-fit`으로 구분한다. 연주 조판의 캐시와 시간 비례 배치식은 바꾸지 않는다.
