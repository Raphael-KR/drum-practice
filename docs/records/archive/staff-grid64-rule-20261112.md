# 64분음표 공통 기본 단위 문서화 — 2026-11-12

문서 역할: **변경·검증 기록**. 현행 규칙은 [제작 상위 Rule](../../reference/score/production.md#score-production-rules--오선-부착-표기의-공통-기본단위), 결정 이유는 [ADR-0032](../../decisions/0032-common-sixty-fourth-unit.md)에 둔다.

후속 [전체 검토 보고서와 수정 우선순위](canonical-rule-audit-20261112.md#correction-priorities)는 새 기준으로 갱신했다. 아래 문서화 당시 수치와 코드 미반영 상태는 그대로 구분해 보존한다.

- 목표: 승인된 64분음표 공통 기본 단위를 오해 없이 문서화한다.
- 범위: 제작·MusicXML·표기·조판·도구 기준, 관련 절차·스킬·프로젝트 지침과 결정·변경 기록.
- 완료 조건: 현행 참조가 한 기준을 가리키며 음가·원본 예외·표시 이동 조건이 일치하고 이전 결정과 코드 미반영 상태를 구분한다.
- 제외: 악보·앱·제작 도구 코드·패키지·DB·미디어 변경, 조판 재생성·화면/청취 검사·커밋·push·배포.
- 검증: 문서 서식·로컬 링크·앵커·수치·변경 diff, 작업 전후 비대상 파일 해시 대조.

## 변경 범위

- 음악적 위치·음가와 허용된 표시 이동에 같은 기본 단위를 적용했다. 4/4 64칸·6/8 48칸, divisions 96에서 6의 예와 균등 보기의 좌표식을 맞췄다.
- 기본 단위 변경과 음표 분할을 구분하고, 임의 분할·이동·반올림 금지와 원본의 정확한 분수 리듬 보존을 명시했다. 기호 자체 폭·여백·세로 위치는 기존 조판 기준을 유지한다.
- 가사 저장 단위와 편집 조작 간격을 구분했다. 필요한 경우에만 divisions와 duration/backup/forward/offset을 함께 환산하도록 명확히 했다.
- 단위 중립적인 상위 Rule 앵커를 만들고 현행 참조를 갱신했다. 이전 32분음표 앵커는 과거 링크를 위해 보존한다.
- 문서 체계의 새 결정 대체 절차에 따라 ADR-0032를 추가하고 ADR-0031을 superseded로 연결했다. ADR-0030의 시작점 중복 금지와 기존 검증 수치는 보존한다.
- 이전 감사의 표시 offset 9곳에 대한 32분음표 판정은 새 단위 결정으로 대체됐다. 원본 위치·적용 박·최소 여백·가사 근거에 관한 나머지 판단은 유지한다.

## 직전 검토의 기존 자료 대조

현재 입력 `data/production/lyric-onsets-20261111/<곡 식별자>/score.musicxml` 6곡·587마디를 읽어 유리수 위치·음가를 확인한 결과를 재사용한다. 이 문서 변경만을 위해 같은 음악 검사를 반복하지 않았다.

- 가사 시작 항목 1,085개의 현재 시작·길이는 모두 새 기본 단위로 표현된다. 원본 가사 위치의 정확성까지 확인한 결과는 아니다.
- 갑자기 5마디와 붉은 노을 30·34·58·66·78·82·105·106마디의 표시 offset 9곳은 새 기본 단위에 맞는다. 충돌·최소 여백·표시 이동량의 최소성은 별도 검증이다.
- 바람과 언덕의 발라드 72·100마디의 12개 여섯잇단음표와 붉은 노을 131마디의 9개 셋잇단음표는 분수 리듬으로 보존할 예외다.
- 현재 divisions는 일반 4곡이 48 또는 96, 연습곡 2곡이 4다. 기존 음가를 그대로 둘 때 모두 재작성할 필요가 없다. 새로 추가하는 세밀한 값이 기존 divisions로 표현되지 않을 때만 환산한다.
- 입력 식별·원본 대조의 상세 범위는 [전수 감사](canonical-rule-audit-20261112.md)에 보존한다.

## 검증 결과

- 기준 문서 5개·새 ADR·이 기록의 Prettier 검사를 통과했다. 생성 UI 문서 검사와 `git diff --check`도 통과했다.
- 문서 168개, 로컬 링크 4,769개, Markdown 앵커 링크 3,461개를 검사했다. 폐기 주소를 가리키는 과거 링크 119개는 기존 이관 목록으로 확인했다. 외부 URL·절대경로·비 Markdown 앵커는 이 검사의 대상이 아니다.
- 현행 기준·절차·스킬에서 이전 단위 요구를 검색했다. 남은 32분음표 표기는 과거 링크용 앵커와 기존 `grid32` 출력 해석 안내이며 현행 기본 단위로 사용하지 않는다.
- 변경 전후 본문에서 원본 우선·임의 분할/반올림 금지·분수 리듬 보존·음악적 적용 박 유지·충돌 여백과 줄 제한을 대조했다. 4/4와 6/8 칸 수, 음가 환산, offset 및 균등 좌표식의 단위를 확인했다.
- 기존 파일 768개 중 변경은 문서 20개뿐이고 삭제는 없다. 나머지 748개는 해시가 같으며 앱·제작 도구 코드와 현행 정본 6개·수록 패키지 6개를 포함한다. 새 파일은 ADR과 이 기록 2개다.
- 작업 전 본문·해시와 변경 diff·검사 결과는 로컬 `data/production/staff-grid64-rule-20261112/`에 보존했다. 새 SVG·앱 저장·청취·빌드 검사는 수행하지 않았다.
