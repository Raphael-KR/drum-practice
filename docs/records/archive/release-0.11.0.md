# 0.11.0 SVG 전체 보기 가사·코드 정리 릴리스

## 범위와 버전

누적된 코드·CSS·주석·문서 정리, SVG 전체 보기의 공통 가사 표시와 마디 번호 오류 수정, Loveholic 교정 수록본을 함께 반영한다. SVG 전체 보기의 가사는 새 사용자 기능이므로 두 앱을 0.10.8에서 0.11.0 minor로 올린다. 악보제작기는 PC 로컬 전용이며 공개 대상은 드럼연습실이다.

사용자가 종료한 구형 개별 ZIP 백업·CLI 래퍼·문서 안내 주소·D1/Drizzle 연결을 제거한다. 현재 전체 백업·복원, `.drumscore`, JSZip, 브라우저 저장 계약과 Worker 보안 헤더는 유지한다. SQL 원문은 기록 폴더에 보존하고 원격 DB는 변경하지 않는다. 정리별 근거는 [코드 정리 기록](../code-maintenance.md), 기존 번들·SQLite 경고의 유지 기준은 [검증 기준](../../reference/engineering/verification.md)을 따른다.

## 검토와 로컬 검증

- 기존 미푸시 문서 커밋 `b726ffa`와 요청된 미커밋 변경 전체가 대상이다. 신규 모듈의 책임·참조, 저장 DB/키/패키지, 현재 편집·악보 교체 진입점, 공통 가사 배치, 배포의 D1 제거·자산 일치 경로를 자체 검토했다. 독립 검토로 표현하지 않는다.
- 사용자 승인 범위에서 기존 fixture·메모리 데이터·fake-indexeddb·임시 SQLite DB를 사용했다. Node 22.22.2·pnpm 12.18.0의 `pnpm run verify`가 통과했다: lint·472파일 서식·타입·i18n·공통 구조/경계·문서 링크/앵커·17로컬 자산·131파일 814테스트·두 앱 빌드와 player 공개 경계.
- 최초 전체 검사의 편집 UI 3개가 실패했다. 같은 파일은 단독 26/26 통과했으며 첫 편집창 준비의 기본 1초 대기 실패 뒤 후속 검사가 영향을 받았다. 실제 미디어 읽기·저장이 끝나 편집창이 열리는 동일 조건을 최대 5초 기다리게 수정했다. 검사 조건·제품 코드는 완화하지 않았으며 전체 814테스트를 다시 통과했다.
- 릴리스 중 PRD의 구형 ZIP 지원 문구를 확정된 지원 종료 범위와 맞췄다. 수록 패키지 6개의 릴리스 시작 시점 해시를 보관하여 main 빌드와 대조한다. 원본/수록 패키지를 추가로 가공하지 않는다.
- 증거는 `.tmp/release-0.11.0/`의 전체 검사 로그·`input-baseline.json`·화면 캡처·보존 대조에 남긴다. 기존 Vite 500kB 청크 경고와 Node SQLite 실험 API 경고는 비차단으로 유지한다.

## Safari 화면·조작 확인

- 로컬 `127.0.0.1:5173`의 Safari MCP 전용 탭에서 Loveholic을 목록에 불러오고 재열었다. 1줄·2줄 표시, 카운트오프, 2줄 실제 재생이 5마디를 지나 10마디까지 진행되고 일시정지되는 것을 확인했다. 실제 네이티브 AudioContext는 32kHz·running 상태였고 시간이 증가했다. 청취·전곡 안정성·문제가 보고된 iPhone의 재현 결과로 확대하지 않는다.
- 전체 SVG의 가사와 1·3·7·11 등 줄 첫 마디 번호, 마디 시작점에 정렬된 첫 섹션을 캡처로 확인했다. 내부 `d-m…` 문자열은 표시되지 않았다. 109 BPM 프리셋 적용 후 원곡으로 복귀했다.
- Safari 네이티브 Window 메뉴에서 MCP 창을 찾지 못해 응답형 디자인 모드 조작을 완료하지 못했다. Safari MCP 크기 조절을 사용하고 실제 `innerWidth/innerHeight`를 확인했다. 이 도구가 창 바깥 크기를 바꾸는 차이를 보정했으며 실제 폰 가로 852×393, 폰 세로 393×852, 태블릿 폭 768×946에서 확인했다. 마지막 높이는 데스크톱 화면 제한으로 1024가 아니며 iPad 기기 프리셋 검증으로 표시하지 않는다.
- 폰 가로의 악보 전용 화면·설정/BPM 카드와 고정 음량, 폰 세로/태블릿 폭의 상단·하단 공통 조작판을 캡처로 확인했다. PC 제작기는 1280×800에서 현재 편집 진입점의 곡 정보·가사 탭, 악보 교체 및 새 곡/완성 패키지 입력 창을 확인했다. 실제 교체·새 곡 생성은 실행하지 않았고 해당 저장 경로는 전체 회귀 검사로 검증했다.
- 검수 후 변경 입력 없이 모달을 닫고 검사 전용 탭만 종료했다. 기존 Safari 창과 개발 서버는 유지했다. iOS/iPadOS 실기기·시뮬레이터는 릴리스 범위에서 제외했다.
