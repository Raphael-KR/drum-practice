# 가사 연구와 판독 기록

문서 역할: **사실·연구 기록**. 원문 날짜·입력·환경·결과·실패·미확인은 각 절의 당시 상태다. 이번 통합에서 과거 검증을 재실행하지 않았으며, 기록의 “현재”는 원래 작성 시점이다. [기록 안내](../README.md)와 [현행 정본](../../RULES-INDEX.md)을 구분한다.

## 연구 근거의 주 보존 위치

가사 연구 문서의 실제 대상은 Real Paradis였다. 공통 방법처럼 보이는 STT·강제 정렬·토큰 균등 분배·파형 보정도 그 곡의 입력·실험 조건과 묶여 있으므로 [곡별 기록](../songs/real-paradis.md)에 원문을 보존한다. 이 파일에는 원문을 복제하지 않는다.

- [정렬 방법과 한계](../songs/real-paradis.md#lyric-alignment-audit--확인된-방법과-한계)
- [시간 정확성 감사](../songs/real-paradis.md#lyric-accuracy-review--가사-시각-정확성-감사--2026-09-19)
- [일본어 원문·발음 대조](../songs/real-paradis.md#japanese-canonical-readings--일본어-정본과-검수한-한글-발음)

현재 인쇄 가사 제작은 [음악적 위치 계약](../../reference/score/musicxml.md)을 따른다. 과거 가창 측정 실패나 시안이 새 PDF 변환의 선행 조건이 되지 않는다.
