# 0.10.3 화면 준비·재생 부하·도구 호환성 릴리스

- 목표: 화면 준비와 5번째 마디 전환·자동 저장의 불필요한 비용을 줄이고 개발 도구 호환성 개선을 공개 반영한다.
- 범위: 승인된 누적 미커밋 변경, 두 앱 공통 버전, 전체 검사, GitHub PR·CI·main 병합, 기존 player Site 발행과 결과 기록.
- 완료 조건: 기존 저장·패키지 호환성 및 전체 로컬 검사, 두 앱 브라우저 검수, PR/main CI, 독립 Sites 빌드와 공개 파일 대조를 통과하고 이번 병합 브랜치를 정리한다.
- 제외 범위: 제작기 공개, 원본 악보·저장 스키마 변경, 새 사용자 기능, 공개 범위 변경, iOS/iPadOS 실기기·시뮬레이터 검증과 문제 iPhone의 원인 확정.
- 검증: 기존 fixture·메모리 fake-indexeddb·일시 SQLite DB 사용을 이번 릴리스에 명시적으로 허가받았다. `pnpm run verify`, frozen 설치·audit·카탈로그/패치 보존, 실제 악보 열기·재생·저장·재열기, Sites 산출물·공개 응답을 확인한다.

## 후보와 버전 선택

- 시작 main은 `1fe915bcd40e560e100eb62d49e5bb1341609eef`이며 원격과 같다. 별도 미병합 브랜치·stash·worktree와 열린 PR은 없다. 기존 32개 미커밋 경로를 보존해 `codex/release-0.10.3`에서 함께 검토한다.
- 독립된 새 기능이나 저장 계약 변경이 없는 기존 실행 성능·호환성 보완이므로 두 앱 0.10.2 → 0.10.3 patch를 선택한다. 공용 개발 패키지 버전은 유지한다.
- 개발 근거: [도구 호환성](jsdom-typescript-upgrade-20261109.md), [경고·로딩 비용](runtime-loading-cost-20261109.md), [화면 준비](screen-preparation-20261109.md), [5마디 전환·저장](fifth-bar-load-20261109.md). 이전 개발 검증과 이번 릴리스 검증을 구분한다.
- SVG 출력·글꼴 검사·캐시 정책과 DB/키/직렬화를 유지한다. 상주 RSS의 지속 감소나 문제 iPhone의 충돌 해결은 이번 관측으로 확정하지 않는다.

## 실행 결과

- 폐기 악보 fake-indexeddb 집중 검사: 2개 통과. 이전 개발 단계의 허가 대기 상태는 이번 릴리스 허가와 실행으로 해소했다.
- Node 26.13.0·pnpm 12.18.0에서 전체 `pnpm run verify` 통과: lint·447파일 서식·앱/도구/hosting 타입·187소스 경계·159문서·17로컬 자산·132파일 810테스트·두 앱 빌드. 소스 빌드는 `8c051b046bc1`이다.
- 최초 전체 검사는 799개 통과·SVG 예외 검사 1개 시간초과였다. 실제 큰 SVG의 기존 예외 입력 11개를 독립 사례로 나눠 같은 native 파싱 동등성 단언을 유지했고, 기본 5초 제한·검사 규칙을 바꾸지 않았다. 전체 재실행은 모두 통과했다. `verify.log`와 `verify-retry.log`를 구분한다.
- 공통 저장소 frozen 설치·카탈로그 일치·JSZip 공유 검사와 peer 검사가 통과했다. audit은 모든 심각도 0건이다. 샌드박스 설치 시 공통 저장소 하드링크/DNS 제한으로 재시도하던 실행을 중단하고, 허가된 실행 환경에서 원래 공통 저장소를 사용해 설치했다. lockfile은 `a8324600d927c8981c37b140fd47d6490a07cfedbc4793f22a518f0dad7016c7`, 카탈로그는 `26dca00a5da71076fe295ee2b88ff4fdf5d3e7b6e4f8cb7abad2736335aae084`를 유지한다.
- Safari MCP에서 검사 탭을 선택해도 `visibilityState=hidden`·focus=false였고 12초 뒤에도 예약한 animation frame이 실행되지 않았다. 생성한 탭만 닫고 프로젝트의 실패 대체 기준에 따라 ego-browser/Chromium으로 검수했다. Safari/iPad 또는 iOS 실기기 검증으로 표현하지 않는다.
- 실제 드럼연습실의 기존 Loveholic 123마디를 열어 1줄/2줄 보기, 실제 재생·일시정지·처음·저장 후 재열기를 확인했다. AudioContext `running`으로 2·4·5·7마디 진행, 5마디 경계의 같은 현재 행 Node 유지·미제거를 확인했다. 저장 put 12회 중 songs cursor는 0회였다. 시험 전후 전체 저장 레코드·Song·미디어 해시가 같고 원래 1마디/ribbon을 유지했다.
- 악보제작기 1280×900 데스크톱에서 같은 저장 악보의 편집 열기·MusicXML/PDF/가사/음원 존재와 내용 변경 없는 닫기, 공통 두 줄 재생을 확인했다. 실제 AudioContext `running`으로 30마디 진행을 관측했고 처음부터 4·5·7마디를 다시 통과해 7마디 일시정지 화면을 캡처했다. 원래 1마디/ribbon·목록 복귀 후 전체 레코드 해시가 여전히 같았다. 앱별 위치 컨트롤 ID 혼용에 따른 관측 대기 실패는 실제 ID로 바로잡았다. 선택적인 CDP init-script 제거는 `Script not found`였고 페이지 내 임시 계측·컨텍스트와 검사 탭을 정리했다.
- 브라우저 초기 검수 호출에서 CLI 파일 인수와 앱별 버튼 식별자를 혼용한 오류는 표준입력/실제 DOM으로 정정했다. viewport CDP 호출 후 무효화된 ref는 공통 닫기 CSS 식별자로 바꿨으며 앱 코드를 변경하거나 자동 재생 정책을 해제하지 않았다.
- PR/CI·발행은 후속 단계에서 기록한다. 큰 청크 경고는 남고 OSMD 혼합 import·Node localStorage 경고는 이번 전체 검사/빌드 로그에 없다. iPhone 충돌 원인·상주 RSS 고정 감소·사람 청취·전곡 안정성은 미확정이다. 근거는 `.tmp/release-0.10.3/`에 보존한다.
