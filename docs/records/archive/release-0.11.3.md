# 0.11.3 릴리스 실행 기록

문서 역할: **사실 기록**. 2026-11-11 릴리스 요청의 변경 범위·검사 선택·실제 결과를 기록한다.

현재 상태: **사용자 결정으로 정적 검사까지만 수행하고 릴리스를 보류했다.** 아래 범위와 검사 계획은 재개할 때 참고할 기록이며 자동 실행하지 않는다.

후속 상태(2026-11-11): 이후 가사 표시·오류 안내 개선과 기존 미커밋 정리를 로컬 커밋하며 두 앱 버전을 0.11.4로 올렸다. 이 문서는 당시 0.11.3 준비 범위를 보존한다. 새 릴리스 요청 시 현재 변경 범위로 검사를 다시 선정하며, 공개 발행은 계속 보류한다. 자세한 변경은 [history.md](../../../history.md)를 따른다.

- 목표: 정지·2줄 보기의 관성 스크롤 수정과 검사·문서 정리를 검증해 기존 드럼연습실 Site에 발행한다.
- 범위: `fa776b6`의 공통 wheel 수명 관리와 기존 미커밋 35파일(신규 2개 포함)을 모두 통합한다. 두 앱은 이미 커밋에서 올린 `0.11.3` patch를 유지한다.
- 완료 조건: 필요한 로컬 검사·화면 확인, PR/main CI·main 빌드·Sites 자산 일치·공개 읽기를 확인하고 결과 문서와 전체 변경을 main에 반영한다. 마지막에 로컬/원격 main과 제품 입력을 대조하고 작업 브랜치를 정리한다.
- 보존·제외: 원본·수록 6곡·사용자 저장 데이터·과거 기록을 보존한다. editor는 PC 로컬 전용이고 player만 공개한다. iOS/iPadOS 실기기·시뮬레이터, 사람의 청취, 실계정 QA와 유보된 iPhone 재로드 원인 조사는 포함하지 않는다.
- 검증: [검사 카탈로그](../../reference/engineering/check-catalog.md)의 공통 필수와 아래 선택 검사를 적용한다. 실행 로그·입력 해시는 `.tmp/release-0.11.3/`에 보관한다.

## 시작 상태와 검토

- 정본 HEAD `fa776b68d7bf0319303ea3a922be5ddd296a0567`, 원격 main `f4b0b05aecba5cf299692d75eb9447103b4e0d02`. 기존 커밋 1개가 아직 원격에 반영되지 않았다. 시작 시 main 외 로컬/원격 브랜치·별도 worktree·stash는 없다.
- 작업 브랜치 `codex/release-0.11.3`를 만들었으며 시작 시 추적/비제외 파일 746개와 수록 패키지 6개의 해시를 `before.json`에 기록했다.
- 정지·2줄에서만 passive로 같은 wheel listener를 등록하고 재생/보기 변경 때 갱신한다. 기존 행 스냅 CSS, 재생 중 입력 억제, 1줄 가로 탐색, 공통 dispose 경로와 저장 계약을 유지한다. 앱별 복제·상시 DOM observer·곡별 예외는 추가하지 않았다.
- 폐기 SQL 검사, 옛 함수/UI 이름 부재 검사, 중복 생성 준비와 510ms 대기를 제거했다. 가사 교정 3파일은 1파일의 6사례로 통합하고 폰 설정 검사는 player 진입점으로 이동했다. [정리 근거](../check-audit-20261111.md)를 재검토했다.
- 현재 IndexedDB 이관·저장/백업/패키지 호환, 실제 재생 연산 소유권, Worker 응답/보안 헤더와 배포 자산 해시는 유지한다. Worker 번들 문자열 검사를 실제 응답 검사의 대체물로 사용하지 않는다. 관련 문서·앵커·스킬을 카탈로그와 대조했다.
- 검토 범위에서 추가로 제거할 제품 코드나 호환 경로는 확인하지 못했다. 변경과 무관한 구조 개편은 하지 않는다.

공통 정적/회귀/번들의 계획 순서는 `verify`와 같다. 허가 대기 중 정적 검사를 먼저 마쳤으며, 사용자가 “정적 검사까지만 — 릴리스 보류”를 선택해 후속 실행을 중단했다. 미실행을 통과로 기록하지 않는다. 과거 임시 passive 비교를 이번 영구 코드의 실제 화면 성공으로 대신하지 않는다.

## 실행 결과

- `pnpm run check`: lint 오류·경고 없음, 474개 코드/설정 서식, 앱/테스트·도구·hosting 타입, JSZip 공유·i18n·재생/공통 UI/소스 경계, 159문서·4,618로컬 링크·3,386앵커 통과. 기록 결과를 추가한 문서는 후속 문서 검사로 확인한다.
- 스킬 정적 문법과 `git diff --check` 통과. `node scripts/checks/check-local-assets.mjs`로 기존 검사 자산의 존재를 확인했으며 실제 회귀 결과와 구분한다.
- 열린 PR 없음, 기존 Sites는 소유한 public 프로젝트·저장 버전103이다. 이 조회는 새 발행이 아니다. 별도 배포 사본에 미커밋 변경은 없다.
- 보류 결정 뒤에는 이 기록과 `history.md`만 갱신하고 문서·링크·앵커 및 diff 정적 검사만 수행한다. 새 커밋·push·PR·merge·발행은 하지 않았으며 작업 브랜치 `codex/release-0.11.3`와 기존 미커밋 변경을 보존한다. 공개 버전은 앞서 발행한 0.11.2다.
