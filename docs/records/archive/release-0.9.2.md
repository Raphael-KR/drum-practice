# 0.9.2 아이폰 가로 상단바 릴리스

- 목표: 아이폰 가로 화면에서 악보 제목·버전을 첫 줄, 버튼을 다음 줄에 표시한다.
- 범위: 공통 재생·목록 CSS, 관련 UX와 Safari 응답형 화면 검수 문서, 두 앱 버전 및 릴리스 기록.
- 완료 조건: 전체 로컬 검증과 화면 확인, PR 검토·CI, main 병합·CI와 빌드, 기존 Sites 발행·공개 읽기 검사, 이번 병합 브랜치 정리.
- 제외 범위: 제작기 공개, 저장·오디오 동작 변경, 원본 미디어와 무관한 작업 변경.
- 검증: `pnpm run verify`, 승인된 실제 로컬 앱의 화면·조작, PR/main CI, 검증된 main의 두 앱 빌드와 공개 player 파일 대조.

## 후보와 검토

- 시작 HEAD와 origin/main은 `ba3ad10`이며 기존 작업 브랜치 `codex/fix-iphone-landscape-header`를 사용한다. 기존 작업 트리의 상단바 및 화면 검수 문서 변경을 이번 릴리스에 포함한다.
- 두 앱 0.9.1 → 0.9.2. 기존 화면 배치 수정이므로 patch를 선택한다. 저장 스키마·키·패키지·오디오 예약은 바꾸지 않는다.
- 공통 CSS는 폭 1023px 이하·높이 480px 이하 가로 화면의 상단바에 기존 세로 두 줄 배치를 적용한다. 넓은 재생바와 하단 조작판의 기존 배치는 유지한다. 검토는 Codex 자체 검토이며 독립 검토로 표현하지 않는다.
- 기존 UI 실측은 Safari 27.0.1과 Ego Lite에서 두 앱을 확인했다. 제작기 667px 가로에서 앱 전환 링크가 줄바꿈되는 관측은 기존 검수 한계로 유지한다. 실제 iOS 기기의 터치·청취는 별도다.
