## 실제 사용처·호환성 근거 전수 재점검과 잔재 정리 — 2026-11-10

현재 관리 대상 731파일을 목록화하고 앱·도구·검사·설정·문서의 참조를 대조했다. TypeScript/JavaScript 385파일의 선언·호출·반환 API, Python 68파일의 구문·import·중복 함수, CSS 32파일의 선택자·변수·중복 선언, Markdown 145파일의 링크·앵커·중복 문단을 정적으로 조사했다. Swift 2파일은 제작 워크플로의 실제 빌드 입력이며 해당 연결을 확인했다. 설치 패키지·원본 미디어·생성물·임시 출력은 역할과 참조만 확인하고 내용 정리 대상에서 제외했다.

두 앱 진입점에서 실행용 TypeScript 199파일에 모두 도달한다. 나머지 3파일은 의존성·Vite의 자료형 선언이다. 파일별 도달성만으로 모든 선언이 쓰인다고 판단하지 않고 동적 import·DOM 클래스·번역 키·CLI·검사·저장 경로를 추가 대조했다. 근거는 `.tmp/usage-audit-current-20261110/`에 보관했다.

### 재점검에서 보존한 실제 경로와 기록

- `openSettings`·`closeSettings`·`showLibrary`와 제작 도구의 브라우저 진입 함수는 동적 import·UI 검사·검수 HTML에서 호출한다. `.d.mts`도 실제 `.mjs` 소비자의 자료형 연결에 사용한다.
- `asset-${key}` 클래스는 보유 파일 칩에서 생성한다. 문자열 검색에 없는 자산별 CSS를 미사용으로 보지 않는다.
- IndexedDB의 기존 DB 읽기, bytes-v1·Blob 복원, 기존 곡/가사 교정 자료와 메트로놈 저장값 해석에는 현재 읽기 경로와 회귀검사가 있다. 이번 정리에서 추가 지원 종료나 데이터 이관을 하지 않는다.
- 저장소 차단·용량 제한 시 렌더 캐시 없이 진행하는 처리, 이미 끝난 오디오 소스·포인터 캡처 해제, Wake Lock 거절과 모션 감소/미지원 처리는 현재 오류·브라우저 경계를 처리한다. 예외 처리와 대체 경로를 일괄 제거하지 않는다.
- `DrumPractice.xcworkspace`는 [Xcode 승인 경로의 기록](ipad.md)에 근거가 있는 웹 소스 작업공간이다. `red-sunset-rebuild-handoff.json`은 실제 산출물·검수 근거를 연결하는 과거 인계 자료로 보존한다.
- 현재 문서의 검사 입력 표·UI 생성 문서·정본 링크와 보관 기록을 대조했다. 과거의 폐기 주소 119개는 지원 종료 목록으로 추적하는 기록이며 현행 주소로 덮어쓰지 않는다. 이번 조사에서 추가 삭제할 현행 문서 본문은 확인하지 못했다.
- 큰 파일은 `main.ts` 862줄·`playback-screen.ts` 825줄 등이 남는다. 현재 세션/재생 상태 수명과 이벤트 연결을 조립하는 소유자다. 실제 하위 모듈 사용을 확인했으며 줄 수만 줄이는 전달 모듈은 추가하지 않았다. 동일한 짧은 콜백·검사 준비 코드는 맥락이 달라 새로운 공통 추상화로 합치지 않았다.
