# 음원 연주 시작과 1마디 기준 (2026-10-13)

- 목표: 녹음된 카운트/관객 소리 뒤 실제 연주 시작을 1마디 1박으로 표시한다.
- 범위: 음원 로컬 분석, Song 저장 계약, 파형 보정 창, 마디/메트로놈 표시. 기존 박별 시각은 원본 초 단위로 보존한다.
- 완료 조건: 자동 후보는 추정으로 표시하고, 파형 선택 후 [여기를 1마디 1박으로] 저장/취소/재열기가 가능하다. 연주 전 음원은 보존하고 카운트오프가 켜져 있으면 마지막 네 박에 카운트 소리를 겹친다. 지정 뒤 첫 박부터 강박을 적용한다.
- 제외: 원본 편집·오디오 업로드·수동 기준의 서버 공유·커밋/푸시/발행·새 외부 분석 서비스.
- 검증: 변속 박과 중간 박 기준, 앞부분 보존, 강박, 저장 왕복/재분석 보존/잘못된 입력/취소, 로컬 Safari UI, 전체 드럼 테스트·분리 빌드.

## 계약과 추정 한계
`audioPractice.barOne`은 {time, source: estimated|manual}인 로컬 기준이다. 추종 모드에서는 기존 beatTimes의 가장 가까운 박에 맞춘다. 앞부분은 마디 0(화면에는 연주 전) 하나로 보존하고 실제 음악 마디는 1부터 시작한다. 추종을 끄면 고정 박자로 지정한 시작점부터 마디를 만든다. 미지정 구형 자료는 기존 4박 묶음·무강세를 유지한다.

자동 추정은 첫 60초의 박 주변 에너지와 지속적인 연주 진입, 반복 강세를 이용한 보수적 후보이다. 관객·말·스틱 카운트를 의미적으로 인식하는 알고리듬은 아니며 불명확하면 후보를 확정하지 않는다. AFM/STT는 음악 강박의 정본 근거가 아니고 기기 내 웹 경로에서 사용할 수 없어 이 기능의 판정에 사용하지 않는다. 수동 기준이 우선이며 재분석은 새 박 지도에서 그 위치에 가장 가까운 박을 유지한다. 서버의 기존 박 캐시는 변경하지 않고, 로컬에 디코딩된 PCM으로 시작 후보만 계산한다.

## 연주 전 카운트오프 (추가 승인)
- 목표: 연주 시작 직전 네 박을 기존 카운트 소리로 알려준다.
- 범위: 공통 Player의 카운트 예약, 도움말, 회귀 검사.
- 완료 조건: 음원을 지연하지 않고 원곡은 실제 박 시각, 연습 BPM은 변환된 고정 간격을 따른다. 1마디에서 일반 메트로놈으로 이어지며 중복 클릭이 없다.
- 제외: 원본 편집, 새 분석, 저장 계약 변경, 커밋/발행.
- 검증: 켜짐/꺼짐, 원곡/고정 연습 BPM, 짧은 전주, 중간 재개/탐색, 1마디 경계와 기존 카운트 동작.

연주 전 구간을 통과할 때 현재 카운트오프 설정을 적용한다. 분석된 이전 박이 네 개보다 적거나 중간에서 시작하면 남아 있는 박만 울리고 음원을 멈추거나 앞에 시간을 삽입하지 않는다. 고정 박 모드는 지정한 1박에서 4분음표 네 박을 역산한다. 기존 카운트오프와 같은 스틱 소리 경로를 사용하며 일반 메트로놈 켜짐 설정과 독립적이다. 연주 시작점 이후에서 시작하면 기존 재생 전 카운트오프 동작을 유지한다. STT/AFM은 저장된 박 시각으로 예약하는 이번 변경에 필요하지 않다.
