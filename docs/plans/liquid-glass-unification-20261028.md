# 공통 Liquid Glass 효과 통일

- 목표: 사용자가 확인한 참조 방식으로 기존 유리 CSS의 흐림·굴절·반사를 통일한다.
- 범위: 공통 재생 조작판, 드럼 악보 기호 모달, 두 앱의 설정창, 폰 가로 악보 화면의 설정·도움말 버튼과 악보 조작 도움말 모달, 제작기 편집창 헤더와 모달 전환 처리. 최초 참조 적용 대상이었던 악보 우상단 확대·복귀 버튼은 폰 가로 자동 전환 결정으로 제거했다.
- 완료 조건: 모든 대상이 같은 장식층 생성기와 CSS를 사용하고 이전 개별 배경·28px/18px 흐림 규칙이 남지 않는다.
- 제외 범위: 버튼 동작·배치·음원·저장 형식, 일반 불투명 UI, 범례 그림 내부의 승인된 SVG 도해, 커밋·푸시·발행.
- 검증: 개발 단계는 `pnpm run check`와 diff 정적 검토만 수행한다. 각 화면·모달 전환·접근성·재생 성능은 릴리스에서 확인한다.

## 구현 순서와 기준

1. 기존 버튼 전용 코드를 공통 `mountLiquidGlass`와 `src/shared/styles/liquid-glass.css`로 정리한다. 사용자가 제공한 `liquid-glass-test.html`의 3px 흐림·180% 채도, SVG 노이즈/변위와 반사 수치를 유지한다. 본문·아이콘에는 필터나 전체 투명도를 적용하지 않는다.
2. 각 사용처에 같은 장식층을 연결한다. 그림자·반사·테두리 색은 공통 CSS가 담당하고, 위치·크기·모서리·레이아웃은 각 컴포넌트가 유지한다. 아이콘 교체 후에는 기존 장식층을 다시 연결하며, 임시 모달·재생 화면 종료 시 필터 정의와 장식을 정리한다.
3. 예전 도움말 카드용 유리 CSS, 재생 조작판의 별도 배경색/그라데이션, 제작기 헤더의 별도 흐림을 제거한다. 일반 도움말의 투명 가이드와 설명 말풍선은 기존 목적을 유지한다. 폰 가로의 1줄·2줄에서는 악보 조작 전용 유리 모달 하나를 사용하고 공통 `×`만 원래 우상단 위치에 유지한다. 범례의 승인된 SVG 도해는 CSS 표면과 구분해 보존한다.
   - 폰 가로 도움말 본문에는 설정 > 화면과 같은 불투명 카드 배경을 사용한다. 바깥 모달의 유리 효과와 제목·닫기 배치는 유지하고 본문에 별도 유리 효과를 추가하지 않는다.
4. 모달 전환 중에는 해당 모달의 배경 굴절만 멈추고 반사는 유지한다. 전환 뒤 재합성 대상도 실제 굴절층으로 바꾼다. 투명도 감소·대비 증가 설정과 backdrop-filter 미지원 환경의 불투명 대체 배경을 공통 처리한다.
5. 폰 가로 악보 화면의 우상단 두 버튼은 해당 모드 진입 때 각각 같은 장식층을 붙이고 이탈·화면 종료 때 제거한다. 모드가 유지되는 동안 다시 생성하지 않는다. 버튼의 크기·클릭·긴 누르기·초점은 유지하며 SVG 필터 정의는 배치 공간을 차지하지 않는다.

## 릴리스 확인 항목

- 두 앱의 조작판, 악보 기호 모달, 초기 목록·재생 설정창과 제작기 편집창 헤더에서 동일한 효과와 선명한 내용. 설정창은 내부 카드의 구분 색을 유지하고 창 바탕과 제목 영역에만 공통 장식층 하나를 사용한다.
- 조작판 버튼 클릭/긴 누르기, 편집창 탭·닫기, 모달 열기/닫기/재열기와 포커스.
- 가로·세로·전체화면, 시스템 투명도 감소·대비 증가, 화면 크기 변경 뒤 장식층 유지.
- 폰 가로 악보 화면의 우상단 두 버튼의 반사·굴절과 선명한 아이콘, 세로·목록 복귀 시 기존 외형, 회전 반복 후 장식·필터 정의 미누적.
- 폰 가로 1줄·2줄의 악보 조작 도움말 모달에서 같은 효과와 선명한 설명·`×` 정렬, 열기/닫기/회전 시 장식·필터 정리.
- 긴 재생·반복 모달 열기 뒤 필터 정의 누적 여부와 Safari 렌더링 비용. 정적 검사만으로 화면·성능 성공을 판단하지 않는다.
