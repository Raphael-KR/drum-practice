# 아이폰 세로 전용 재생 화면
목표: 아이폰 세로 화면의 상단을 제목 / 조작 버튼 / 템포·메트로놈·줄보기의 세 줄로 정리한다.
범위: 공통 재생 CSS와 드럼연습실의 아이폰 가로 사용 안내, UX·변경 기록.
완료 조건: 폭 320~480px 세로 화면에서 상단 버튼이 한 줄씩 배치되고 하단은 재생 조작과 바로가기만 보인다. 가로 사용 안내는 최신 정정 요청에 따라 제거한다. Safari 회전 강제 잠금은 지원되지 않아 구현하지 않는다.
제외 범위: iPad mini 배치 변경, 악보·마커·구간 데이터 삭제, 앱 버전 상승·커밋·푸시·발행.
검증: Safari의 아이폰 크기 화면 검사와 iPad mini 크기 수정 전후 비교, 타입 검사·앱 빌드.
