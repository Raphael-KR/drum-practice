# 반복 구간 시작·삭제 동작 (2026-10-22) — 이력 안내

문서 역할: **완료된 구현 계획의 이력 진입점**. 승인된 동작은 [재생 이동 Rule](../reference/product/playback.md#playback-actions--재생-이동과-반복-구간-동작), 실행은 [UI 검수 절차](../how-to/verify.md#ui-review--화면악보재생-검수-절차)를 따른다. 당시 구현·검증·실패 기록은 [ADR-0006](../decisions/0006-practice-navigation-and-overlays.md)의 이관 원문에 보존했다.
