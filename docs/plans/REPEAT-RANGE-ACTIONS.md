# 반복 구간 시작·삭제 동작 (2026-10-22)

- 목표: 반복 구간을 언제든 처음부터 다시 연주하고, 명시적인 삭제 버튼으로만 삭제한다.
- 범위: 드럼연습실·악보제작기의 공통 반복 구간과 길게 누르기 도움말.
- 완료 조건: 아래 동작, 기존 저장 호환성, 공통 검사와 회귀 테스트 확인.
- 제외: 빈 슬롯 등록 방식·저장 형식 변경, 버전 인상·커밋·푸시·발행.
- 검증: 기존 자료를 사용하는 반복 구간·재생·도움말 테스트, 공통 검사, 두 앱 빌드 및 로컬 화면 확인. 실제 iPad 터치 결과와 구분한다.

## 승인된 동작

| 조작 | 결과 |
| --- | --- |
| 저장 구간 짧게 누르기 — 재생 중 | 해당 구간 시작에서 카운트오프 설정에 따라 카운트한 뒤 재생한다. 이미 활성인 구간도 다시 시작한다. |
| 저장 구간 짧게 누르기 — 정지 중 | 해당 구간 시작으로 이동하고 정지 상태를 유지한다. 시작 마디에서 다시 눌러도 삭제하지 않는다. |
| 저장 구간 길게 누르기 | 공통 말풍선에 구간 명칭·설명과 삭제 버튼을 표시한다. |
| 길게 누른 손 떼기 | 말풍선을 유지한다. 클릭·재생·이동·삭제를 실행하지 않는다. |
| 말풍선의 삭제 누르기 | 해당 저장 구간만 삭제한다. 활성 구간이면 반복을 해제하고 슬롯을 시작 마디순으로 정리한다. |
| 바깥 누르기 또는 Escape | 삭제하지 않고 말풍선을 닫는다. |

별도 휴지통 대기 상태와 타일 안의 삭제 아이콘은 추가하지 않는다. 빈 `+ 구간` 등록은 유지한다. 일반 버튼의 도움말은 기존처럼 손을 떼면 닫힌다. 스크롤·드래그·포인터 취소·화면 이탈·대상 교체 시에는 남은 말풍선을 닫는다. 도움말 전용 모드에서는 실제 삭제 동작을 제공하지 않는다.

카운트오프 확장과 충돌하는 재생 정책은 [버튼 이동 카운트오프](COUNT-OFF-NAVIGATION.md)의 후속 결정을 따른다. 아래 `play(false, false)` 관측은 확장 전 검증 기록이다.

## 구현·검증 기록

- 두 앱이 사용하는 `loop-slots.ts`의 시작 마디 재클릭 삭제 분기를 제거하고 기존 공통 재생 전환을 재사용했다. 저장 형식·키·9칸 정렬과 숨긴 레거시 슬롯은 유지한다.
- 공통 도움말 말풍선에 선택적 액션을 지원한다. 저장 구간의 실제 DOM 버튼에만 삭제 콜백을 연결하고 대상 교체·곡 변경 시 오래된 콜백은 실행하지 않는다. 일반 도움말과 도움말 전용 모드에는 삭제 버튼을 넣지 않는다.
- `npm run check` 통과. 전체 `npm run test:drum` 123파일733테스트, `npm run build` 두 앱 빌드와 player 경계 검사 통과. 기존 청크 크기·Node localStorage 경고는 유지한다.
- 최초 전체 실행에서 구동작을 기대하던 두 앱 회귀 검사를 새 계약으로 수정했다. 빌드와 테스트의 생성 파일 갱신이 겹친 시각 검사 실패는 생성 작업을 직렬 실행하여 해소했다. 검사 기준을 낮추지 않았다.
- 로컬 ego-browser에서 두 앱의 저장 구간 길게 누르기·손 뗀 뒤 유지·명시적 삭제, 정지 중 반복 클릭의 구간 보존, Escape/바깥 취소를 확인했다. 기존 붉은 노을 자료를 사용했으며 검증용 구간은 양쪽에서 삭제하고 처음 위치로 복귀했다.
- 실제 재생 엔진의 같은 구간 재선택: `play(false, false)` 시작 위치12.990초, 호출 후 위치12.990초·재생true 확인. 브라우저 고수준 클릭이 탭을 잠깐 숨겨 자동 일시정지를 유발하여, 탭을 전환하지 않는 CDP 포인터 입력으로 확인했다. 관찰용 런타임 래퍼는 원복했다.
- 증거: `.tmp/repeat-range-check.log`, `.tmp/repeat-range-tests.log`, `.tmp/repeat-range-build.log`, `.tmp/repeat-range-ui/results.json`. Safari MCP에는 길게 누르기 입력이 없어 ego-browser를 사용했다. 화면 캡처는 CDP 시간초과로 실패하여 픽셀 외형 검수는 미완료이며 실제 iPad Safari/터치·청취 품질은 미검증이다.
- 최종 집중 재검사4파일141테스트 통과(삭제 버튼의 Space가 재생 단축키로 전달되지 않는 회귀 포함). 소스 빌드 `b7e8f0358c59`.
- 앱 버전0.8.10 유지, 소스 기반 빌드번호 갱신. 커밋·푸시·발행하지 않았다.
