# 구간 드래그 제거 (2026-10-13)
- 목표: 빈 구간 버튼은 [구간 선택]을 표시하고 태블릿의 두 번 탭 등록만 준비한다.
- 범위: 구간 드래그/pointer capture/경계 자동스크롤 삭제, 안내와 CSS 갱신.
- 완료 조건: 마우스 드래그는 구간을 등록하지 않음. 태블릿은 시작·끝 탭, 마우스는 더블클릭, 키보드는 Enter로 기존 등록 유지.
- 제외: 악보 스크롤/재생 위치/저장 구조·원본·커밋/푸시/발행.
- 검증: 드래그 미등록/터치 스크롤·엔드포인트와 취소/더블클릭 및 Enter 회귀, Safari runtime.
