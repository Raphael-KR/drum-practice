# BPM 3:2 오추정 보정

- 목표: 현재 분석기를 유지하면서 120BPM을 80BPM으로 고르는 오류를 줄인다.
- 범위: player 템포 후보 선택·회귀 테스트·분석 캐시 버전과 같은 16곡 로컬 검증.
- 완료 조건: 해당 곡이 120BPM 근처로 개선되고 다른 15곡의 변화를 전후 표로 확인한다.
- 제외: 라이브러리 교체, 곡별 이름/해시 하드코딩, 음원 변경·업로드, 커밋·푸시·발행.
- 검증: 신호/후보 점수 진단 → 합성 리듬 회귀 → 같은 16곡 반복 실측 → 집중/전체 테스트·빌드.

## 완료 결과
- 기존 후보 선택 뒤에 3:2 비율의 빠른 후보를 제한적으로 재검사한다. 단일 점수 70% 이상, 1~4박 반복 근거 20% 이상 개선 조건으로 보정한다. 모든 느린 추정값의 일괄 가속은 하지 않는다.
- 같은 16곡 브라우저 재검증에서 문제 곡 80.0→120.0, 나머지 15곡 BPM 및 16곡 첫 박 값 유지. 분석 시간 약 0.015초 유지.
- 분석기/캐시 v3로 이전 오추정 캐시를 분리했다. 기존 사용자 곡·서버 행은 유지한다.
