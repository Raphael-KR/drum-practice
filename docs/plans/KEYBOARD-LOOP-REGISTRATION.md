# Enter 반복 구간 등록 (2026-10-13)
- 목표: 이동한 마디에서 Enter 두 번으로 시작/끝을 지정하고 반복 구간을 등록한다.
- 범위: 공통 반복 슬롯 저장·키보드 선택 상태·재생 화면·도움말. 사용자 확정: 시작 마디 순서 정렬.
- 완료 조건: 양끝 마디 포함, 같은 마디/역방향 지정 지원, 빈 슬롯 우선·9개 가득 차면 가장 오래 등록한 구간 삭제, 빈칸은 뒤에 배치. 등록 순서는 song.loops 삽입 순서로 보존하고 표시 정렬은 repeatSlots에서 처리한다.
- 제외: Enter 길게 누르기의 중복 등록, 입력 필드/모달/버튼 기본 동작 가로채기, 구간 자동 재생, 과거 숨긴10~12슬롯 자료 삭제, 커밋·푸시·발행.
- 검증: 같은 마디·역방향·Esc·상하좌우 이동 병행·가득 찬 정렬 목록의 오래된 구간 교체·저장 재읽기·웹/portable 호스트와 Safari 공통화면 검증.
