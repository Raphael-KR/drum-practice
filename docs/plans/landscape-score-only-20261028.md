# 폰 가로 자동 악보 전용 모드

- 목표: 폰용 화면을 가로로 돌리면 자동으로 악보 전용 모드로 전환하고 세로로 돌리면 원래 화면으로 돌아간다.
- 범위: 두 앱의 공통 재생 화면, 기존 수동 전환 설정·버튼 제거와 재생바 배치.
- 완료 조건: 폰용 가로에서 악보가 준비되면 별도 설정 없이 악보 전용 모드를 적용한다. 한 줄에서는 기존 재생바 하나가 하단에 겹쳐 표시되며 오선 제3선의 중앙 정렬을 유지한다. 재생바는 좌우로 스크롤하지 않고, 너비900px 미만에서는 주변 마디 반복 묶음을 숨긴다. 세로·목록·태블릿/데스크톱용 화면에서는 기존 화면을 유지한다.
- 제외 범위: 브라우저 전체화면 API 변경, 원본 악보·저장 포맷·재생 상태 변경, 커밋·푸시·발행.
- 검증: 개발 중 정적 검사만 실행하고, 기능·회전·Safari 화면 검수는 릴리스에서 수행한다.

## 구현 기준

1. 기기 종류가 아니라 기존 폰용 가로 CSS 조건인 가로 방향·너비1023px 이하·높이480px 이하의 뷰포트로 적용 여부를 판단한다. 악보가 준비되면 자동 적용하며, 이미 가로인 상태에서 곡을 열어도 동일하게 적용한다. 초기 목록에는 적용하지 않는다.
2. ‘가로화면에서 악보영역만 보기’ 설정과 악보 우상단 확대·복귀 버튼을 제거한다. 버튼·설정의 명칭표·도움말·이벤트·CSS도 함께 제거한다. 과거 `drum-practice.landscape-score-only` 선호값은 읽거나 갱신하지 않으며 삭제 작업도 하지 않는다. 곡별 설정과 `.drumscore` 형식은 변경하지 않는다.
3. 세로 또는 폰용 가로 범위를 벗어나면 원래화면으로 돌아가고 이전 외부 스크롤 위치를 복구한다. 다시 폰용 가로가 되면 자동으로 적용한다. BPM·설정·목록 등 상단바 조작이 필요하면 세로로 돌린다. 창 크기 변경과 회전은 기존 미디어 쿼리 변경 이벤트를 재사용하며 반복 검사나 기기 식별을 추가하지 않는다.
4. 브라우저 자체 전체화면과 독립적으로 동작한다. 회전으로 숨겨진 상단바·조작판에 초점이 있거나 가로에서 설정 대화상자를 닫으면 악보 영역으로 초점을 돌려준다. 보이는 재생바 버튼의 초점과 긴 누르기 도움말은 유지한다.
5. 악보 자산·음표 크기·줄 보기·음원 위치·반복·카운트오프는 바꾸지 않는다. 폰용 가로의 악보 전용 모드에서 한 줄은 오선 제3선을 화면의 세로 중앙에 맞춘다. 기존 오선 위치와 배율로 제3선의 표시 좌표를 구하며, 마디 번호·가사를 포함한 박스 중심으로 대신하지 않는다. 위쪽 표기 여백과 전체 악보 높이는 보존하고, 확대 시에는 외부 세로 스크롤 위치를 맞춰 위아래 내용에 접근할 수 있게 한다. 모드 진입·악보 재배치·화면 크기 변경 때만 중앙을 맞추며 수동 스크롤을 반복해서 되돌리지 않는다. 일반 화면·두 줄·검수 보기·오선 좌표가 없는 PDF와 음원 연습은 기존 정렬을 유지한다. 기존 너비 변경 재배치와 ResizeObserver를 재사용한다.
6. 한 줄 보기에서는 기존 `.playback-dock`의 `.transport`를 하단 고정 오버레이 한 줄로 표시한다. 마커·마디 위치·처음으로·재생/일시정지·되감기·반복 켜기/끄기·주변 반복의 실제 DOM과 이벤트를 재사용한다. 별도 재생바나 복제 버튼을 만들지 않는다. 기존 버튼 규격·반응형 배치·표면 색·안전 영역을 사용한다. 가로 스크롤은 제공하지 않는다. 기존 재생바의900px 배치 기준을 재사용하여 그보다 좁으면 주변 마디 반복 묶음(`.dock-repeat`)을 숨기고,900px 이상에서는 기존 한 줄 배치를 사용한다. 상단바와 구간 조작판은 숨기고 두 줄·검수 보기에서는 재생바도 숨긴다. 오버레이는 악보 높이와 제3선 중앙 정렬에 공간을 차감하지 않으며, 보이는 재생바 버튼의 키보드 초점을 유지한다.

## 릴리스 확인 항목

- 두 앱의 세로→가로→세로 자동 전환, 가로에서 곡 열기·새로고침, 세로에서 목록 복귀. 수동 설정·확대·복귀 버튼과 해당 도움말이 남지 않는지 확인한다.
- 폰용 가로 경계(1023×480px) 안팎의 자동 진입·해제, 다시 축소 시 자동 적용, 숨겨지는 조작 요소의 초점 이동. 태블릿/데스크톱용 화면에서는 기존 배치를 유지하며, 기기와 무관하게 창이 폰용 가로 크기가 되면 자동 적용한다. 과거 선호값의 켜짐/꺼짐/없음이 적용 여부에 영향을 주지 않는지도 확인한다.
- 한 줄·두 줄·PDF·음원 연습과 제작기 검수 보기, 가로 화면의 안전 영역, 세로 복귀 후 BPM·설정 접근.
- 폰용 가로 악보 전용 모드의 한 줄에서 MusicXML·오선 검출된 PDF의 제3선이 화면 세로 중앙에 있는지 확인한다. 마디 표제·가사·변박·균등 간격·배율50~300%·브라우저 도구막대 높이 변경을 포함한다. 큰 악보의 상하 스크롤 접근, 수동 스크롤 유지, 일반 화면 복귀 후 기존 정렬도 확인한다.
- 재생·일시정지·반복 중 전환, 긴 누르기 도움말, 설정 모달 닫기와 키보드 초점.
- 하단 오버레이의 모든 기존 재생바 기능, 단일 DOM/이벤트 유지, 가로 스크롤 없음·안전 영역·긴 누르기 도움말·키보드 접근, 한 줄/두 줄·일반 화면 전환 시 표시와 기존 배치 복귀.900px 경계 안팎에서 주변 마디 반복 묶음의 숨김/표시와 한 줄 배치를 확인한다. 오선 중앙이 재생바 높이만큼 위로 이동하지 않는지도 확인한다.
- 전체화면 API 미지원 Safari와 지원 환경에서 브라우저 전체화면 설정과의 독립성.

자동 전환으로 제거한 우상단 버튼의 유리 효과는 더 이상 생성하지 않는다. 다른 표면의 공통 유리 효과는 [통일 계획](liquid-glass-unification-20261028.md)에 따라 유지한다.

구현·정적 검사 결과는 [작업 기록](../../history.md)에 기록한다. 화면·기능 검증 완료를 뜻하지 않는다.
