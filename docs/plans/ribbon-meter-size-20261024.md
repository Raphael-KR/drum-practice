- 목표: 붉은 노을135마디의6/4 오선·음표가 한 줄 보기에서 인접4/4보다 커지지 않게 한다.
- 범위: 두 앱의 공통 native 연습 조판·표시 자산 선택·파생 캐시와 관련 기록.
- 완료 조건: 한 줄의 마디 폭은 사분음표 수에 비례하고, 오선·음표의 두 축 배율과 기준선은 전곡에서 같다. 두 줄과 균등 모드는 기존 크기를 유지한다.
- 제외: 원본 XML·음원·박 시각·저장된 곡/연습 정보 변경, 앱 버전 상승·커밋·push·발행.
- 검증: 실제 수록곡의134~136마디 native 자산·화면 계측과 Safari 확인, 기존 단위·통합·실제 패키지 검사, lint·타입·빌드.

## 원인과 수정

한 줄의 표시 폭은 시간축용 timeline에서 계산하지만 그림은 고정 폭 row를 선택했다.6/4의 표시 폭이4/4의1.5배가 되면서 row SVG의 두 축이 함께1.5배 커졌다. 두 줄은 셀 폭이 같아 드러나지 않았다.

공통 native row 간격 계산을 재사용하여 한 줄용 마디는 사분음표 수에 비례하는 폭으로 조판한다.4/4의 기준 폭과 글리프 크기는 두 줄과 같게 두고,6/4는 오선과 음표 사이 공간만 넓힌다. 한 줄은 그 폭에 맞는 native 자산을 사용한다. 완성 SVG 좌표 이동이나 글리프의 비균등 변형은 하지 않는다. 기존 저장 패키지는 source XML에서 새 파생 캐시로 표시한다.
