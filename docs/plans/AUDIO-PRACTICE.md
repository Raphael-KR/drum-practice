## 설계
명시적인 Song.audioPractice 메타정보(길이·박자·파형)를 추가한다. 음원에는 악보 페이지·좌표를 만들지 않는다. 마디 시간표는 BPM과 첫 박으로 생성하며 마지막 마디의 음악적 길이를 잘라 BPM을 바꾸지 않는다. 실제 재생·반복 끝은 음원 길이에서 제한한다. 재생 화면은 공통 엔진·커서·마커·구간 조작을 재사용하고 악보 대신 파형/박 눈금을 그린다. 첫 박 이전의 음원도 보존한다.

기준 BPM 보정은 음원 속도를 바꾸지 않는다. 박자 설정 적용 시 원곡1배속으로 돌아가며 마커·반복은 원본 초 위치를 보존한다. 연습 BPM 변경은 기존 배속/음정 유지 경로를 사용한다. 자동 추정은 가져올 때 적용하고 확인 창 없이 연습 화면으로 이동한다. 곡명·가수는 로컬 파일 태그를 사용하며, 태그가 없거나 손상되면 파일명을 제목으로 사용하고 가수는 비운다. 필요할 때만 수동 입력·탭 템포·음원 현재 시각으로 첫 박 지정 기능을 제공한다. 박자 설정은 음원 목록 항목에서 다시 열 수 있다.

저장 형식은 기존 RecordData 컨테이너를 유지하되 음원 모드의 pdf는 빈 Blob, pages/regions는 빈 배열이다. 이는 악보로 위장한 자료가 아니며 변환/렌더러/악보 보기에는 진입하지 않는다. 기존 악보 검증은 그대로 유지하고 음원 모드의 제한을 별도 검증한다.
