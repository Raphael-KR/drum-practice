# 버튼 이동과 카운트오프 (2026-10-22)

- 목표: 카운트오프 설정을 마커·섹션 바로가기·주변 마디 반복·저장 반복 구간에 일관되게 적용한다.
- 범위: 두 앱의 공통 재생 화면·버튼 이동·재생 엔진·도움말·정본 문서.
- 완료 조건: 재생 중에는 대상 시작점에서 카운트 후 재생하고, 정지 중에는 이동만 하며, 해제·삭제와 일반 탐색에는 새 카운트를 추가하지 않는다.
- 제외: 저장 형식·음원 변경, 버전 인상·커밋·푸시·발행, 반복 회차마다 카운트 추가.
- 검증: 기존 곡 자료·기존 오디오 테스트 환경으로 설정 켬/끔, 재생/정지, 카운트 교체, 두 앱 버튼 연결을 검사하고 공통 검사·전체 테스트·두 앱 빌드를 실행한다.

## 승인된 규칙

| 상황 | 결과 |
| --- | --- |
| 재생 중 네 종류 버튼으로 이동/반복 선택 | 대상 시작점으로 이동 → 설정이 켜져 있으면 카운트오프 → 재생. 꺼져 있으면 바로 재생 |
| 정지 중 버튼 선택 | 대상 시작점으로 이동하고 정지 유지. 이후 재생 버튼에서 설정에 따라 카운트 |
| 카운트 도중 다른 대상 선택 | 기존 소리·카운트를 취소하고 새 대상에서 다시 카운트 |
| 활성 주변 반복 재클릭·반복 해제·구간 삭제 | 새 카운트 없음. 기존 해제/삭제 동작 유지 |
| 현재 마디 마커 재클릭·빈 마커 등록 | 기존 삭제/등록 동작 유지. 새 카운트 없음 |
| 구간 자연 반복·속도 변경·드래그·진행률·방향키·처음·되감기 | 이번 버튼 이동 카운트오프 적용 대상이 아님 |

주변 마디 반복도 선택 순간 구간 시작으로 이동한다. 기존의 현재 위치 유지 규칙을 대체한다. 마커·바로가기가 활성 구간 밖으로 이동하면 기존처럼 반복을 해제한다. 안쪽으로 이동하면 반복은 유지한다. 저장 반복 구간 재선택은 같은 시작점에서 다시 카운트한다.

일반 카운트는 현재 연습 템포의 4분음표 네 번이다. 음원 연주 전 구간으로 이동하는 경우는 기존 음원 보존 정책을 따라 마지막 네 박에 카운트를 겹치며 별도 대기를 추가하지 않는다.

## 구현과 검증

- 공통 `seek` 경로에 선택적 카운트 요청을 전달하고 기존 `Player.play`에서 설정을 판정한다. 마커·섹션 바로가기는 이 경로를 함께 사용한다. 별도 카운트 타이머나 저장 설정은 추가하지 않았다.
- 반복 구간 선택도 같은 `Player.play`를 호출한다. 구간 해제는 카운트를 요청하지 않는다. 주변 반복 선택 시 구간 시작으로 이동하고 이전 키보드 선택을 해제한다.
- 기존 현재 위치 유지를 기대하던 두 앱·반경1~4 테스트8개를 새 승인 계약으로 수정했다. 마커 등록/삭제와 구간 삭제, 정지 유지, 일반 seek의 카운트 제외를 함께 검증했다.
- `npm run check` 통과(lint·서식·타입·i18n·구조·문서). `npm run test:drum` 전체123파일739테스트 통과. `npm run build` 두 앱 빌드·player 경계 검사 통과. 기존 청크 크기·Node localStorage 경고는 유지한다.
- Safari 로컬 `player.html`에서 기존 `public/demo` 곡과 실제 AudioContext로 공통 엔진을 별도 인스턴스화하여12개 상태를 확인했다. 켬4박/끔0박, 대상 이동, 카운트 중 반복 구간으로 교체, 해제0박, 정지 이동 및 수동 재개를 확인했다. 사용자 목록·설정·저장 기록을 변경하지 않았으며 검증 인스턴스와 임시 페이지를 종료했다.
- 최초 자료 로드는 빌드 생성 파일의 Vite 새로고침과 겹쳐 실패했다. 빌드 종료 후 각 로컬 자료HTTP200과 재로드 성공을 확인했다. Safari의 AudioContext는 사용자 클릭 후 running 상태에서 검증했다. 두 앱 버튼 연결은 자동 DOM 통합 검사로 확인했고, 실제 iPad 터치·청취 품질은 미검증이다.
- 증거: `.tmp/countoff-check.log`, `.tmp/countoff-tests.log`, `.tmp/countoff-build.log`, `.tmp/countoff-safari.json`. 소스 빌드 `e1fe96ecbef8`, 앱 버전0.8.10 유지. 커밋·푸시·발행하지 않았다.
