아래는 2026-11-11 교정 계획의 보존본이다. 이후 승인된 [ADR-0032](../decisions/0032-common-sixty-fourth-unit.md)가 공통 기본 단위를 64분음표로 바꿨다. 후속 제작은 [현행 Rule](../reference/score/production.md#score-production-rules--오선-부착-표기의-공통-기본단위)을 따르며 아래 쌍별 분할 방법을 새 가사의 기본 교정법으로 재사용하지 않는다.

- 목표: 서로 다른 음절의 곡 전체 음악적 시작점이 같지 않도록 현행 정본을 검사·교정한다.
- 범위: 현행 제작 정본 전체와 로컬 XML 인벤토리, 가사 작성·저장 Rule, 재사용 검사 도구, 곡별 근거.

- 제외: src/public/카탈로그/DB/history.md 변경, 과거 입력 덮어쓰기, 새 합성 자료/시험 DB·음원 분석·GUI·iOS·커밋·배포.
- 검증: 실제 XML을 유리수로 읽어 마디 경계·화음·backup/forward를 포함하고 text 없는 extend는 제외한다. 실제 공통 writer/reader를 호출하고 독립 검사로 재대조한다.

## 교정 판단

Real Paradis의 순차 발음 문구·전¼박 격자 아카이브와 후속 격자 기록을 대조한다. 실제 가창 시간을 새로 측정하거나 과거 추정 초값을 악보의 목표 시각으로 되돌리지 않는다. 같은 시작을 가진 두 음절은 모두 앞 음절에¼박 음가가 있다. 이¼박 구간을 두32분음표(각⅛박)로 나누어 앞 음절 시작을 유지하고 뒤 음절 시작을⅛박 뒤에 둔다. 앞 음절 길이는⅛박, 뒤 음절 길이는 기존 끝점을 유지하도록⅛박 줄인다. 다음 서로 다른 시작점과 마디를 침범하지 않는지 쌍별로 확인한다. 이는 사용자 요청에 따른 음악적 편집 교정이며 원본 보컬 악보/실연의 정확한 음가를 확인했다는 뜻은 아니다. 음절 삭제·병합·epsilon 추가·모든 음절 재양자화는 하지 않는다.

최종 사용자 확인에 따라 기존32분음표 그리드를 가사에도 적용한다. 사분음표1박당8칸, 4/4 한 마디32칸이며 앞선64분음표 언급은 기억 착오로 철회됐다. 이번 교정과 현행6곡의 모든 가사 시작/길이를⅛박 그리드와 대조하고 중복도 함께 검사한다. 원본에 명시된 연음·세부 음가는 임의 반올림하지 않고 예외 근거를 검토한다. 길이 구간 중첩과 같은 시작점을 구분하며 구형 파일 읽기/보존은 유지한다.
