## 범위 검토와 버전

신규 공통 모듈 `playback-words.ts`는 `modules/score`에서 두 앱의 native 조판에 재사용한다. SVG 글꼴 검사는 앱에 동봉된 Pretendard 바이트와 CSS 전체 일치만 허용하며 기존 외부 URL·실행 코드 검사를 유지한다. 저장소 스키마·DB/키·패키지 형식은 바꾸지 않는다. 최신 악보 교정본의 원음원·가사·ID·박 시각 보존 근거는 곡별 기록을 따른다.

0.8.13은 연속 크레센도·섹션/연주 지시·Pretendard·변박 크기 등 기존 연습 흐름의 조판 오류 수정과 제작/검수·문서 보완이므로 patch다. 앞서 커밋된 정본 문서 정리도 현재 브랜치의 승인된 작업으로 함께 병합한다. 이번에 별도 전체 구조 개편은 하지 않는다. 공개 대상은 player뿐이며 editor는 같은 버전의 로컬 제작 앱으로 유지한다.

실행 증거는 Git 제외 `.tmp/release-0.8.13/`와 최종 [발행 기록](../records/releases.md)에 연결한다. 발행 전 항목은 완료로 기록하지 않는다.

## PR CI에서 발견한 문서 이식성 보완

최초 PR head `1e40272`는 로컬 전체 검사를 통과했지만 CI에서 상대 링크66개의 대상이 없어 실패했다. 두 기록 문서가 로컬 Git 제외 `data/production/` 증거를 링크로 제공한 것이 원인이다. 자료는 그대로 보존하고 표시를 같은 캡션·경로의 로컬 보존 기록으로 바꿨다. 공통 문서 검사는 실제 존재뿐 아니라 기존 `projectFiles()`의 Git 추적/비제외 신규 파일·상위 폴더 여부를 확인하도록 보완했다. 바꾸기 전 로컬에서도 같은66개를 실패로 검출한 뒤 문서를 수정하고 다시 검사한다. 검사 제외나 원본 미디어 업로드로 해결하지 않는다. CI 수정에 따른 버전 중복 인상은 하지 않는다.

## Sites 소스 업로드 크기 보완

- 목표: Sites가 거부한 대형 패키지의 재생성 가능한 중복 캐시를 줄여 동일한 악보를 발행한다.
- 범위: 릴리스용 패키지 압축 도구·실제 세 수록 패키지와 호환성 검사. 실패한 배포 사본과 원래 패키지를 별도 경로에 보존한다.
- 완료 조건: 원본/XML·음원·가사·박 시각·마커·설정·인쇄 SVG 잉크가 같고 기존 패키지 API로 재읽히며, canonical XML에서 동일 연습 조판이 생성된다.
- 제외: 음악/저장 형식 변경·동봉 글꼴 제거·화면 품질 저하·기존 공개 버전 롤백·Site Git 강제 push/이력 재작성.
- 검증: 기존 실제 패키지의 모든 ZIP 엔트리와 manifest를 대조한다. `metadata[data-ribbon-timeline="1"]`와 해당 page 크기만 바뀌어야 한다. 공통 재읽기·native 렌더·전체 로컬 검사/CI/빌드 후 새 후보를 발행한다.

실패 사유는 `pack member exceeds aggregate working-memory limit`다. 붉은 노을 첫 SVG68,477,964바이트 중65,295,212바이트가 중복 native 렌더 metadata였다. 공개 로딩은 기존 `prepareBrowserScore()`가 canonical XML로 현재 정책의 조판을 재생성하므로 배포 패키지에 이 캐시를 중복 저장할 필요가 없다. 인쇄 SVG의 텍스트·글꼴·음표와 원본 자료는 그대로 두고 알려진 버전1 native metadata만 제외한다. 첫 발행은 아직 하지 않았으므로 버전0.8.13을 유지한다.

실제 세 후보는 ZIP의 page0와 manifest의 해당 size만 바뀌며, 다른 모든 엔트리·canonical XML·Song은 정확히 같다. 인쇄 SVG는 독립 XML 파서로 캐시를 제외한 전체 잉크와 글꼴 동일성을 확인했다. 크기는 붉은 노을56,373,182→13,557,768, 갑자기25,515,619→7,966,184, 바람과 언덕의 발라드30,113,720→11,476,951바이트다. Safari에서 세 후보의 공통 재읽기·137/93/110마디 native 조판 재생성을 확인했다.

원래 세 패키지는 `local-archives/releases/0.8.13-package-inputs/`, 실패한 Sites 사본과 미발행 커밋 `945b6f5`는 `local-archives/releases/sites-upload-failed-0.8.13/`에 그대로 보존했다. 공개 이력·작업을 reset하거나 강제 push하지 않고 같은 Site의 확인된 원격 소스 `56de1cd`에서 새 배포 사본을 열었다. 새 CLI 타입 선언 `.d.mts`도 서식·ESLint 검사 대상에 포함한다.

경량 패키지·소스 빌드 `f6dd74f66c92`의 최종 `npm run verify`127파일758검사·서식428파일·lint/타입/문서/경계·두 앱 빌드가 통과했다. public 파일별 SHA256과 인쇄/엔트리 대조는 `.tmp/release-0.8.13/compact-evidence.json`, Safari 실제 복원은 `compact-browser.json`에 보존했다. 원래 자료를 쓰는 제작 도구18검사는 입력/도구가 그대로이므로 앞의 통과 결과를 재사용한다.
