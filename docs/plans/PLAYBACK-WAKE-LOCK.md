# 재생 중 화면 유지
목표: OS 구분 없이 재생 중 화면 자동 꺼짐을 방지한다.
범위: 공통 재생 화면의 Screen Wake Lock 수명 관리와 테스트·UX·변경 기록.
완료 조건: 재생/카운트오프 중 요청, 정지·종료·화면 이탈 시 해제, 보이는 화면으로 복귀 시 재생 중이면 재요청한다. 늦은 응답은 현재 상태를 따른다.
제외 범위: 알림/집중 모드 변경, 시스템 수동 잠금 무력화, 미지원 브라우저 우회, 앱 버전 상승·커밋·푸시·발행.
검증: 비동기 경합·거부·미지원·가시성·정리 집중 테스트, 공통 재생 테스트와 Safari 실제 API 확인 및 앱 빌드.
