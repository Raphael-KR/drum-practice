# 재생선과 마디 선택 분리 (2026-10-13)
- 목표: 정지 중 키보드 마디 선택과 실제 재생 위치를 분리하고 두 보기의 진행 표시를 통일한다.
- 범위: 공통 재생 화면의 선택 상태·키보드/마커/Enter 등록·재생 시작, frame과 CSS, 도움말/표시 정본.
- 완료 조건: 두 보기 빨간 재생선, 방향키는 정지 위치/파란 진행 음영 불변·선택만 이동. 사용자 확정: 재생을 누르면 선택한 마디부터 시작. M과 Enter는 선택 마디 기준.
- 제외: 음원/악보 원본 수정, 기존 마우스 직접 탐색 동작 변경, 커밋·푸시·발행·버전 상승.
- 검증: 실제 재생 위치와 선택/진행/화면 스크롤의 독립성, 재생 재개·마커/구간 등록·두 보기·역방향 및 보기 전환 회귀검사와 Safari.
