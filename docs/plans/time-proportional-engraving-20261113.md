# 공통 시간 비례 조판과 가사 묶음 전환

- 목표: 두 앱의 모든 MusicXML 화면이 같은 음악적 시간 좌표와 최종 가사 묶음을 사용한다.
- 범위: 공통 조판, 정본 가사 읽기·저장, 변박 폭, 전체 보기·두 줄 초과 행 축소, 구형 저장 형식·파생 캐시 정리.
- 완료 조건: 일반/균등 선택 없이 음표·가사·진행선 좌표가 일치하고, 제작자가 전환한 정본을 앱 패키지에 반영한다.
- 제외: 원본·제작 작업 파일·과거 기록 삭제, 음원·드럼 리듬 변경, 커밋·푸시·발행.
- 최초 구현 검증: lint·서식·타입·정적 경계·문서 링크/앵커·실제 파일 구조 대조로 제한했다. 이후 사용자가 로컬 두 앱의 실제 SVG·1줄·2줄 화면 검증을 별도로 승인했으며 결과는 아래에 구분한다.

## 승인한 설계

1. 기존 균등식의 시간 비례 배치를 공통화한다. 시작 여백은 기존 공통 inset을 재사용한다. 리듬 공간만 사분음표 단위 길이에 비례하며 사전 최소 기호 폭은 추가하지 않는다.
2. 겹치는 가사는 제작·저장 단계에서 첫 시작점의 최종 묶음으로 확정한다. 묶기 전 전체 원문·음절별 시간·변환 대응은 제작 작업 파일에 보존한다. 정본에는 묶음 문구·시작 위치·필요 음가만 남긴다. 줄 끝·줄 경계·다음 묶음 침범을 사전 금지하지 않는다.
3. 같은 보표의 가사 소유 성부를 재사용한다. 정본 manifest는 `drum-practice:score:v3` / `version:3`이며 기존 `lyrics` 항목 구조는 최종 표시 단위를 뜻한다. 구형 정본을 앱이 몰래 교정하지 않는다.
4. 한 줄 보기는 연속 흐름을 유지한다. 두 줄은 네 마디를 한 줄로 묶고 넘치는 줄만 같은 배율로 축소한다. 짧은 줄은 오른쪽 빈 공간을 허용한다. 음표·가사·진행선·탐색은 같은 좌표를 사용한다.
5. `uniformSpacing` 설정·타입·선택 분기와 row/grid 중복 생성 경로를 제거한다. 구형 앱 데이터는 schema 전환에서 초기화하고 구형 패키지는 새 정본으로 재생성한다. 원본·제작 자료·발행/검증 기록은 정리 대상이 아니다.
