# 음원 템포 변화 따라가기

- 목표: 기기 음원의 전체 박 시각을 자동 분석해 메트로놈·파형·반복이 실연의 속도 변화를 따른다.
- 범위: 음원 전용 가져오기/설정, 박 추적 Worker, Song 시간표, 기존 공통 재생기, 분석 캐시 계약.
- 완료 조건: 변속 합성 음원의 정답 박과 비교하고 붉은 노을 및 기존 16곡을 실행한다. 저장·재열기·배속·탐색·반복과 고정 BPM 회귀를 검증한다.
- 제외: 음원 업로드, 자동 채보·박자표/강박 판별, 기존 악보 패키지 재분석, 커밋·푸시·발행.
- 검증: 집중 단위/통합 검사, 실제 로컬 브라우저 Worker·가져오기·재생, 전체 테스트와 앱 빌드.

## 설계

기존 자체 BPM 분석기는 대표 BPM 추정에 유지한다. MIT 라이선스 music-tempo 1.0.3의 BeatRoot 기반 박 추적을 음원 전용 Worker에 추가한다. 대표 BPM 주변 후보로 전체 음원의 타격 시각을 따라가며, 결과를 일정 간격으로 다시 펴지 않는다. 16kHz 단일 채널을 사용하고 가장 에너지가 큰 채널을 선택해 반대 위상 상쇄를 피한다. 메인 스레드를 막지 않으며 Worker는 종료·오류·시간 제한에서 정리한다. 4초 미만·30분 초과 음원은 고정 BPM 경로를 유지한다. 지원 길이의 신뢰도 있는 BPM 분석에서 박 추적이 실패하면 오류를 표시하며, 조용히 고정 격자를 저장하지 않는다.

새 음원은 유효한 박 시각이 있으면 자동 추종한다. 박 정보 없는 기존 음원은 열 때 자동으로 보완한다. 이미 박 정보가 있으면 수동으로 끈 추종 설정도 존중한다. 박자 맞추기에서 명시적으로 재분석할 수도 있다. 분석 결과가 있으면 자동 추종과 고정 BPM을 전환한다. 마커·반복의 원본 초 위치는 유지한다. 추종 모드의 마디는 탐색용 4박 묶음이며 실제 강박을 판정하지 않는다. 잘못된 강박을 주지 않도록 추종 클릭은 같은 소리로 재생한다.

Song.audioPractice에 원본 박 시각과 추종 상태를 저장한다. 추종 시간표의 마디별 박 시각은 이를 투영한 값이며 검증 시 일치 여부를 검사한다. 기존 악보와 고정 BPM 음원은 기존 경로를 유지한다. 연습 BPM은 대표 BPM 대비 배속이며, 박 시각도 공통 재생기의 같은 배속·반복 주기로 변환한다.

캐시는 v4로 분리하고 박 시각 목록을 허용한다. JSON 크기·시각 범위·단조 증가·개수 제한을 적용한다. 파형·음원·경로·수동 보정값은 전송하지 않는다. 긴 JSON은 fetch keepalive 제한을 넘지 않게 일반 요청을 사용한다. 공개 서버 반영은 향후 발행 시 수행한다.
