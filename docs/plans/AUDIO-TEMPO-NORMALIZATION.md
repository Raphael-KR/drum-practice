# 원곡 실시간 BPM과 연습 박 간격 정규화

- 목표: 원곡에서는 최근 4박 평균 BPM을 소수점 한 자리로 보여주고 연습 모드에서는 음원 박을 지정 BPM 간격에 맞춘다.
- 범위: 박 시각이 있는 음원, 명시적 원곡/연습 설정, 공통 재생기·Worker·상단 BPM. 기존 악보는 기존 배속 동작을 유지한다.
- 완료 조건: 같은 BPM에서도 원곡/연습이 구분되고 원본↔재생 시간 변환, 클릭·탐색·반복·저장, 피치 및 박 타격 정렬이 검증된다.
- 제외: 원본 음원 변경/업로드, 자동 채보, 새 분석기, 커밋·푸시·배포와 버전 상승.
- 검증: 변속 합성 신호의 실제 출력 샘플·스테레오 피치·박 오차, 재생기 통합 테스트, 로컬 브라우저 Worker/UI, 전체 테스트·분리 빌드.

## 설계

기존 박 시각은 원본 초 단위를 유지한다. 연습 모드의 출력 박은 60/지정BPM 간격이며 원본과 출력 사이의 단조 구간 선형 시간표를 만든다. 메트로놈·파형 커서·음원 탐색·반복 경계가 같은 시간표를 사용한다. 전체 음원 타임스트레칭은 Worker에서 처리하고 원본 모드는 원본 AudioBuffer를 사용한다. 박 사이를 피치를 유지하는 WSOLA로 변환하고 경계 연결을 검증한다. 박 추적 구간 밖의 앞뒤 음원은 기준 배속으로 보존한다.

`settings.tempoMode`는 original/practice이며 기존 저장값은 rate=1이면 original, 그 외 practice로 해석한다. 추종을 끈 고정 BPM 음원과 악보에는 기존 균일 배속을 적용한다. 원곡의 표시 BPM은 완료된 최근 최대 4개 박 간격 평균이며 매 박 갱신한다. 정지·선택 이동에서는 마지막 표시값을 유지한다. 원곡 버튼에는 기준 BPM을 유지한다.

## 구현·완료 근거

- `src/audio-time-map.ts`: 모드, 원본↔출력 시간표, 완료된 4박 BPM 평균.
- `src/stretch-warp.ts`: 타격음 보호 구간 + WSOLA + 교차 페이드. 초기 전체 구간 스트레칭에서 확인된 타격음 약화를 해결했다.
- `src/audio-core.ts`, `src/stretch-worker.ts`: 변환 완료 후 원자적 적용, 일정한 박 스케줄, 원본 시간 기준 탐색·반복·위치 유지.
- `src/playback-screen.ts`, 도움말: 원곡 소수점 한 자리·정지 시 유지·명시적 연습 모드.
