# 터치 구간 등록 (2026-10-13)
- 목표: 태블릿에서는 두 번의 마디 탭으로 구간을 등록하고 손가락 드래그는 악보 스크롤로 사용한다.
- 범위: 공통 구간 슬롯의 터치 pointer 처리, 터치 스크롤 CSS, 안내/도움말.
- 완료 조건: 첫 탭 시작·두 번째 탭 끝(끝 마디 포함), 스크롤/취소된 pointer는 선택하지 않으며 시작 대기는 유지한다. 기존 마우스 드래그·키보드 Enter는 유지한다.
- 제외: 슬롯 정렬/저장 구조·반복 재생·음원 수정·커밋/푸시/발행.
- 검증: 탭/스크롤/역방향/같은 마디/중단/삭제 통합 테스트, Safari runtime 및 가능한 iPad 검증.
