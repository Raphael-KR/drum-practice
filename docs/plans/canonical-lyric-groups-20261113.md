# 가사 묶음 정본 v3 전환

- 목표: 활성 악보의 최종 표시 가사를 제작 단계에서 확정하고 묶기 전 자료는 작업 파일로 보존한다.
- 범위: 활성 MusicXML 6곡, 공통 제작 어댑터, 제작·저장 규칙, 제작 절차·스킬, 곡별 기록.
- 완료 조건: 공통 묶음 함수로 만든 v3 정본과 음절→묶음 대응표를 인계하고 원문·드럼·음원 연결 보존 근거를 남긴다.
- 제외: 앱 `src/`, 수록 패키지·카탈로그, `rendering.md`, `history.md` 수정, GUI·회귀·빌드·커밋·푸시·발행.
- 검증: 실제 파일의 XML 구조·유리수 시간·해시 대조, XSD, 코드 구문·서식·문서 링크를 정적으로 검사한다. 실제 표시·재생 검증은 수행하지 않는다.

## 승인과 소유

2026-11-13 웹앱 개발 채팅의 사용자 요청은 보완 계획의 구현과 악보제작자의 정본 전환을 명시했다. 해당 채팅의 사용자 원문을 확인했다. 개발 담당은 공통 조판·앱 저장 경로·패키지·캐시를 맡는다.

- 개발 담당: `hostId=local`, `threadId=01a0afc9-ca21-7371-9390-06eb07c017e9`.
- 통합 계획: [공통 시간 비례 조판](time-proportional-engraving-20261113.md).
- 입력: `data/production/canonical-corrections-20261112/<곡 ID>/score.musicxml`.
- 출력·보존: `data/production/lyric-groups-20261113/<곡 ID>/`.

## 처리 순서

1. 수록 목록·곡 기록·현행 정본을 대조하고 원본 XML과 Song, 전체 가사·음절별 시간·메타정보의 사본과 해시를 보존한다.
2. 개발 담당의 `lyric-groups.ts`와 `time-spacing.ts`를 재사용한다. Pretendard Regular 13pt의 실제 텍스트 폭과 행 경계 없는 공통 시간 좌표로 묶음을 계산한다.
3. 같은 보표의 기존 소유 가사 성부를 공통 writer로 다시 쓴다. 묶음 첫 ID·시작점, 결합 문구, 필요한 끝 위치를 사용한다. 원래 모든 구성 음절이 확인된 경우에만 묶음을 확인 상태로 기록한다.
4. manifest를 `drum-practice:score:v3` / `version:3`으로 전환한다. 전체 원문·원래 음절별 근거는 정본에서 제거하고 작업 자료로 보존한다. 박 위치가 없는 마디 문구는 임의로 시간화하지 않는다.
5. XML 구조·원문 대응·드럼/음원 연결 보존과 정적 검사를 기록하고 기존 개발 담당에게 인계한다. 실제 앱 반영·표시 상태와 구분한다.

## 조사 결과

- 6곡·587마디의 수록 XML과 제작 정본이 바이트까지 일치한다.
- 가사: Real Paradis 515개, Loveholic 269개, 갑자기 301개. 나머지 3곡은 가사가 없다.
- 갑자기의 시간 없는 마디 문구 7개를 유지한다. Loveholic의 전체 원문 필드와 Loveholic·갑자기의 원래 음절별 위치 근거는 작업 파일로 옮긴다.
- 기존 미확정 가사를 원본 확인 완료로 승격하지 않는다. 원본 의미 재판독은 이번 형식 전환의 범위가 아니다.

- 6곡 v3 정본 생성·작업 자료 보존과 정적 XML 검사를 완료했다. Real Paradis 515→480, Loveholic 269→269, 갑자기 301→301이며 나머지 3곡은 0개다.

## 후속: 소스 전용 패키지의 제작 도구 연결

개발 담당의 후속 요청에 따라 패키지 v2를 읽은 뒤 조판 결과를 직접 사용하는 제작 도구를 확인한다. 비어 있는 MusicXML 페이지·영역은 기존 `prepareBrowserScore`로 준비하고, 이미 준비한 결과는 재사용한다. 패키지 왕복 기대값은 공통 `verifyPackage`를 사용한다.

수정 범위는 `common/review.mjs`·타입 선언, Loveholic 검수 진입점, 갑자기 검수용 반환값, 붉은 노을 패키지 비교와 제작 도구 계약·이 기록이다. 정본·앱 코드·수록본은 변경하지 않는다. 개발 담당이 `review-score.md`와 `history.md`를 갱신한다. 구문·lint·서식·타입·문서 링크만 검사하며 렌더링·브라우저·회귀는 실행하지 않는다.
