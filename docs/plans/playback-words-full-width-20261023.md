# 연습 지시문의 마디 전체 폭 사용

- 목표: 붉은 노을66·134마디의 과도한 줄바꿈과136마디의 늦은 문구 시작을 수정한다.
- 범위: 두 앱의 공통 native 연습 라벨 배치·파생 캐시와 표시 규칙/결과 기록. 이전 미커밋 변경과 원본/백업을 보존한다.
- 완료 조건: 짧은 지시는 한 줄로 표시하고, 긴 지시는 중앙 앵커 주변의 좁은 폭이 아닌 마디 상단 전체 폭을 쓴다.136마디는 왼쪽에서 시작한다. 섹션·음표와의 간격 및 전체 문구 표시를 확인한다.
- 제외: 원본/canonical XML·음표/박 시각·음원·가사·개인 연습 설정 변경, 앱 버전 상승·커밋·push·발행.
- 검증: 실제66·134·136마디의 네 조판 경로/경계 계측, Safari 한 줄·두 줄 화면, source/canonical·미디어 보존, 관련 집중 검사와 전체 검증·두 앱 빌드.

이전v29의 중앙 앵커 양쪽으로 같은 폭만 허용한 계산은 사용자의 새 원본 대조에서 부적절한 것으로 확인됐다. 중앙 대칭 폭 제한을 없애고 실제 마디의 전체 여백 안에서 문구를 배치한다. 원래 명시된 줄바꿈은 보존하고, 자동 줄바꿈은 전체 폭을 넘는 경우에만 한다. 섹션과의 충돌은 위쪽 높이로 분리한다.

## 추가 결정 — 2026-10-24

중앙 정렬 라벨의 크기만 줄이면 문구 왼쪽이 뒤로 밀린다. native 원래 왼쪽 위치를 기준으로 크기를 바꿔 인쇄 지시문의 시작점을 유지한다. 두 줄 마디 번호는 기존28px 예약 영역 안으로 올려 번호 배경이 지시문을 가리지 않게 한다.

사용자는 연주 지시문 글꼴을 Pretendard로 확인하고 섹션 표기와 같은 글자 크기로 줄이도록 결정했다. 인쇄·연습의 공통 native 라벨에 실제 섹션 크기를 적용한다. VexFlow 섹션의10pt는 CSS13⅓px이므로 OSMD의20px 지시문을13⅓px로 맞춘다. 원본 XML의 글자 속성은 보존하고 출력에만 적용한다. 섹션은 굵게, 연주 지시는 원래 굵기를 유지한다. 같은 크기로 계산한 문구가 섹션 오른쪽에 들어가면 옆에 배치하며, 전체 폭을 넘지 않으면 한 줄을 유지한다. 이 추가 결정은 앞의 인쇄 출력 불변 조건보다 우선하며 인쇄 악보의 음표·박 시각·섹션 크기는 유지한다.
