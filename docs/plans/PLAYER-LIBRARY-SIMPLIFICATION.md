# 드럼연습실 악보 보관 단순화 (2026-10-13)
- 목표: 드럼연습실 백업·복원·별도 업데이트 기능과 기존 복원본을 제거한다.
- 범위: 재생 앱 목록/가져오기/도움말, 공통 DB의 재생 앱 archives 저장소 삭제, 재생 보관 코드와 검사.
- 완료 조건: 동일 ID 가져오기는 무조건 새 파일로 교체, 삭제는 영구 삭제, 현재/구형 DB에 archives 없음. 기본 연습곡 열기는 제공 중인 최신 파일 사용.
- 제외: 사용자 결정에 따라 악보제작기 전체 백업·작업 이력과 제작 원본 유지. 커밋·푸시·발행은 별도 요청 전까지 실행하지 않는다.
- 검증: 기존 DB 업그레이드·미디어 읽기 실패와 트랜잭션 실패의 현재 악보 보존·새 파일 교체·UI 기능 제거 집중 테스트, 전체 검사, 접근 가능한 사용자 브라우저 runtime 재조회.
