## 후보와 검토

- 시작 HEAD와 origin/main은 `0ca47a4e1d74e9bbcf8b458326cf9ada6c8aeb05`. 기존 변경 5파일을 보존하며 열린 PR과 다른 worktree는 없다.
- 두 앱 0.9.0 → 0.9.1. 기존 기능의 배치 오류와 아이콘 가독성 개선이므로 patch를 선택한다. 저장 스키마·키·패키지·오디오 예약은 바꾸지 않는다.
- CSS는 기존 BPM 전용 클래스와 공통 헤더를 재사용한다. 메트로놈·음표는 36×36px SVG 두 개이며 버튼은 세 모드 모두 84×48px다. 음원 조정 미리듣기 체크박스와 다른 버튼 스타일은 적용 대상에서 제외된다.
- 검토는 Codex 자체 검토이며 독립 검토로 표현하지 않는다. 새 기능·새 시험 데이터·별도 도구를 추가하지 않는다.
- 버전 갱신 직전 소스 빌드 `7948267fe366`이 기존 UI 검수 빌드와 일치한다. Ego Lite의 두 앱·6화면 크기·3모드 총 36상태 검수를 재사용하고, 이후 버전 이외 제품 소스 변경이 없는지 대조한다. Safari MCP 비활성/rAF 문제와 지정 iPad 시뮬레이터 부재는 기존 검수 한계로 유지한다.
