## 추가 확정 — 닫힌 서랍 공간 유지
- 서랍을 닫으면 내용만 숨기고 높이는 유지한다. 재생바와 악보는 움직이거나 확대되지 않는다. 정지 상태의 두 줄 보기도 두 행만 표시하며 상하 탐색은 행 단위로 정렬한다.

- 서랍 전환은 버튼 기준 확대/축소를 사용하지 않는다. 공통 View Transitions 처리에서 서랍 전용 모션을 선택해 상단 경계부터 아래로 펼치고 역방향으로 접는다. 열린 서랍의 내용 전환과 리퀴드 글래스는 유지한다.

- 재생바와 서랍 사이 간격은 0이다. 맞닿는 모서리는 직각으로 연결하여 재생바 아래에서 서랍이 나오는 형태로 표시한다.

- 재생 화면의 html/body 바탕만 흰색으로 분리한다. #app 및 제목바의 기존 색, 구역 배색, theme-color, 상단 간격은 유지한다.
- Safari 당김 시 드러나는 바탕을 실제 iPad에서 비교하기 위한 변경이며, 제목 흐림 해소를 확정하지 않는다.

## 2026-10-04 — 제목바 배색 강화
- 제목바와 theme-color를 #b8d4f5 파랑으로 변경하여 흰 바깥 바탕과 구별한다. 다른 구역 배색과 제목 글자색은 유지한다.

## 2026-10-04 — 상태바 색상용 제목바 구조 일치
- dgkmaWeb public-layout의 불투명 sticky top:0 헤더와 동일한 위치 방식을 적용한다. 드럼 제목바는 #b8d4f5, z-index40, backdrop-filter:none으로 둔다.
