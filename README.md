# 드럼 연습실

PDF 마디 영역과 원곡 시간을 연결하는 로컬 우선 웹앱입니다. MusicXML 변환 없이 악보·가사·음악을 함께 보며 연습합니다.

## 실행

Node.js 22 이상을 사용합니다.

```sh
cd /Users/raphael/Playground/drum-practice-web
npm ci
npm run dev -- --port 5173
```

Mac에서 `http://127.0.0.1:5173/`를 엽니다. 이 주소는 같은 Mac 전용이며 iPad에서 Mac에 접속하는 주소가 아닙니다. 현재 외부/LAN 배포는 하지 않았습니다. iPad 실사용에는 HTTPS로 접근 가능한 배포 또는 로컬 보안 접속 경로를 별도 준비해야 합니다.

## 사용

1. 기존 곡 버튼으로 준비한 곡을 열거나 ‘곡 추가’에서 PDF·음원을 선택합니다.
2. PDF의 마디 후보는 자동 검출 제안입니다. ‘악보·가사 맞추기’에서 원본과 비교하고 드래그로 영역을 바꿉니다.
3. BPM·첫 박을 입력합니다. 음원 템포 추정 또는 박자 탭을 참고하되 들어 보고 확인합니다.
4. 가사 시작·끝 시각을 보정합니다. 새 곡의 가사는 임시 분배이며 자동 음성 인식 결과가 아닙니다.
5. 연습 화면에서 속도·클릭·카운트인을 조절하고 마디/박으로 반복 범위를 저장합니다.
6. 마커, 반복, 정렬은 IndexedDB에 저장됩니다. 브라우저 정리 시 지워질 수 있으므로 ZIP 백업을 내보냅니다.

속도 변경은 음정을 유지하는 오디오를 기기에서 준비한 후 같은 음악 위치에서 재개합니다. 준비 중 잠시 멈춥니다. 카운트인은 음악 시간과 분리되며 구간 첫 마디의 박자표를 사용합니다. 음원 앞 여백이나 박 중간에서 시작하면 실제 다음 박에 준비 클릭을 맞춥니다. 화면을 떠나면 일시정지합니다.

## 예제 자료

현재 사용자가 제공한 원본과 분석 자료는 `public/demo/`, `data/reference/`에 로컬로 준비되어 있습니다. Git 제외 대상입니다. 앱을 공개 배포하기 전에 이 파일을 제거하거나 배포 범위를 별도로 결정해야 합니다. 빌드는 이 자료를 dist에도 복사하므로 dist 역시 공개하지 않습니다.

`python scripts/prepare_demo.py`는 원래 로컬 파일과 `/tmp/real-paradis-work/`가 있을 때만 재생성용으로 사용합니다. 정상 실행에는 임시 폴더가 필요하지 않습니다.

## 검증

```sh
npm test
npm run build
npm audit
```

실험 기록은 `history.md`, 반복 지시문은 `ONE_SHOT_PROMPT.md`, 증거는 `docs/experiments/`를 참고하세요. 현재 자동 테스트 25개와 빌드가 통과했고 로컬 Chromium GUI 검증을 수행했습니다. 항목별 증거와 남은 검증은 `docs/acceptance.md`를 참고하세요. 실제 iPad·청감·사용자 드럼 연주 평가는 아직 남아 있습니다. 새 백업은 파일 해시를 대조하지만 이전 버전 백업에는 해시가 없습니다.

## 라이선스

PDF.js: Apache-2.0, SoundTouchJS 0.3.0: LGPL-2.1, JSZip: MIT 또는 GPL-3.0. 배포 전 사용 버전의 라이선스와 원본 악보·음원의 이용 범위를 확인해야 합니다. 사용자 파일을 서버에 자동 전송하는 기능은 없습니다.

## 노래별 HTML 저장

곡을 연 뒤 상단 **HTML 한 파일로 저장**을 누릅니다. 음원·악보·가사·마커·반복과 실행 코드가 포함됩니다. HTML에서 수정한 내용은 같은 버튼으로 새 파일에 다시 저장하세요.

예제는 `exports/바람과 언덕의 발라드-드럼연습.html`입니다. Mac 브라우저의 파일 직접 실행·네트워크 차단 재생을 확인했습니다. iPad 기본 파일 미리보기 실행은 보장하지 않으며 실제 기기 검증이 남아 있습니다. 자세한 사용법과 제한은 `docs/PORTABLE-HTML.md`를 참고하세요.

### iPad mini 가로 화면

가수·곡명과 원곡 `♩ = BPM`을 상단에 표시합니다. 악보 아래 슬라이더를 끌면 손잡이 위에 현재 마디가 표시되고 악보가 함께 이동합니다. 하단의 반복·마커·소리·화면·악보 편집·가사 편집·곡 정보·파일 버튼으로 기능에 바로 접근합니다. 기본 악보 배율을 유지하고 아래 여백을 줄였습니다. 설계와 검증 범위는 [가로 화면 UX](docs/IPAD-LANDSCAPE-UX.md), [실험 기록](history.md)을 참고하세요. 실제 iPad 검증은 아직 수행하지 않았습니다.

## 현재 개발 정본

후속 개발은 `src/`와 `http://127.0.0.1:5173/` 웹앱을 기준으로 진행합니다. 예제 HTML은 요청 시에만 별도로 내보냅니다. 앱의 HTML 저장 기능은 유지합니다.

Git은 소스·설정·문서·테스트를 관리하며, 원본 미디어·로컬 분석 자료·실험 산출물·생성 HTML은 로컬에 보존하고 추적하지 않습니다. 일부 예제 기반 테스트는 제외된 `public/demo/`와 `data/reference/` 자료가 있어야 실행됩니다.
