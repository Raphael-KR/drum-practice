# 보존한 범례와 화면 검수 자료

이 폴더는 과거 범례 SVG와 화면 검수 증거를 보존한다. 일반 임시 출력이나 현재 앱 빌드 결과를 모으는 폴더가 아니다. 파일명에 `exports`가 있어도 독립 HTML 내보내기 기능을 뜻하지 않는다.

| 자료 | 용도와 확인 경로 |
| --- | --- |
| [드럼-악보-공통범례.svg](드럼-악보-공통범례.svg) | 보존된 범례 SVG. 현행 악기·주법 의미는 [표기 정본](../docs/reference/score/notation.md), 앱 범례 자산·생성 절차는 [범례 자산 안내](../docs/design/legend-diagram/README.md)를 따른다. 이 파일을 현행 규칙 정본으로 사용하지 않는다. |
| [help-qa/](help-qa/) | 도움말·조정·확인창 등의 과거 화면 캡처 14개. 당시 환경·검사 범위는 [변경 기록](../history.md)과 [공통 UI 결정의 원문 기록](../docs/records/archive/adr-0021-contextual-help-and-shared-ui-sources.md)에서 확인한다. 현재 화면이나 최신 기기 검증을 보증하지 않는다. |

## 보존과 새 산출물의 위치

- 기존 SVG·캡처의 내용과 경로를 유지한다. 이번 안내 추가는 이동·재생성·삭제를 포함하지 않는다.
- 새 임시 검사 로그·화면 증거는 작업별 `.tmp/`에 두고, 확인한 결과·환경·한계를 관련 `docs/records/` 문서와 `history.md`에 기록한다. 로컬에만 있는 증거 경로는 클릭 링크로 만들지 않는다.
- 앱 빌드 결과는 `dist/`, 악보 제작 원본·산출물은 기존 제작 절차가 지정한 `data/production/` 등에서 관리한다. 이 폴더에 복제하지 않는다.
- 표기·앱 기능 변경은 관련 정본과 공통 구현을 통해 수행한다. 과거 SVG·캡처를 수정해 현재 검증 증거로 바꾸지 않는다.
